## 問題群の世界観

### 1. 高校数学の対象を、別の理論の座標として使う

数列を離散力学、三角形を半代数領域、格子点を連続極限、方程式の根を点配置として読む。
大学数学の用語を問題文に置くことが目的ではない。同じ対象を高校数学の操作で扱える別表現へ移すことが核心である。

例:

- 問題15: 三角形の角 -> 対称な三角関数不変量 -> 境界曲線 -> 面積。
- 問題31: 積分方程式 -> 微分方程式 -> Chebyshev型多項式 -> 円分的根構造。
- 問題34: 床関数付き整数条件 -> Pell双曲線上の格子点 -> 弧と弦の面積。
- 問題72: Fourier部分和 -> 小数部分近似 -> 回転体積 -> 調和級数型観測。

### 2. 難しさは計算量より「表現を変える決断」に置く

良い問題では、表面上の対象と実際に計算すべき対象が一致しない。変換後の計算は標準的でもよい。
問題15の作問者コメントにも、対称性から境界を二等辺へ落とせば、その後は標準計算で押し切れるという設計意図が明記されている。

### 3. 異分野接続は、同じ不変量が運ばれる場合だけ成立する

単に「整数論の答を幾何の係数へ渡す」のではない。点集合、順序、対称性、解集合、面積、周期など、
次の表現でも意味を保つ対象が必要である。作問サークル問題も、多くは小問が同じ不変量を段階的に露出させる構成であり、無関係な題材の直結ではない。

### 4. 局所計算より大域的な問いを好む

通過領域、軌跡、存在範囲、全分類、極限、最大最小が多い。これは一点の値を計算する問題より、
パラメータ全体の振舞いを把握させる設計である。Minkowski和は、この世界観に合うが、名前を貼るだけでは不十分である。
「可動図形の配置空間 -> 平行移動集合 -> 和・差体 -> 境界 -> 面積」という必然的な経路として使うべきである。

## 従来生成器が外した理由

1. 射の本数を難易度の代用にした。長い一本道でも、各射が問題の核心に必要とは限らない。
2. 同じfamilyとqueryを固定し、数値だけを変えた。これは構造新規性ではない。
3. 閉形式が得られることを優先し、問題を解きたいと思わせる構想を評価しなかった。
4. モルフォロジー経路の隣接性は検査したが、各辺の必要性を反実仮想で検査しなかった。
5. ユーザーのコーパスにない楕円接線族を、一般的な幾何生成族として過剰配信した。

投票もこれを支持する。修復理由は `too_easy` 69、`too_typical` 50、
`unnatural_connection` 7、`short_proof` 7、`unnatural_wording` 3だった。
旧scalar bridgeは95件すべてスキップされた。

## 新しい生成契約

新候補は、数値が正しいだけでは配信しない。次を記録する。

1. `surface_object`: 問題文で見える高校数学対象。
2. `latent_object`: 解法で初めて現れる抽象対象。
3. `transported_invariant`: 表現をまたいで保存される量・関係。
4. `bridge_morphism`: なぜその表現変換が必要か。
5. `proof_dag`: 独立条件がどこで合流するか。
6. `edge_ablation`: 各主要辺を外したとき、問いが未決定になるか。
7. `surface_ablation`: 数値変更でなく、対象・制約・問いを変えても同じ構想が再利用できるか。

少なくとも一つの主要辺が「なくても同じ答が出る」なら、見せかけの多層化として保留する。

## 優先する生成方向

1. 可動図形の包含を、配置空間とMinkowski差へ移す通過領域。
2. 回転・折返し・正射影を介した領域と包絡線。
3. 対称な多角形・三角形配置を群作用で商にし、境界を一変数化する問題。
4. 格子点や整数条件が、曲線・角・面積を剛直化する整数幾何。
5. 関数・図形変換の反復を、固定点・周期・極限領域として観測する問題。

楕円接線の単発計算、サイコロ和、ギャンブラー破産は現在の公開対象から保留する。

## 空間図形への拡張実験

二次元の問題へ立体語を足すのではなく、同じ世界観を次元だけ上げる。

- 三角形の変位領域 `T-T` を四面体へ上げ、符号領域の分割から体積比20を得る。
- 動く直線の包絡線を、動く平面による立方体の断面へ上げる。断面積を部分体積の微分として観測する。
- 円板の通過領域を球の通過領域へ上げ、面・辺・頂点という境界階層から体積を再構成する。

これらは同じ問題の数値違いではない。差集合、切断、平行体という異なる潜在対象を使う。
各問題は閉形式の導出とは別に、三次元凸包または辺交点から数値検算した。
