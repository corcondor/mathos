# 行列・二次形式・図形観測核（2026-08-10）

## 結論

「すべてを通常の数値行列にする」のではなく、次の4項組を共通核とする。

`TypedSpace + OperatorMatrix + ConstraintSet + Observation`

- 連立一次方程式: `A u = b`
- 多項式の点通過条件: 係数ベクトルに対する評価行列
- 根条件: 係数ベクトルに対する評価行
- 二次方程式の実根条件: 判別式を行列式として観測
- 円・二次曲線: 同次座標上の対称二次形式 `X^T C X = 0`
- グラフ上の距離: 埋め込みベクトルのGram形式
- 一次分数変換: `PGL(2)` の2×2行列（生成側には既存、問題解答入力への接続は次段階）

不等式・存在領域は行列だけでは失われるため、`ConstraintSet`を必須とする。非線形問題は有限次元の単項式空間へ持ち上げられる場合だけ行列化し、閉じない場合はGroebner基底・量化消去へ渡す。

## 実装した共通チャート

`matrix_semantic_query.py` に表層問題名ではなく、以下の実行射を追加した。

1. `evaluation_matrix`: 点通過条件から係数を復元して観測
2. `evaluation_row`: 指定された根から未知係数を復元
3. `discriminant_matrix`: 実根領域、整数・有理根、有限確率を観測
4. `symmetric_conic_matrix`: 円の中心・半径・座標極値を観測
5. `gram_distance_lift`: グラフ上の原点距離を最小化
6. `vieta_coefficient_map`: 根の型制約を対称係数へ射影

すべての結果に `typed_matrix_chart` 証明書と、実際の行列・行列式・代入検証を付ける。数値を変えた問題でも同じチャートと実行射を使い、答えだけが変わるテストを置いた。
このIRは共有意味グラフにも持ち上げ、`chart -> constraint -> query morphism -> backend` の経路をUI・検証ログに残す。
