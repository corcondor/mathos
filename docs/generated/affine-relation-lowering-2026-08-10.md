# 比較・割合・未知量の実行可能lowering（2026-08-10）

## 目的

比較、割合、未知量を問題文別の解法へ振り分けず、すべて有理アフィン制約
`A x = b` と観測射へloweringし、同じGauss消去核で実行する。
問題ID、データセット名、期待解、正解値は実行器へ入力しない。

## 実装

- `AffineEquation`: 型付き変数の有理係数線形式。
- `solve_affine_system`: 全分野共通の有理Gauss消去。
- 状態の穴: `final = initial + gains - losses`。
- 排他的分割: `a+b=total`, `a-b=difference`。
- 比較鎖: 大小差、倍数、既知値を一つの連立系へ統合。
- 割合作用: 増加、割引、元値をアフィン写像として実行。
- 重み付き観測: `sum(count_i * unit_value_i)`。
- 質問観測: 個体値、総和、2変数の差を別の射として合成。

## 完全性ゲート

初版は比較節だけを解き、個数と単価、総和、別対象への質問を落としたまま回答した。
次の一般条件を追加した。

1. 同じsurface spanから得た比較関係は1回だけIRへ登録する。
2. 数値アンカーは文境界を越えない。
3. `who`は直前の明示対象へ解決し、未解決の代名詞は変数にしない。
4. 百分率の基準対象と質問対象の型が一致しない場合は実行しない。
5. 全数値前提が型付きleafにならない次元合成は棄却する。
6. 未消費のrate、時間変換、状態遷移がある場合は比較核から答えない。

これらは問題固有の答えを追加する規則ではなく、IRが入力制約を取りこぼしていないことを
検査するproof obligationである。

## 定量結果

同一manifest `996fd351...`、3,574問、外部検索なし、8 workers、1問12秒で比較した。

| 指標 | 直前 | 最終回帰 | 差 |
|---|---:|---:|---:|
| exact | 681 | **707** | **+26** |
| exact rate | 19.05% | **19.78%** | **+0.73pt** |
| wrong | 545 | **542** | **-3** |
| answer precision | 55.55% | **56.61%** | **+1.06pt** |
| held-out exact | 474 | **492** | +18 |
| held-out wrong | 399 | **397** | -2 |
| morphism-to-backend gap | 2,128相当の重点層 | **2,105** | -23 |

分割別の最終値は dev `152/686`、calibration `63/358`、held-out `492/2530`。
単体・反実仮想テストでは名称、数値、対象語を変更して同じ制約骨格が発火することを確認した。
新設したアフィン経路は比較、割合、未知量、積型比較を合わせて **28/28正答** だった。

## 評価上の注意

最初のheld-out実行は正答を増やした一方で誤発火も増やした。その誤りを構造監査に使って
完全性ゲートを修正したため、最終held-out値は純粋な未見推定ではなく回帰値である。
次の汎化主張には、別saltまたは別コーパスで新しいfrozen setを作り、一度だけ測る必要がある。

## 残差

最終でも `morphism_to_backend_gap=2,106` が最大である。次は単純な語彙追加ではなく、
複数割合の合成、rateと時間単位の変換、状態遷移を含む線形系を、それぞれ全制約消費証明付きで
同じ消去核へ接続する。
