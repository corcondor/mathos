# MORTRA-1 構造定理核による全問題ベンチ改善実験

## 原理

問題ごとの答えや文型を登録するのではなく、複数分野で再利用できる数学的な射を型付きIRとして実行する。

今回の核は、問題文を次の形へ落とす。

```text
TeX / 日本語
  -> 型付き数学対象とquery
  -> 構造定理operator
  -> 厳密計算・有限列挙・Sturm列・既知定理
  -> answer + witness + derivation
```

`lowering_certificate` は `alpha_renamable=true`、`memorized_answer=false` を要求する。実行結果には、答えだけでなく、使用した変換、有限探索範囲、符号証明、反例探索の記録を残す。

## 方法

- 対象: `全問題.tex` から解答部分を除いて抽出した85問。
- 外部LLM、ウェブ検索、旧benchmark専用adapter: 不使用。
- 制限時間: 1問20秒。時間切れは正答に含めない。
- 成功条件: 問題全体の回答を返し、型付き実行結果と証明書が成功した場合だけ `verified_answer` とする。
- 一般化検査: 係数・上限・変数を変更した反事実入力と、有限範囲の全探索を別テストで実行する。

追加した主な構造射は次の通りである。

1. 等半径円の共通面積を距離微分と漸近差へ変換する。
2. 相加平均・相乗平均の相関を連続極限と共分散行列へ変換する。
3. 円分値の有理化を商環の逆元計算へ変換する。
4. 非線形漸化式を二段比、Wallis積、Gaussian積分へ変換する。
5. Chebyshev積分方程式をODE、重根、導関数へ変換する。
6. 正十二面体を `Q(sqrt(5))` 上の20頂点と外積比較へ変換する。
7. 三角関数三辺の面積を一変数多項式とSturm符号証明へ変換する。
8. 基本対称式三辺を素数順序と双曲線型不等式へ変換する。
9. 素数冪三辺を `log(x)/(x-1)` の単調性へ変換する。
10. 有理な正弦条件を平方条件と有限因子対へ変換する。
11. 三角数と素数積の一致を有限基底とBertrand型成長へ変換する。
12. 合成三角関数積分をJensen不等式と接線上界へ変換する。
13. 正の二階線形漸化式を特性根と黄金比区間へ変換する。
14. 角倍化整数三角形を有理半角媒介と正弦漸化式へ変換する。
15. 全実数上の対数・指数不等式を二本の支援曲線と係数領域へ変換する。
16. 三角形の角式最大化を項別上界と同時等号条件へ変換する。
17. 三角関数反復を二段作用、凸導関数、有理Taylor区間証明へ変換する。
18. 離散三角指数列を一変数凸関数と有理根分離へ変換する。
19. べき平均漸化式を `y_n=x_n^p` で二階線形漸化式へ共役する。

## 結果

| 段階 | 検証済み回答 | 率 |
|---|---:|---:|
| 実験開始時 | 10 / 85 | 11.76% |
| 第一波 | 30 / 85 | 35.29% |
| 第二波 | 42 / 85 | 49.41% |
| 最大観測値 | 46 / 85 | 54.12% |
| 厳密性監査後 | **45 / 85** | **52.94%** |
| 追加構造・高速経路後 | **54 / 85** | **63.53%** |

開始時からの改善は `+44問`、`+51.76ポイント`、回答完了数で5.4倍である。最終測定では31問が `partial_plan` で、時間切れは0問だった。

分野別では、幾何 `23/40`、整数論 `5/9`、不等式 `5/7`、代数 `6/10`、最適化 `3/6`、確率 `2/2`、実解析 `4/4`、微積分 `2/3` となった。

最大観測値46件から、複素二項式の全実数不等式1件を除外した。この問題は有限prefixと数値最適化では正しい値を示したが、上界との差が小さく、全領域を覆う厳密証明書が未完成だったためである。

## 解法暗記の検査

- 円共通面積は距離差の定数を `1/2` から `3/2` に変え、答えが `-sqrt(3)/8` から `-9sqrt(3)/8` に変わることを確認した。
- 素数冪和は底を2026から4へ変え、例外素数と合成因子を再計算した。
- 正十二面体は辺長を1から2へ変え、最大面積が4倍になることを確認した。
- 対称式三辺、順序付き素数冪、有理正弦、三角数と素数積は、最大1000または素数上限を変えた有限全探索と理論分類が一致した。
- 三角関数面積は有限個の値比較を廃止し、連続変数上の導関数符号へ置き換えた。
- 角倍化整数三角形は未使用の `n=4,...,12` でも同じ有理媒介から整数辺を再生成し、三角不等式を確認した。
- 三角関数反復は特定の反復回数を列挙せず、二段作用の区間不等式から偶奇別帰納法で全自然数を覆った。
- 離散三角指数列は80項比較を廃止した。凸性と二つの有理分離点で候補を12,13に絞り、pi・sqrt(6)・log(1+u)の有理区間証明でa_12<a_13を閉じた。
- べき平均漸化式は初期値1,2に依存せず、未見初期値3,5でも同じ共役、特性根、極限計算を再実行した。

これらは完全な高校数学全体への汎化証明ではない。しかし、少なくとも答えの文字列や問題番号ではなく、パラメータ変更後も同じ射が実行されることを示す。

## 考察

改善前の主要因は、構文解析の不足だけではなかった。数式や対象を認識しても、それを実行可能な証明義務へ落とす射が欠けていた。今回の改善は、型付きIRとbackendの間に構造定理operatorを置くことで得られた。

一方、`verified_answer` は正解集とのexact matchではない。MORTRA内部で回答と証明書の生成が完了した割合である。したがって、54/85を外部モデルの正答率と直接比較してはならない。今後は人手または独立証明器によるgold answer監査を追加し、`answer correctness` と `executable completion` を分離する必要がある。

実行順にも欠陥があった。型付き構造定理核が既に選ばれた後でも汎用 `MathSearch` が先に動き、47番では証明核自体が0.001秒未満なのに全体が23.1582秒かかっていた。専用IR確定後は重複した汎用探索を省くようにし、同じ解答と証明書を0.0511秒で返した。約453倍の高速化であり、20秒制限による偽の失敗を除去した。未接続問題の汎用探索は維持している。

残る31問は、一般幾何17問、整数論4問、代数4問、最適化3問などに集中している。次の高利得領域は、領域積分、立体切断、整数格子最適化を同じ半代数集合・消去・単調性核へ接続することである。

## 結論

問題固有の答えを登録せず、再利用可能な構造定理核を追加することで、実行証明書付き回答率を11.76%から63.53%へ改善した。50%目標は超えたが、これは最終的な数学正答率ではない。次の段階では、独立検証器によるgold監査と、残る領域・立体・整数幾何問題の実行可能制約化を進める。
