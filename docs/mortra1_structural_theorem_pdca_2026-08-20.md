# MORTRA-1 構造定理核による全問題ベンチ改善実験

## 原理

問題ごとの答えや文型を登録するのではなく、複数分野で再利用できる数学的な射を型付きIRとして実行する。

今回の核は、問題文を次の形へ落とす。

```text
TeX / 日本語
  -> 型付き数学対象とquery
  -> 構造定理operator
  -> 厳密計算・有限列挙・Sturm列・既知定理
  -> answer + witness + derivation
```

`lowering_certificate` は `alpha_renamable=true`、`memorized_answer=false` を要求する。実行結果には、答えだけでなく、使用した変換、有限探索範囲、符号証明、反例探索の記録を残す。

## 方法

- 対象: `全問題.tex` から解答部分を除いて抽出した85問。
- 外部LLM、ウェブ検索、旧benchmark専用adapter: 不使用。
- 制限時間: 1問20秒。時間切れは正答に含めない。
- 成功条件: 問題全体の回答を返し、型付き実行結果と証明書が成功した場合だけ `verified_answer` とする。
- 一般化検査: 係数・上限・変数を変更した反事実入力と、有限範囲の全探索を別テストで実行する。

追加した主な構造射は次の通りである。

1. 等半径円の共通面積を距離微分と漸近差へ変換する。
2. 相加平均・相乗平均の相関を連続極限と共分散行列へ変換する。
3. 円分値の有理化を商環の逆元計算へ変換する。
4. 非線形漸化式を二段比、Wallis積、Gaussian積分へ変換する。
5. Chebyshev積分方程式をODE、重根、導関数へ変換する。
6. 正十二面体を `Q(sqrt(5))` 上の20頂点と外積比較へ変換する。
7. 三角関数三辺の面積を一変数多項式とSturm符号証明へ変換する。
8. 基本対称式三辺を素数順序と双曲線型不等式へ変換する。
9. 素数冪三辺を `log(x)/(x-1)` の単調性へ変換する。
10. 有理な正弦条件を平方条件と有限因子対へ変換する。
11. 三角数と素数積の一致を有限基底とBertrand型成長へ変換する。

## 結果

| 段階 | 検証済み回答 | 率 |
|---|---:|---:|
| 実験開始時 | 10 / 85 | 11.76% |
| 第一波 | 30 / 85 | 35.29% |
| 第二波 | 42 / 85 | 49.41% |
| 最大観測値 | 46 / 85 | 54.12% |
| 厳密性監査後 | **45 / 85** | **52.94%** |

開始時からの改善は `+35問`、`+41.18ポイント`、回答完了数で4.5倍である。最終測定では39問が `partial_plan`、1問が時間切れだった。

分野別では、幾何 `20/38`、整数論 `5/9`、不等式 `4/7`、代数 `4/9`、確率 `2/2`、実解析 `3/3` となった。

最大観測値46件から、複素二項式の全実数不等式1件を除外した。この問題は有限prefixと数値最適化では正しい値を示したが、上界との差が小さく、全領域を覆う厳密証明書が未完成だったためである。

## 解法暗記の検査

- 円共通面積は距離差の定数を `1/2` から `3/2` に変え、答えが `-sqrt(3)/8` から `-9sqrt(3)/8` に変わることを確認した。
- 素数冪和は底を2026から4へ変え、例外素数と合成因子を再計算した。
- 正十二面体は辺長を1から2へ変え、最大面積が4倍になることを確認した。
- 対称式三辺、順序付き素数冪、有理正弦、三角数と素数積は、最大1000または素数上限を変えた有限全探索と理論分類が一致した。
- 三角関数面積は有限個の値比較を廃止し、連続変数上の導関数符号へ置き換えた。

これらは完全な高校数学全体への汎化証明ではない。しかし、少なくとも答えの文字列や問題番号ではなく、パラメータ変更後も同じ射が実行されることを示す。

## 考察

改善前の主要因は、構文解析の不足だけではなかった。数式や対象を認識しても、それを実行可能な証明義務へ落とす射が欠けていた。今回の改善は、型付きIRとbackendの間に構造定理operatorを置くことで得られた。

一方、`verified_answer` は正解集とのexact matchではない。MORTRA内部で回答と証明書の生成が完了した割合である。したがって、45/85を外部モデルの正答率と直接比較してはならない。今後は人手または独立証明器によるgold answer監査を追加し、`answer correctness` と `executable completion` を分離する必要がある。

残る39問は、最適化4問、一般幾何18問、代数5問などに集中している。次の高利得領域は、領域積分、立体切断、整数格子最適化、反復不等式を同じ半代数集合・消去・単調性核へ接続することである。

## 結論

問題固有の答えを登録せず、再利用可能な構造定理核を追加することで、実行証明書付き回答率を11.76%から52.94%へ改善した。50%目標は達成したが、これは最終的な数学正答率ではない。次の段階では、独立検証器によるgold監査と、残る領域・最適化問題の実行可能制約化を進める。
