# MathOS アフィン・n次元バックエンド接続記録（2026-08-10）

## 目的

数式を文字列のまま `sympy.solve` へ渡すのではなく、型付き意味IRから次の共通数学対象へloweringし、行列演算として実行・再検証する。

- アフィン空間上の直線と超平面
- 超平面への直交射影と鏡映
- 二次形式とアフィン中心
- 二次制約上のユークリッド距離最適化
- 放物線の頂点・焦点パラメータ
- 任意有限次元の等方二次曲面（球面）

問題番号、データセット名、期待解はコンパイラとexecutorへ渡さない。

## 実装した実行契約

| IR operator | 数学的実体 | 検証 |
|---|---|---|
| `quadratic_form_center` | `c=-Q^{-1}l/2` | 勾配が中心で0 |
| `constrained_point_distance_extremum` | Lagrange未定乗数法 | 制約代入、実数性、コンパクト性 |
| `axis_aligned_parabola_directrix` | 頂点形式と `p=1/(4a)` | 二次次数と軸方向 |
| `line_hyperplane_intersection` | アフィン媒介変数消去 | 直線比と超平面の両方へ再代入 |
| `reflect_point_across_hyperplane` | `p'=p-2(n·p+c)n/(n·n)` | 中点が超平面上、変位が法線方向 |
| `sphere_center_or_radius` | 等方二次形式 `Q=lambda I` | 正定値半径と次元整合性 |

3次元は特別な問題型ではなく `Point3` として扱う。球面executorは4次元テストも通し、同じ契約が次元に依存しないことを確認した。

## 公開MATHで新たに正解した6問

1. 不定二次形式で表された双曲線の原点最短距離
2. 一般二次曲線の中心
3. 放物線の準線
4. 楕円上の点と固定点の最大距離
5. 3次元の直線と平面の交点
6. 3次元の点の平面対称点

旧経路は式を一変数について解いた候補を返していた。新経路は問題の観測対象を型付きoperatorとして実行する。

## 未解決の接続欠損

最終計測の `morphism_to_backend_gap` は2,242件。前記録の2,239件より3件多いのは、前回タイムアウトだったMATH 3問が今回は完走し、未接続として正しく分類されたためである。実質的な最大層は次の通り。

- 自然文の数量・割合・時系列を実行可能なアフィン制約へloweringできない問題
- TeX数式から観測対象を決められず、汎用CAS呼び出しが非実行のまま残る問題
- backendは存在するが、型付き意味IRからexecutor contractへ到達しない問題

従って「バックエンド接続が完了した」とは言わない。今回完了したのはアフィン幾何・二次形式・n次元ユークリッド演算の接続である。次の主対象は、2,242件を表層文型でなく制約スケルトン別にクラスタリングし、既存の線形消去核・有限和積核・整数制約核へ接続すること。
