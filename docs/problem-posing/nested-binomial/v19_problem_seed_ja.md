# v19からの作問メモ：二次式の整除と二次式の消去

2026-11-07 JST。研究の式から切り出した問題案。以下の整数問題は記述証明で完結する。
元の二項係数方程式の解決を意味しない。既出問題との照合はしていない。

## 問題案：二次式の整除

互いに素な正の整数 \(a,b\) が \(a>b\) を満たすとする。
\(a^2+3b^2\) が \(24a\) の約数となるような組 \((a,b)\) をすべて求めよ。

### 解答

答えは \(\boxed{(a,b)=(3,1)}\)。

\(d=a^2+3b^2\) とおくと、
\[
d\mid24a,\qquad \gcd(d,a)=\gcd(3b^2,a)=\gcd(3,a)\mid3.
\]
したがって、\(d\) に5以上の素因数はない。

\(a,b\) がともに奇数なら \(d\equiv4\pmod8\) であり、\(d\) の2の指数は正確に2。
一方だけが偶数なら \(d\) は奇数である。
また、\(3\mid a\) なら \(3\nmid b\) より \(d\equiv3\pmod9\) であり、3の指数は正確に1。
\(3\nmid a\) なら \(d\equiv1\pmod3\) である。

よって \(d\mid12\)。\(b\ge2\) なら \(a\ge3\) より \(d\ge21\) となるので、
\(b=1\)。\(a>1\) と \(a^2+3\mid12\) から \(a=3\) である。
実際、\((3,1)\) では \(a^2+3b^2=12\mid72=24a\)。

### 作問上の核

二次式の大きさだけでも \(a<24\) にはなるが、解答ではその有限走査を使わない。
最大公約数で素因数を2・3へ限定し、法8・法9で指数まで決めると、\(d\mid12\) に縮む。
問題文に楕円曲線の知識や誘導を入れる必要はない。

研究では、楕円曲線上の明示点が有限位数だと仮定したとき、
接線の傾きの整除条件がこの問題に帰着する。作問側の証明は上の初等整数論だけで完結する。

研究元：[v19の無限位数点の証明](https://github.com/corcondor/mathos/blob/bb15643fd43f3595676cc410c1774a67a040c0b5/docs/research/nested-binomial/v19_residual_positive_rank.md)。

## 再利用できる補題：二次式と一次式の共通約数

整数 \(x,A,B\) と正の整数 \(d\) について、
\[
d\mid x^2+2,\qquad d\mid Ax+B
\]
ならば
\[
\boxed{d\mid 2A^2+B^2}.
\]

証明は恒等式
\[
A^2(x^2+2)-(Ax-B)(Ax+B)=2A^2+B^2
\]
だけでよい。\(A\) と \(d\) が互いに素という仮定は不要である。

研究では \(n\) を法 \(G\) の式から消去する際に使う。
\(A\) の逆元を勝手に使わず、係数が整数の恒等式を残すことが要点となる。
一般の \(x^2+s\) にも同じ証明で
\(d\mid B^2+sA^2\) と拡張できる。

この補題そのものの新規性は主張しない。既存の消去の補題カードを、
v19で実際に使った具体形と対応づけるための追記である。
