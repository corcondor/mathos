## 今回の使いどころ

| 素材 | 作問で使える仕掛け | 具体化 |
|---|---|---|
| 二つの一次式の共通約数 | 変数を消して一定の整数の約数にする | 最大公約数の最大値が20となる問題 |
| 分母の決まった平方根近似 | 倍して隣接する二平方数の間へ入れる | 四次式が平方数となる正整数は3のみ |
| 平方と立方の整除の差 | 素因数の指数の丸めを分類する | 許される指数が1・2・4となる分類 |
| 二項係数の基本整除 | 巨大な二項係数を補助の整数へ移す | C(p²,p)はpで割れ、p²では割れない |
| 付値の相殺・消去式 | 一方の項の低い指数、二つの合同条件を使う | 発展問題を設計するための補題 |

最初の2題は、有限個の具体的な答えを持つ高校数学の問題として解答まで整えています。
後半2題は一般命題を問う補題確認用です。難易度は編集上の目安で、特定大学の入試相当と判定したものではありません。
全4題について既出調査は未実施であり、独創性の確認は今後の作業です。

## 今後の追記形式

研究の各版から作問に役立つ部分が得られたら、次を記録します。

1. **出典**：版・ファイル・節・固定コミット。
2. **独立した補題**：変数の範囲、必要な仮定、結論、証明。
3. **問題への移し方**：何を隠すと発見になるか、自然な設定は何か。
4. **問題案**：短い問題文、解答、全解である理由、境界値。
5. **状態**：成立性、難易度、既出調査、未検証の発展案をそれぞれ記録。

研究固有の条件を外す際は、その条件を使う証明箇所を確認します。
例えば、元の枝での `n≥104`、`Q|r³`、既約表示、分岐の指定は、独立した整数問題に自動的に引き継がれません。
