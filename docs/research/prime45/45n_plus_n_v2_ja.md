# 45^n+n の数論研究 v2 — 法 m に関する完全一様分布と密度1の合成数

作成：2026-11-15。対象：F(n)=45^n+n、n≥1。動機：2027=45^2+2。

## 0. 結論と注意

**定理 A**（任意の固定法 m に対する完全一様分布）。任意の正整数 m、任意の剰余 r (mod m) に対し

\[
\lim_{X\to\infty}\frac{\#\{1\le n\le X : 45^n+n\equiv r\pmod m\}}{X}=\frac1m.
\]

**系 B**（素数になる指数の密度0）。\(45^n+n\) が素数となる \(n\) の自然密度は0。逆に合成数となる \(n\) の自然密度は1。

**系 C**（有界個の素因数も密度0）。任意の固定整数 K≥0 に対し、\(\omega(45^n+n)\le K\) を満たす n の自然密度は0。ここで \(\omega\) は相異なる素因数の個数。

これらは「素数になる n が有限個である」「3878 と 9424 は素数・合成数である」という主張ではない。既知の初等数論の方法による導出であり、数学界における優先権・新規性は未調査。

## 1. 素数冪での剰余類を全分類

任意の整数 a≥2 に対する \(F_a(n)=a^n+n\) を考える。

**補題 1a（p が a を割らない場合）.** p∤a を素数、d=ord_p(a) とすると、任意の k≥1、任意の c (mod p^k)、および任意の r (mod d) に対して

\[
n\equiv r\pmod d,\qquad a^n+n\equiv c\pmod{p^k}
\]

を同時に満たす n の合同類は法 dp^k に対してただ1つ存在する。

*証明.* d|p−1 より gcd(d,p)=1。k=1 では n=r+dt と置けば a^n≡a^r (mod p) なので、a^r+r+dt≡c (mod p) は t (mod p) をただ1つ定める。k での解を n とする。j=0,1,…,p−1 に対し n'=n+jdp^k と置く。a^d≡1 (mod p) だから二項定理で a^{dp^k}≡1 (mod p^{k+1}) が成り立ち、

\[
F_a(n')\equiv F_a(n)+jdp^k\pmod{p^{k+1}}.
\]

したがって j (mod p) をただ1つ選んで c (mod p^{k+1}) に持ち上げられる。p=2 でも同じ二項定理が使える。帰納法で完了。□

**補題 1b（p が a を割る場合）.** p|a なら、任意の k≥1 に対し n≥k では \(a^n+n\equiv n\pmod{p^k}\)。したがって n→∞ の範囲では各剰余類が等頻度。

*証明.* p^k|a^n は n≥k で成立。□

## 2. 異なる素数の条件が独立になる理由（定理 A の証明）

m=∏_{i=1}^s p_i^{e_i} を p_1<…<p_s の昇順とする。

p_i∤a なら、\(F_a(n)\pmod{p_i^{e_i}}\) は周期 \(d_i p_i^{e_i}\)（d_i=ord_{p_i}(a)）で決まる。p_i|a なら、十分大きい n 以降は周期 \(p_i^{e_i}\) で決まる。

先行する小さい素数の諸条件の周期の最小公倍数を L とする。各 d_i は p_i−1 の約数なので、L の素因数は p_i 未満のものに限られ、新たに追加する素数 p_j は L を割らない。

新しい d_j を加えた周期 T=lcm(L,d_j) に諸条件を精密化しても、古い剰余条件は不変であり、p_j∤T。各 n (mod T) について、補題1aの一意性より、n を n+tT (t mod p_j^{e_j}) と動かすと F_a(n) は p_j^{e_j} のすべての剰余類をそれぞれちょうど1回取る。p_j|a の場合も補題1bから同様。

よって追加した p_j^{e_j} の剰余条件は、先行する条件と **正確に 1/p_j^{e_j} の割合で独立**。帰納法と中国剰余定理で、m のすべての剰余が自然密度1/mで現れる。□

**応用 2a（すべての固定された素数集合で完全独立）.** 有限集合 S に対して

\[
\operatorname{dens}\{n: p\nmid F(n)\ \forall p\in S\}
=\prod_{p\in S}\left(1-\frac1p\right).
\]

より一般に、各素数 p の冪による除算の条件も有限個の素数間で独立になる。

## 3. 密度1で合成数になることの証明

B を固定する。有限集合 S={素数 p≤B} に対して、小素因数を持たない n の密度は正確に

\[
\delta(B)=\prod_{p\le B}\left(1-\frac1p\right).
\]

n が十分大きければ F(n)>B。よって F(n) が素数ならば B 以下のどの素数でも割り切れない。素数指数の上密度は高々 δ(B)。Euler の素数逆数の発散（同値な Euler 積の極限0）より δ(B)→0。従って素数指数の密度0、合成数指数の密度1。□

具体的には、有限個の素数による除外率は次の通り（**極限密度**であり「有限区間にすでにこの割合」という意味ではない）。

| 素数の上限 B | 小素因数を持たない n の密度 δ(B) | 合成数と確定する n の密度の下限 |
|--:|--:|--:|
| 13 | 0.1918081918 | 80.81918082% |
| 23 | 0.1635881954 | 83.64118046% |
| 97 | 0.1203172905 | 87.96827095% |
| 997 | 0.0809652635 | 91.90347365% |
| 9973 | 0.0608846925 | 93.91153075% |

特に、いかなる有限個の固定素数でも全ての n を覆えない。有限個の素数を回避する指数の密度は常に正だからである。

**系 C の証明.** S={p≤B} に対して Y_B(n)=Σ_{p∈S} 1_{p|F(n)} と置く。有限個の指示変数は自然密度の意味で独立であり、平均 μ_B=Σ_{p≤B}1/p、分散 σ_B²=Σ_{p≤B}(1/p)(1−1/p)≤μ_B。任意の固定 K に対して μ_B>K なら Chebyshev より

\[
\operatorname{dens}\{n:Y_B(n)\le K\}
\le\frac{\mu_B}{(\mu_B-K)^2}\xrightarrow[B\to\infty]{}0.
\]

\(\omega(F(n))\le K\) なら \(Y_B(n)\le K\)。ゆえにその上密度0。□

## 4. ユーザーの「括弧で拡張」着想の多項式族（完全パラメータ化）

**命題 4.** 整数係数多項式 P(x) が P(0)=0 と P(−1)=−1 を満たし、p≥7 が素数で P(p−1)>0 とすると、

\[
\boxed{p\mid45^{P(p-1)}+P(p-1)}.
\]

なぜなら n=P(p−1) は n≡P(0)=0 (mod p−1)、n≡P(−1)=−1 (mod p) を満たすため、フェルマーの小定理が使える。

さらに、こうした P は**すべて**次の形で表せる：

\[
\boxed{P(x)=x+x(x+1)Q(x),\quad Q(x)\in\mathbb Z[x].}
\]

証明：P(x)−x は x=0,−1 を根にもつ整数係数多項式だから、モニック多項式 x(x+1) で整数係数のまま割り切れる。逆は明らか。

- Q(x)=x−1 なら P(x)=x³、つまり n=(p−1)³。
- Q(x)=x なら P(x)=x³+x²+x。p=7 で n=258、7|F(258)。
- P(x)=(x+1)^k−1 はどの k≥1 でも条件を満たし、n=p^k−1 が再現される。

これは、多項式を使ったフェルマー由来の普遍的指数構成を1本の公式にまとめたもの。既存の定理に新規性を主張しているわけではない。

## 5. 2027 そのものから高い素数冪を作る

2027=45²+2 は素数で、ord_{2027}(45)=2026（2026=2·1013、45^1013 と 45² は2027を法として1にならない）。

n₁=2 は 2027|F(2)。補題1aの素数冪持ち上げにより n₂=4,106,704 では

\[
\boxed{2027^2\mid45^{4106704}+4106704}.
\]

さらに n₃=1,706,482,522,274 に対して 2027³|F(n₃)。いずれも任意精度整数の modular exponentiation で直接検算可能。計算は \(F(n)\) そのものを構成しない。

## 6. 隣接項の最大公約数

\[
F(n+k)-45^k F(n)=k-(45^k-1)n.
\]

従って

\[
\boxed{\gcd(F(n),F(n+k))\mid |k-(45^k-1)n|}.
\]

とくに \(\gcd(F(n),F(n+1))\mid44n-1\)。例として n=21 では gcd(F(21),F(22))=13。指数が離れた項同士の共通素因数を調べる際に利用できる。

## 7. 2つの大型候補と未解決事項

n=3878 は 2·7·277、n=9424 は 2⁴·19·31。\(\gcd(F(n),n)=\gcd(45^n,n)=3^{v_3(n)}5^{v_5(n)}\) だから、これらの指数自身の素因数で F(n) が割り切れることはない。

どちらの指数も今回の有限小素数によるチェックでは除外できないが、**どちらが素数であるかの厳密証明は今回得られていない**。

密度1の合成数という結果は、素数指数が有限か無限かについては結論を与えない。素数の分布を見積もる \(\sum 1/\log(F(n))\sim\log X/\log45\) は、あくまで確率的な発見的予想であり、証明ではない。
