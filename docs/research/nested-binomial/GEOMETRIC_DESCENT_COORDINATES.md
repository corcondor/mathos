# 3-isogeny公式の座標部分をLean検証

既存の還元 \(y^3-y=cr^3\)、\(x=-cr/y\)、\(z=c/y\) に対して、
古典的な公式

\[
X=\frac{x^3+4c^2}{x^2},\qquad
Z=\frac{z(x^3-8c^2)}{x^3}
\]

の座標等式を6定理に分け、DeepSeekが証明生成・修正し、実Leanで検証した。
`v10_formal/GeometricDescent.lean` が正確な型と証明の正本。

| 定理 | 検証した内容 |
| --- | --- |
| `mordellModel3_delta` | \(E'_c: Z^2=X^3-27c^2\) の判別式 \(-314928c^4\) |
| `mordellModel3_delta_ne_zero` | \(c\ne0\) なら判別式は非零 |
| `iso3_image_equation` | \(x\ne0\) の点の像が \(E'_c\) の式を満たす |
| `branch_image_coords` | 元の枝の像は \(X=(3y^2+1)/r^2\)、\(Z=(9y^2-1)/r^3\) |
| `branch_pell_relation` | \(Xr^2-3y^2=1\) |
| `branch_r_sq_relation` | \(r^2(3X-Zr)=4\) |

後半3定理の仮定は \(c,r,y\in\mathbb Q\)、\(c,r,y\ne0\)、\(y^3-y=cr^3\)。
元の研究分枝の非零条件とは整合するが、形式化したのは有理数上の座標等式まで。
「Pell型」という呼称から \(X\) の整数性を仮定してはならない。

群準同型性、次数3、核・双対の群スキーム、降下の完全性、Selmer群、階数、生成元、
全有理点は未検証。双対核が有理的に定義されることと、その点がすべて有理点であることも区別する。
これらの古典的公式を新しい数学的発見とは扱わず、元の方程式の全解決定や
30余因子最終定理の連分数仮定の除去を主張しない。

今回の依頼ではPR #1と固定コミットへのリンクに加え、既存の幾何学Leanソース、
v11ノートの本文、委任スキル、研究状態、参考リポジトリ要約をAPIへ実際に渡した。
High推論の最初の研究依頼は32,768トークンをすべて推論に使い、最終回答なしで上限到達。
未完として採用せず、前の応答を引き継いで上限65,536で続行したところ、
31.869秒、推論10,148トークンで提案が返った。
その提案の座標定理を固定して、証明生成と修正を1定理ずつDeepSeekへ依頼した。

定義欄の余分なnamespaceはホストが定理固定前に除去。証明本文は手作業で修正していない。
別のAPI呼び出しによるレビューは同じモデルによるもので、独立した外部監査ではない。
最終的な採用根拠はLeanの終了コードと公理依存の実検査。
