# v43：Mordell–Weil高さによる全切断の排除下限を8/3へ改善

2026-11-08。v38で得たK3二次基底変換 \(T=q^2-1=(p/b)^2-1\)、\(b\mid486\) の全幾何学的Mordell–Weil群の切断 \(P=mR+nH\) について、v41の \(13/6\)、v42の \(12/5\) をさらに改善する。ここでの高さは **関数体上の幾何学的切断のShioda高さ**であり、固定 \(T_0\) の個別Néron–Tate高さではない。元の四変数二項係数方程式は未解決である。

## 定理（全整数係数に対する統一高さ下限）

\[
\hat h(mR+nH)=\frac{(2m+n)^2+9n^2}{60},
\qquad m,n\in\mathbb Z.
\]
\(p>b>0\)、\(b\mid486\)、\(q=p/b\)、\(\rho=p^2-b^2\) をとる。

**定理：** \(\hat h(P)<8/3\) なら、\(P=mR+nH\) の特殊化は元の二項係数方程式の整数解に必要な
\[
a^2=b^2A(T)/X(P)\in\mathbb Z_{>0},\quad
a^2>p^2,\quad \gcd(a,b)=1,\quad
\rho\ge32770,\quad \rho\bmod9\in\{1,4,6,7\},\quad
\gcd(a,\rho)=\gcd(a,3)
\tag{43.1}
\]
を満たさない。従ってこれらの条件を満たす切断が存在するなら
\[
\boxed{\hat h(P)\ge8/3.}\tag{43.2}
\]

## 証明1：高さ球を完全に分類する

\(\hat h<8/3\) は
\[
(2m+n)^2+9n^2<160.
\tag{43.3}
\]
この式から \(|n|\le4\) が直ちに従い、各 \(n\) で許される整数 \(m\) は

| \(n\) | 許される \(m\) | 既存成果または新しい処理 |
|---:|---:|---|
| 0 | \(-6\le m\le6\) | v41と新しい \(6R\) |
| 1 | \(-6\le m\le5\) | v39/v40、v42の \(6R-H\) |
| -1 | \(-5\le m\le6\) | 符号対称 |
| 2 | \(-6\le m\le4\) | \((m+1)R+Q\)、v35〜v37 |
| -2 | \(-4\le m\le6\) | 符号対称 |
| 3 | \(-5\le m\le2\) | v41の負値判定、v42の二つの境界 |
| -3 | \(-2\le m\le5\) | 符号対称 |
| 4 | \(-3\le m\le-1\) | 今回の \(2Q,\,\pm R+2Q\) |
| -4 | \(1\le m\le3\) | 符号対称 |

\(n=4\) では \(4H=2R+2Q\) なので
\[
-3R+4H=-R+2Q,\quad
-2R+4H=2Q,\quad
-R+4H=R+2Q.
\]
従って新たに調べるべきは \(6R\) と \(2Q,R\pm2Q\) の4点だけである。

## 証明2：6Rは \(D\mid4000b^4\) で全排除

既存のv27の群法則から
\[
\frac A{X(6R)}=\frac{T(4T+3)}{3(T+32)}
\]
である。\(T=(p^2-b^2)/b^2\) として
\[
a^2=\frac{(p^2-b^2)(4p^2-b^2)}
{3(p^2+31b^2)}
=\frac{N}{3D},\quad D=p^2+31b^2.
\]
もし整数 \(a^2\) が存在すれば \(D\mid N\)。しかし直接の多項式恒等式
\[
\boxed{
N=D(4p^2-129b^2)+4000b^4
}\tag{43.4}
\]
により
\[
\boxed{D\mid4000b^4=2^5 5^3 b^4.}\tag{43.5}
\]
\(b=2^e3^f\)、\(e=0,1,\ f=0,\ldots,5\) の全てで、正約数候補は**4224個**。各 \(D\) から \(p^2=D-31b^2>b^2\) を復元すると整数 \(p\) は79件、整数 \(a^2\) は70件、完全平方は**0件**。よって \(P=\pm6R\) は全排除。

## 証明3：2Q, R+2Qは大きさだけで排除

第二楕円商の \(Q=(A/q^2,A(9T+8)/q^3)\) を2倍し、さらにRを加えると次を得る：
\[
\frac A{X(2Q)}
=\frac{4q^2(q^2-1)(4q^2-1)}
{(4q^2-q+1)(4q^2+q+1)},
\tag{43.6}
\]
\[
\frac A{X(R+2Q)}
=\frac{(q-1)^2(4q+1)^2}{8(q+1)(2q+1)}.
\tag{43.7}
\]
\(q>1\) に対して両者とも \(q^2\) より厳密に小さい。実際、
\[
\frac A{X(2Q)}-q^2
=-\frac{3q^2(3q-1)(3q+1)}
{(4q^2-q+1)(4q^2+q+1)}<0
\]
であり、
\[
\frac A{X(R+2Q)}-q^2
=-\frac{(3q+1)(16q^2-3q-1)}
{8(q+1)(2q+1)}<0.
\]
従って \(a^2>p^2\) の条件だけでこれらを全排除。

## 証明4：残る -R+2Q は780個の約数に有限化

\[
\frac A{X(-R+2Q)}
=\frac{(q+1)^2(4q-1)^2}{8(q-1)(2q-1)}
\]
なので
\[
\boxed{
a^2=\frac{(p+b)^2(4p-b)^2}{8(p-b)(2p-b)}.
}\tag{43.8}
\]
\(p>b\) で分母は正。もし整数 \(a^2\) が存在すれば、特に \(d=p-b>0\) は分子を割る。\(p\equiv b\pmod d\) を代入すれば
\[
\boxed{d\mid(2b)^2(3b)^2=36b^4.}\tag{43.9}
\]
\(36b^4=2^{2+4e}3^{2+4f}\) なので \(b\mid486\) の全12族で**780個の明示的な正約数候補**だけを検査すればよい。すべてで式(43.8)の分母は分子を割り切らず、**整数 \(a^2\) が0件**。よって全排除。\(\square\)
