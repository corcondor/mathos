# v32：5進衝突の全ケースに対する平方判定、零点の完全分類、Haar測度

2026-11-08 JST。**新規の研究対象**は既存v31の種数2補助曲線が与える「平方でなければならない」という**必要条件**であり、元の入れ子二項係数方程式の無解証明ではない。v31の「T≡13 (mod25)、d奇数」という未完の解析を、**全 T≡3 (mod5)** に拡張する。補助楕円曲線の巡回部分群 \(\langle R\rangle\) に属するという仮定は一切使わない。

## 記号

\[
S^2=F(a,b,\rho),\qquad b\mid486,\quad b>0,\quad \rho>0,\qquad
u=a/b\in\mathbb Z_5,\quad T=\rho/b^2\in\mathbb Z_5.
\]
\[
F=4a^6+(24b^2-12\rho)a^4+(36b^4+60b^2\rho+12\rho^2)a^2-3b^2\rho^2-4\rho^3.
\]

\(5\nmid b\) なので \(F/b^6=f(u,T)\) は \(F\) と同じ5進平方類を持ち、
\[
\boxed{ f(u,T)=H^2+4z^3 },\quad
H=6u^2+2+3T,\quad z=u^2-1-T,\quad
D=8+9T,\quad H=6z+D.
\tag{32.1}
\]
また \(\chi(x)\in\{+1,-1\}\) を5進単元の法5における平方指標とし、\(0\) は平方の集合に含めて考える（零点自体は別に分類する）。

\(T\equiv3\pmod5\) と仮定し、
\[
k=v_5(4T+3),\quad d=v_5(9T+8).
\]
両方とも1以上で、
\[
(9T+8)-(4T+3)=5(T+1),\quad T+1\equiv4\pmod5
\quad\Longrightarrow\quad\boxed{\min(k,d)=1}.
\tag{32.2}
\]
従って \(k=1\) と \(d=1,k\ge2\) を調べれば **全て** の5進衝突を扱える。\(k=d=1\) のgeneric caseは前者に含む。\(T>0\) なので \(4T+3\ne0,\ 9T+8\ne0\)。

基本的な法5恒等式：
\[
f(u,T)\equiv-u^2(u^2+1)^2\pmod5.
\tag{32.3}
\]
\(u\equiv\pm1\pmod5\) では常に5進平方。\(u\equiv\pm2\pmod5\) では \(5\mid z,H\)。

## 定理A：k=1の完全な局所解析（generic caseを含む）

\(k=1\)、従って \(d\ge1\) とする。

1. \(u\equiv0\pmod5\) なら \(v_5(f)=1\)、従って非平方。
2. \(u\equiv\pm1\pmod5\) なら常に平方。
3. \(u\equiv\pm2\pmod5\) について、\(d\) が奇数なら
   \[
   \boxed{f(u,T)\in(\mathbb Q_5^\times)^2
   \iff v_5(H)<h=(3d+1)/2.}\tag{32.4}
   \]
   特に \(d=1\) （\(k=d=1\)、\(T\bmod25=3,8,23\)）は
   \[
   \boxed{5\nmid a,\quad25\nmid(6a^2+2b^2+3\rho)}
   \tag{32.5}
   \]
   が5進平方性の**必要十分条件**。
4. \(d=2e\) が偶数なら \(h=3e\) として、\(u\equiv\pm2\pmod5\) で
   - \(v_5(H)<h\) のとき常に平方。
   - \(v_5(H)>h\) のとき、\(\chi(q)=+1\) と平方性が同値。ここで
     \[
     q\equiv-\frac{D}{5^{2e}}\cdot6^{-1}\pmod5.
     \tag{32.6}
     \]
   - \(v_5(H)=h\) のとき \(z/5^{2e}\in\mathbb Z_5^\times\) とおき、
     \[
     \boxed{
     f/5^{6e}=(H/5^{3e})^2+4(z/5^{2e})^3
     }\tag{32.7}
     \]
     が5進平方かどうかで正確に決まる。零点に近い場合は任意に深い桁が必要になる。

**証明**：定数項 \(-T^2(4T+3)\) の付値は1で、\(u^2\) の係数 \(12(T^2+5T+3)\equiv4\pmod5\) は単元なので (1)。\(u\equiv\pm1\) は式(32.3)。残りは \(z=(H-D)/6\) の付値を見る。\(v_5(z)\ne d\) なら \(v_5(H)=\min\{v_5(z),d\}\) で \(2v_5(H)<3v_5(z)\)、よって \(f=H^2(1+5\mathbb Z_5)\) が平方。\(v_5(z)=d\) なら \(v_5(H)\ge d\) で、\(2v_5(H)\) と \(3d\) の最小付値を比較する。奇数 \(d\) では等号が起こらず (32.4) が従う。偶数 \(d=2e\) では境界 \(v_5(H)=3e\) のみ両項が同じ付値を持ち、式(32.7) になる。\(v_5(H)>3e\) では単元 \(z/5^{2e}\equiv q\pmod5\) の平方指標で判定できる。

## 定理B：d=1, k≥2の完全な局所解析

これはv31で未完だった \(T\equiv18\pmod{25}\) の全ケースに当たる。

1. \(u\equiv\pm1\pmod5\) なら常に平方。
2. \(u\equiv\pm2\pmod5\) なら
   \[
   \boxed{f\text{ が5進平方}\iff25\nmid(6a^2+2b^2+3\rho).}\tag{32.8}
   \]
   従って **\(5\nmid a\) 全体**について式(32.8) が必要十分条件となり、20個の単元剰余類 \(a\bmod25\) のうち **18個** が平方条件を満たす。
3. \(5\mid a\) とし \(s=v_5(a)=v_5(u)\ge1\)。
   - \(2s<k\) なら常に平方。
   - \(2s>k\) なら、\(k\) が偶数かつ \(\chi((4T+3)/5^k)=+1\) のとき、かつそのときのみ平方。
   - \(2s=k=2e\) なら \(w=u/5^e\in\mathbb Z_5^\times,\ q=(4T+3)/5^{2e}\) に対し、
     \[
     \boxed{
     \frac{f(5^ew,T)}{5^{2e}}=
     4\cdot5^{4e}w^6+(24-12T)5^{2e}w^4
     +12(T^2+5T+3)w^2-T^2q
     \equiv4w^2+q\pmod5.
     }\tag{32.9}
     \]
     この縮約多項式の5進平方性が正確な判定。特に \(\chi(q)=-1\) のときは単なる法5判定で済む。\(\chi(q)=+1\) のときは2つの単純零点近傍で追加の桁が必要。

**証明**：\(d=1\) なので \(v_5(D)=1\)。\(u\equiv\pm2\) では \(5\mid H,z\)。もし \(v_5(H)=1\) なら \(v_5(H^2)=2<3v_5(z)\) で平方。もし \(v_5(H)\ge2\) なら \(v_5(z)=1\) なので \(v_5(f)=3\) で非平方。\(u\equiv\pm1\) は式(32.3)で平方なので (32.8) が全単元 \(a\) に成立。\(5\mid a\) では \(u^2\) 項の係数が法5で4、定数項の付値が \(k\)、\(u^4,u^6\) の付値はそれぞれ4s、6s以上。従って \(2s\ne k\) は主項の付値と平方指標から結論。等号 \(k=2e\) で直接代入すると (32.9)。

## 定理C：5進零点は正確に0・2・4個

\(f_T(u)=f(u,T)\) の \(\mathbb Z_5\) 内の零点を数える。

| 互いに素なケース | 条件 | \(\mathbb Z_5\) 内の零点数 |
|:--|:--|--:|
| \(k=1\), \(d\) 奇数（\(d=1\) も含む） | 全て | **0** |
| \(k=1\), \(d=2e\) | \(\chi(-D/5^{2e})=-1\) | **0** |
| \(k=1\), \(d=2e\) | \(\chi(-D/5^{2e})=+1\) | **4** |
| \(d=1\), \(k=2e+1\ge3\) | 全て | **0** |
| \(d=1\), \(k=2e\ge2\) | \(\chi((4T+3)/5^{2e})=-1\) | **0** |
| \(d=1\), \(k=2e\ge2\) | \(\chi((4T+3)/5^{2e})=+1\) | **2** |

全ての零点は**単純零点**である。

**証明**：定理A・Bで付値が厳密に異なる領域では \(f\ne0\)。定理Aの偶数 \(d=2e\) で零点候補は \(H=5^{3e}w\)。\(D=5^{2e}D_0\) とすると
\[
\frac{f}{5^{6e}}=
G(w)=w^2+\frac{(5^e w-D_0)^3}{54}
\equiv w^2+4q^3\pmod5.
\tag{32.10}
\]
ここで \(H(u)=6u^2+2+3T\) の導関数 \(12u\) は \(u\equiv\pm2\pmod5\) で単元。各々の根球は \(H\) を局所座標にできる。\(\chi(q)=+1\) のとき \(G\bmod5\) は非零で互いに異なる2根 \(w\) を持ち、\(G'(w)\equiv2w\ne0\pmod5\) なのでHenselにより各 \(u\)-球に2根、計4根。\(\chi(q)=-1\) なら \(w\) は根を持たない。定理Bの偶数 \(k=2e\) では縮約多項式 (32.9) の法5根は \(w^2=q\) なので、\(q\) が平方単元の場合ちょうど2つ、導関数は \(8w\ne0\pmod5\)。奇数 \(k,d\) では付値の奇偶から零点が存在しない。

### 系：固定の法 \(5^N\) だけで平方性を完全判定できる場合／できない場合

上表で零点が**存在しない**場合、平方判定は \(u\bmod5^N\) の有限表に落とせる。具体的には
\[
\begin{array}{c|c}
\text{場合} & \text{十分な指数 }N\\ \hline
k=1,\ d\text{ odd} &(3d+1)/2\\
k=1,\ d=2e,\ \chi(-D/5^d)=-1 &3e+1\\
d=1,\ k=2e+1\ge3&\max(2,e+1)\\
d=1,\ k=2e\ge2,\ \chi((4T+3)/5^k)=-1&\max(2,e+1)
\end{array}
\]

一方で上表の **2根または4根の場合、どんな有限の \(N\) でも、\(u\bmod5^N\) だけから5進平方性を全整数 \(u\) に対して完全判定することはできない**。単純零点 \(u_0\) に任意に近く、\(f(u)\) が平方になる点と非平方になる点がともに存在するためである。これは「法を大きくするだけで局所探索が終わる」とは限らない理由を厳密に説明する。

## 定理D：平方性を満たすaの5進Haar密度の閉形式

固定の \(T\) に対して
\[
\mu(T)=\operatorname{Haar}\{u\in\mathbb Z_5:f(u,T)\in(\mathbb Q_5)^2\}.
\]
\(b\) が5進単元なので、\(a\) の密度も同じ。零点は測度0。

| ケース | 厳密な密度 \(\mu(T)\) |
|:--|:--|
| \(k=1,\ d\) odd, \(h=(3d+1)/2\) | \(\displaystyle\frac45-\frac2{5^h}\) |
| \(k=1,\ d=2e,\ \chi(-D/5^d)=-1\) | \(\displaystyle\frac45-\frac6{5^{3e+1}}\) |
| \(k=1,\ d=2e,\ \chi(-D/5^d)=+1\) | \(\displaystyle\frac45-\frac{23}{15\cdot5^{3e}}\) |
| \(d=1,\ k=2e+1\ge3\) | \(\displaystyle\frac{23}{25}-\frac1{5^{e+1}}\) |
| \(d=1,\ k=2e\ge2,\ \chi((4T+3)/5^k)=-1\) | \(\displaystyle\frac{23}{25}-\frac3{5^{e+1}}\) |
| \(d=1,\ k=2e\ge2,\ \chi((4T+3)/5^k)=+1\) | \(\displaystyle\frac{23}{25}-\frac{23}{6\cdot5^{e+1}}\) |

**証明**：法5で \(u\equiv\pm1\) の2球は常に平方。\(k=1\) の場合 \(u\equiv0\) は非平方で、\(u\equiv\pm2\) の2球では \(H(u)\) の導関数が単元なので \(H\) は \(5\mathbb Z_5\) にHaar測度を保つ局所座標を与える。奇数dでは失敗領域は \(H\in5^h\mathbb Z_5\) のみ。偶数dでは \(H\in5^{3e}\mathbb Z_5\) の残りの単元多項式が平方になる割合を法5で数える。\(\chi(q)=-1\) なら5つの残基のうち2つが平方。\(\chi(q)=+1\) なら1つが平方・2つが非平方・2つが単純零点。単純零点の1球の内部で多項式が平方となる割合は、正規化Haarに対し \(\operatorname{Haar}((\mathbb Q_5)^2\cap5\mathbb Z_5\mid5\mathbb Z_5)=1/12\)。ゆえに後者の条件付き割合は \((1+2/12)/5=7/30\)。以上を足すと上の初めの3式。

\(d=1,k\ge2\) では \(5\nmid u\) の平方率は \(18/25\)。\(5\mid u\) の球は \(s=v_5(u)\) ごとに分割。\(k=2e+1\) なら \(1\le s\le e\) が必要十分。\(k=2e\)、非平方 \(q\) の場合は \(s<e\) を全採用し、\(s=e\) の4つの単元残基の2つのみ採用。平方 \(q\) なら \(s<e\) 全採用、\(s>e\) 全採用、\(s=e\) では4つの単元残基の2つが単純零点近傍でそれぞれ \(1/12\) の割合で採用。従って \(s=e\) の条件付き率は \(1/24\)。\(v_5(u)\) の幾何級数を合計すると後の3式。

### 明示的な残差例：完全な法25の整数条件

\(b=1,\ \rho=T=32793\) は \(\rho\ge32770\)、\(\rho\equiv6\pmod9\)、\(T\equiv18\pmod{25}\) を満たす。\(\ k=v_5(4T+3)=2\)、\(q=(4T+3)/25\equiv2\pmod5\) は非平方なので、定理BとCから平方性は **\(a\bmod25\) だけ**で判定できる。

\[
\boxed{F(a,1,32793)\in\mathbb Q_5^{\,2}
\iff a\not\equiv0,7,10,15,18\pmod{25}.}\tag{32.11}
\]

**証明**：\(5\nmid a\) では \(H=6a^2+2+3T\equiv6(a^2+1)\pmod{25}\) なので、非平方は \(a\equiv\pm7\pmod{25}\) のみ。\(5\mid a\) では \(s=1=k/2\) であり、\(4(a/5)^2+2\) が平方となるのは \(a/5\equiv\pm1\pmod5\)、すなわち \(a\equiv5,20\pmod{25}\)。したがって残る3つ \(a\equiv0,10,15\) も排除。これは**特定の \(\rho\) に対する必要条件**であり、元の二項係数方程式の解を発見したわけではない。

- [v32_rational_T_audit.py](v32_rational_T_audit.py) は、実際の \(T=\rho/b^2\notin\mathbb Z\) も検査。\(b=2,3,486\)、\(\rho\ge32770\)、\(\rho\bmod9\in\{1,4,6,7\}\) を満たす32種類の \((b,\rho)\) の各3125剰余、計100,000件で元の六次式と正規化した判定が全一致。v32の数値検算は **287,500 + 100,000 = 387,500件**。
- 完全証明は上記の記述証明と既知のHensel補題・5進平方単元判定に依存する。現時点では**Lean形式証明ではなく、外部査読も受けていない**。
- ゼロ根の分類とHaar密度は \(\mathbb Z_5\) 上の局所現象であり、**元方程式の全整数点・有理解の不存在を主張しない**。
- v33の有力課題：根がないケースでは、上の有限指数 \(N\) による完全な局所剰余表を他素数の条件とCRT結合する。根のあるケースでは、無限の法増大ではなく、単純根近傍の5進解析とMordell–Weil認証を別個に扱う。
