# v17：平方根境界の完全分類と、主添字・二次式の素因数制限

2026年11月6日 JST。

## 今回の到達点

対象は引き続き、上下の添字を二乗する元の方程式

\[
\binom{\binom ij}{\binom{k}{\ell}}
=\binom{i^2}{j^2}+\binom{k^2}{\ell^2}
\]

の **\(\ell=1,\ j=i-3\)** の枝です。

\[
n=i,\quad A=\binom n3,\quad B=\binom{n^2}{6n-9},
\quad r=\min(k,A-k),\quad t=r-3n,\quad m=6n-9,
\]

\[
M=\gcd(n,3)\gcd(n-1,6),\qquad Q=\frac{n(n-1)}M,
\qquad\delta=\frac{Q}{\gcd(Q,r^2)}
\]

とします。両分岐 \(k=r\)、\(k=A-r\) を扱い、既存の
\(n\ge104\)、\(3n<r<10n/3\)、\(Q\mid r^3\) を入力とします。
\(P^+(u)\) は正整数 \(u>1\) の最大素因数です。

| 項目 | v17で得た必要条件・分類 |
|---|---|
| 平方根境界 | **\(r>3n+3\sqrt n\)**。旧整除条件の等号例は正確に13組で、元式の両分岐26件を全排除 |
| 整数残差からの追加下限 | **\(h\ge93M\)**、**\(r-3n+3>\sqrt{31n/3}\)** |
| 主添字の素因数 | **\(P^+(n)<3\sqrt n\)**、**\(P^+(n-1)^2\le6n-9\)** |
| \(n^2+2\) の補因子 | すべての素因数 \(p\) で **\((n^2+2)/p\ge65\)** |
| 複数の二次式の反復素因数 | 適用可能な最大12式に同時制限。\(p^2>m\) の反復素数は補分岐・指数3に限られ、全式を合わせて高々4素数 |
| 正の二次式の全指数 | \(n\equiv3\pmod6\) なら **\(n^2+1\mid\operatorname{lcm}(1,\ldots,m)^2\)** |

元の四変数方程式およびこの枝全体の解決、具体解の発見には至っていません。
今回の成果は記述証明と完全な整数証明書、その別実装による監査です。

## 1. 平方根境界を完全に分類

旧必要条件だけから

\[
\boxed{(r-3n)^2\ge9n}
\]

を示しました。等号は

\[
n=s^2,\qquad r=3s(s+1)
\]

の形で、正確に

\[
\boxed{s\in\{13,19,25,28,37,55,73,82,109,163,217,325,649\}}
\]

の13組です。このリストは元方程式の解のリストではありません。

### 有限化の理由

v16の正整数

\[
h=\frac{M\{(9t^2+27t+27)n+t^3\}}{n(n-1)}
\]

を使います。\(h/(81M)=a/b\) を既約分数にすると、
分母は \(b\mid486\) の12種類しかありません。
v16の平方根近似の正の残差をさらに正規化した整数 \(j_*\) は

\[
0<j_*<\frac{216a^2+760b^2}{1377},
\qquad j_*\equiv a^2\pmod b
\]

を満たします。ここで \(j_*\) は元の二項係数の添字とは別物です。
各 \((a,b,j_*)\) から、二次方程式で \(t\)、有理式で \(n\) を復元でき、
逆に元の必要条件へ戻るための整除・整数条件も証明しました。

\(t\le3\sqrt n\) なら

\[
\frac hM\le81+\frac{108}{\sqrt n-1}<93,
\qquad27a<31b.
\]

従って、\(n\) に探索上限を置かずに全候補が有限化されます。

| 完全検証の段階 | 生成器と独立実装で一致した件数 |
|---|---:|
| 既約係数対 \((a,b)\) | 557 |
| 正の整数残差 | 94,710 |
| 平方判別式 | 272 |
| 復元した整数 \(t\ge4\) | 30 |
| 復元した整数 \(n\ge104\) | 13 |
| \(t^2<9n\) | 0 |
| \(t^2=9n\) | 13 |
| 元の両 \(k\) 分岐を合同式で排除 | 26 |

独立監査は生成器を呼ばず、\(M=6\) へ換算した整数変数と生の残差から
別の二次式を作って全域を再計算しています。全残差の分類・両根・元式の剰余が一致しました。

等号の場合は、別途

\[
s-1\mid324\gcd(s-1,2)
\]

だけで13組を初等的に分類できます。
それぞれの \(k=r,A-r\) は13以下の素数を法として元式の左右が一致しません。
24件は両二項係数がゼロになる型、\(n=5329\) の2件は内側が法5で3となる型です。
全剰余を記録しているため、v16の \(\delta\le12\) 排除を使わなくても26件を除外できます。

### 同じ有限域から得られた追加の系

復元時に \(t^2\le9n\) をフィルタとして用いていません。
つまり、\(h/M<93\) の全必要候補がこの13組であり、元式ではすべて排除されます。
従って

\[
\boxed{h\ge93M}
\]

が必要です。\(u=t+3\) とすると、さらに

\[
\boxed{u>\sqrt{31n/3}}
\]

が得られます。証明は短く、\(h<4Mt\) から \(u\ge27\)。
仮に \(u^2\le31n/3\) なら、

\[
\begin{aligned}
&(9u^2-27u+27)n+(u-3)^3-93n(n-1)\\
&\quad\le n(120-50u/3)-9u^2+27u-27<0,
\end{aligned}
\]

となり \(h\ge93M\) に矛盾します。

なお旧必要条件だけでは \(h>81M\) が鋭く、
\((n,r,M,h)=(421201,1265550,6,487)\) は \(h=81M+1\) を達成します。
これは \(\delta=6\) の補助例で、元式の解ではありません。

## 2. 主添字の大きな素因数を排除

この枝のすべての解に対して

\[
\boxed{P^+(n)<3\sqrt n,\qquad P^+(n-1)^2\le6n-9}
\]

を証明しました。\(n\not\equiv2\pmod3\) なら、第一式も
\(P^+(n)^2\le6n-9\) に強まります。

### \(n-1\) の証明の中心

\(p\mid n-1\)、\(p^2>m\) と仮定して \(n=pw+1\) と書くと、
\(p\ge29\)、\(p>6w\) です。\(Q\mid r^3\) により \(r=pv\) と書けます。

外側は \(A=p\alpha\) として、\(\alpha\) の法 \(p\) の剰余を調べると

\[
v_p\binom Ar\in\{0,1\}
\]

に限られます。一方、内側の階乗の付値では、\(p\) と \(p^2\) の段で
それぞれ1回、以後は0回の繰り上がりがあり、

\[
v_p(B)=2.
\]

さらに \(p\mid A,r\) なので両分岐で \(p^2\mid k^2\) です。
元の等式の右辺は \(p^2\) で割れ、左辺の付値は0か1なので矛盾します。

\(n\) 側も同じ方針で、もし \(p\mid n\)、\(p^2>m\) なら

\[
\boxed{n\equiv2\pmod3,\quad n=pw,\quad6w<p<9w,
\quad p\mid3w^2+2}
\]

が必要です。これから \(p^2<9n\) が従います。
素数の大きさを順に試す計算による結論ではなく、全素数に量化された付値の証明です。

## 3. 複数の二次式を同時に制限

\[
\mathcal C=\{2,3,5,6,7,8,10,11,12,13,14,15\}
\]

のうち \(6\mid(c+2)n-3c\) を満たす \(c\) を対象とします。
\(a_c=((c+2)n-3c)/6\) とおくと、

\[
A-a_c=\frac{(n-3)(n^2-c)}6
\]

です。この同じ形の因数分解を用いて、v16の \(c=10\) の結果を全12種類へ広げました。

\[
p^2\mid n^2-c,\quad p^2>m
\]

なら、必ず

\[
\boxed{k=A-r,\qquad v_p(n^2-c)=3,
\qquad v_p(r-a_c)=1}
\]

となります。例外処理は118個の定数から導いた69組の法 \(p^2\) の根表に限定され、
全根を別々の方法で取得して一致を確認しました。最後の \(n=149,157,275,5382\) も
旧整除条件だけで排除されます。

また、この種の素数の積を \(P\) とすると

\[
P\mid k,\quad\gcd(P,Q)=1,\quad Q\mid(k/P)^3,
\quad P^3<\frac{n^7}{35}.
\]

5素数あれば \(P^3>m^{15/2}\) となって矛盾するため、
**適用可能な全二次式を合わせても高々4素数**です。
同じ素数が異なる二次式に重複して数えられることもありません。
従って \(n\equiv3\pmod6\) なら、12式のうち少なくとも8式には、
\(p^2>m\) を満たす反復素因数が存在できません。
これはそれらの整数全体が平方自由だという主張ではありません。

### 全指数を扱う共通の合同補題

\(L_m=\operatorname{lcm}(1,\ldots,m)\) とします。
\(p^e\mid U\)、\(1\le j\le m\) のとき、
\(j\binom Uj=U\binom{U-1}{j-1}\) から
\(p^{e-\lfloor\log_p m\rfloor}\mid\binom Uj\) が得られます
（正の指数の場合）。Vandermondeの恒等式を通して、両二項係数へ適用できます。

その結果、\(n\equiv3\pmod6\) なら

\[
\boxed{n^2+1\mid L_m^2}
\]

が必要です。すなわち全素数について

\[
v_p(n^2+1)\le2\lfloor\log_p m\rfloor.
\]

特に \(p^2\mid n^2+1\)、\(p^2>m\) なら、指数は正確に2です。
負の二次式の指数3と異なる振る舞いが現れます。
さらに \(p^e\parallel n^2+1\) の指数 \(e\) が奇数なら、
\(w=(n^2+1)/p^e\) に対し **\(p<36w\)** が必要です。全指数を扱う制限です。

負側の全二次式についても、\(N_c=n^2-c\) として

\[
\mathcal R=\prod_{c\in\mathcal C(n)}
\left(\frac{N_c}{\gcd(N_c,L_m)}\right)_{[\ge17]}
\]

を定めると、

\[
\boxed{\mathcal R\mid k^2,\qquad\mathcal R^3Q^2\mid k^6}
\]

が成り立ちます。添字 \([\ge17]\) は17以上の素数の部分だけを残す意味です。
小さい分岐では **\(\mathcal R<(225n)^{2/3}\)** となり、各式を個別に見るよりも
強い、素数冪の過剰部分の同時制限になります。

詳細：[主添字と二次式の全証明](v17_quadratic_prime_powers.md)、
[完全例外表と支持検算](v17_quadratic_prime_powers_checks.json)、
[別実装の監査](v17_quadratic_independent_audit.json)。

## 4. \(n^2+2\) の小さい補因子をまとめて排除

任意の素因数 \(p\mid n^2+2\) に対し \(w=(n^2+2)/p\) とおくと、

\[
\boxed{w\ge65,\qquad P^+(n^2+2)\le\frac{n^2+2}{65}}
\]

が必要になりました。

\(p>m\) のとき、\(\varepsilon=0,1\) で二つの分岐を表すと

\[
z=\frac{(r-\varepsilon)^2-6n+8}{p}\in\mathbb Z,
\qquad9w<z<100w/9.
\]

さらに

\[
c_0=2z-(8+\varepsilon^2)w,\quad
c_1=3z-(2+\varepsilon^2)w
\]

を使い、\(n/\gcd(n,3)\mid c_0^3\)、
\((n-1)/\gcd(n-1,6)\mid c_1^3\) へ帰着します。
\(w\le64\) を固定した全範囲では、\(n\) はこれらの小さい明示整数の約数から
漏れなく生成できます。

| 段階 | 生成器と別実装で一致 |
|---|---:|
| \((w,z,\varepsilon)\) の係数族 | 8,712 |
| 約数から生成した点 | 590,028 |
| 第二整除条件を通過 | 1,260 |
| 整数 \(p=(n^2+2)/w>m\) | 11 |
| \((r-\varepsilon)^2\) を平方数として復元できるもの | 0 |

最後の11件はすべて連続する平方数の間にあります。
ここでは \(p\) の素数性も課さず、より広い必要候補集合を全排除しています。
生成された最大の \(n\) は1,816,487,208ですが、これは約数として出てきた候補です。
その整数まで順に走査したわけではありません。

\(p\le m\) の側は理論的に \(n<6w\le384\) となり、残る4組の実際の
\(\delta\) は1,1,5,1なので、v16の \(\delta\ge13\) によりすべて排除されます。

### v16の \(\delta\) と、別の整数差 \(J\) も接続

同じ係数に対し、全素数で

\[
\begin{array}{ll}
Q/\delta\mid c_0c_1,&k=r,\\
Q/\delta\mid(c_0c_1)^2,&k=A-r
\end{array}
\]

が成り立ち、

\[
\boxed{n<52\sqrt\delta\,w+1\quad(k=r)},
\qquad
\boxed{n<983\sqrt\delta\,w^2+1\quad(k=A-r)}
\]

を得ました。\(\delta\) が小さい領域で使える追加の制約です。

\(p>m\) の場合、\(J=z-9w\) は正整数です。小さい分岐 \(k=r\) では、
v16の五分の三の下限と組み合わせて

\[
\boxed{n^4<2^{150}J^{15},\qquad w^2<2^{40}J^5}
\]

という固定 \(J\) ごとの多項式の高さを得ました。
\(J\) 全体に上限を付けたわけではなく、この高さを補分岐へ適用することもしていません。

[圧縮した全証明書](v17_neighbor_cofactor_certificate.json.gz)、

## 5. 幾何学との接続

平方根境界の残差を変数変換すると、各固定 \((a,b)\) に対して

\[
Y^2=X^3-3b^2(72a^2+b^2)X
+2b^2(648a^4+180a^2b^2-b^4)
\]

が現れます。判別式は

\[
-995328a^2b^4(3a-b)^3(3a+b)^3
\]

で、正の既約係数では \((a,b)=(1,3)\) だけが特異です。
この例外も計算から捨てず、残差条件で処理しました。
それ以外は有理数体上の楕円曲線です。
標準的なWeierstrass形と判別式の判定は
[mathlibの公式定義](https://leanprover-community.github.io/mathlib4_docs/Mathlib/AlgebraicGeometry/EllipticCurve/Weierstrass.html)
に対応します。

今回は全整数点ソルバーに完全性を委ねず、先に証明した残差の有限範囲を尽くしています。
任意の固定 \(a\) には12分母だけが対応し、\(n\) に \(a\) の五次式の上限が付くことも示しました。
曲線の式だけを満たす点を、元の二項係数方程式の解とは扱いません。
