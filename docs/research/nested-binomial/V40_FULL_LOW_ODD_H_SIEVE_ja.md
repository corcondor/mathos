# v40：二次基底変換で奇数H係数 ±1 の全 |m|≤5 を無制限パラメータで排除

2026-11-08。元の入れ子二項係数方程式の \(\ell=1,\ j=i-3\) 枝から得た必要条件の研究。v38で幾何学的群
\(E_{q^2-1}(\overline{\mathbb Q}(q))=\mathbb ZR\oplus\mathbb ZH\)
が決定され、v39では \(|m|\le2\) の \(mR\pm H\) だけを排除した。本稿は \(|m|=3,4,5\) を追加し、**係数 \(m\) のこの固定範囲では、\(p,\rho\) の上限に依存しない完全排除**を得る。特殊化後の全有理点や元の四変数方程式全体は未解決。

## 定理

\[
q=p/b>1,\quad T=q^2-1=\rho/b^2,\quad
p,b\in\mathbb Z_{>0},\quad b\mid486,\quad \rho=p^2-b^2
\]
として、v38の \(E_T,R,H\) を取る。元問題の整数解が \(P=mR\pm H\) に射影されるなら
\[
a^2=b^2\frac{A(T)}{X(P)}\in\mathbb Z_{>0},\quad
a^2>p^2,\quad \gcd(a,b)=1,\quad
\rho\ge32770,\quad \rho\bmod9\in\{1,4,6,7\},\quad
\gcd(a,\rho)=\gcd(a,3)
\tag{40.1}
\]
が必要である。

**主張：** 任意の \(m\in\mathbb Z,\ |m|\le5\) と符号 \(\pm\) について、\(P=mR\pm H\) から(40.1)を満たす整数 \(a,p,b,\rho\) は生じない。

## 1. 新しい6種類の群法則

\(X(-P)=X(P)\) を利用して \(m=3,4,5\) と \(\pm H\) だけ考えればよい。加法公式から、\(a^2/b^2=A/X(P)\) は：

| \(P\) | 正確な復元式 |
|---|---|
| \(3R+H\) | \(\dfrac{(q+1)^2(2q+1)}{2(q+13)}\) |
| \(3R-H\) | \(\dfrac{(q-1)(q+1)(2q+1)}{2(q-7)}\) |
| \(4R+H\) | \(\dfrac{(q+1)(q+3)^2(2q-1)}{2(q^2+20q-29)}\) |
| \(4R-H\) | \(\dfrac{(q-1)^2(2q-1)}{2(q-13)}\) |
| \(5R+H\) | \(\dfrac{(q-1)(q+7)^2(2q+1)}{2(q^2+30q-79)}\) |
| \(5R-H\) | \(\dfrac{(q-3)^2(q-1)(2q+1)}{2(q^2-20q-29)}\) |

これらはSymPyの有理群法則により、分子・分母を正確に因数分解して再確認した。

## 2. 各枝の構造的な排除

### 3R+Hは不等式だけ

\[
\frac A{X(3R+H)}-q^2
=-\frac{(3q-1)(7q+1)}{2(q+13)}<0\quad(q>1).
\]
従って \(a^2>p^2\) に反する。

### 3R-H：\(d\mid720b^3\)

正の復元値が必要なら \(q>7\)。\(d=p-7b>0\) と置くと
\[
a^2=\frac{(p^2-b^2)(2p+b)}{2d}.
\]
整数性から \(d\mid(p^2-b^2)(2p+b)\)。\(p\equiv7b\pmod d\) なので
\[
\boxed{d\mid720b^3=2^4\,3^2\,5\,b^3.}\tag{40.2}
\]
\(b=2^e3^f\)、\(e\in\{0,1\},\,0\le f\le5\) を全て含めて**1638個**の正約数候補となる。1260件で \(a^2\) が整数、**完全平方は0件**。

### 4R+H：\(b<p<3b\)

復元値の正値条件 \(q^2+20q-29>0\) と
\[
\frac A{X(4R+H)}-q^2
=-\frac{3(q-3)(3q-1)(3q+1)}{2(q^2+20q-29)}
\]
の組合せから、必要条件は \(1<q<3\)。従って \(b<p<3b\)、\(b\mid486\) の有限区間だけを厳密検査すればよい。分母正・\(a^2>p^2\) を満たす**1788候補**で、整数 \(a^2\) は19件、平方は0件。

### 4R-H：\(d\mid3600b^3\)

\(q>13\)、\(d=p-13b\) と置けば
\[
a^2=\frac{(p-b)^2(2p-b)}{2d},\qquad
\boxed{d\mid3600b^3.}\tag{40.3}
\]
\(3600=2^4\,3^2\,5^2\) なので**2457正約数候補**。1890件で \(a^2\) が整数、57件で平方。さらに(40.1)の \(\rho\ge32770,\ \gcd(a,b)=1,\ \rho\bmod9\in\{1,4,6,7\}\) を課すと2件のみ：
\[
(b,p,a,\rho)=(9,317,385,100408),\quad(18,298,595,88480).
\]
しかし前者は \(\gcd(385,100408)=77\ne1=\gcd(385,3)\)、後者も
\(\gcd(595,88480)=35\ne1=\gcd(595,3)\)。従って全排除。

### 5R+H：\(b<p<7b\)

正の復元値には \(q^2+30q-79>0\) が必要で、
\[
\frac A{X(5R+H)}-q^2
=-\frac{(q-7)(3q+1)(11q-7)}{2(q^2+30q-79)}.
\]
必要条件 \(1<q<7\) を得る。この有限区間で正値・厳密不等式を満たす**4980候補**のうち整数 \(a^2\) は44件、平方は10件。しかし(40.1)の残差下限・\(\gcd(a,b)=1\)・法9を全て満たすものは0件。

### 5R-H：Bézout恒等式から \(D\mid19200b^5\)

正の復元値には \(D=p^2-20pb-29b^2>0\) が必要で
\[
a^2=\frac{N}{2D},\quad N=(p-3b)^2(p-b)(2p+b).
\]
もし \(a\in\mathbb Z\) なら \(D\mid N\)。直接の多項式恒等式
\[
\boxed{N=D(2p^2+27pb+621b^2)+1200b^3(11p+15b)}\tag{40.4}
\]
と
\[
\boxed{121D=(11p-235b)(11p+15b)+16b^2}\tag{40.5}
\]
を組み合わせると、\(D\) は
\[
\boxed{D\mid19200b^5=2^8\,3\,5^2\,b^5}\tag{40.6}
\]
を満たす。ここが二次分母を**無限の \(p\) を含めて有限化する証明**の核である。

\(b=2^e3^f\) と(40.6)により、\(D=2^i3^j5^k\) は全b合わせて**6003候補**。方程式
\[
p^2-20pb-29b^2=D\quad\iff\quad
p=10b+\sqrt{129b^2+D}
\]
で整数 \(p\) に戻せるのは119件。そのうち整数 \(a^2\) は86件、平方は12件。平方となるものは、検査結果で全て \((p,a)=(37b,51b)\)、\(b\mid486\) の12種類に限られ、
\[
\rho=(37^2-1)b^2=1368b^2\equiv0\pmod9
\]
なので(40.1)に反する。
