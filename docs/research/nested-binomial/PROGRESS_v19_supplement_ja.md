## 2. 消去イデアルから得た新しい整除式

\[
n=i,\quad A=\binom n3,\quad r=\min(k,A-k),\quad
M=\gcd(n,3)\gcd(n-1,6),\quad Q=\frac{n(n-1)}M,
\]
\[
\delta=\frac Q{\gcd(Q,r^2)},\quad C=M\delta,\quad K=\frac{\delta r^2}{Q}.
\]
従来の結果から \(Cr^2=Kn(n-1)\) である。
\(g=\gcd(C,K),\ c=C/g,\ h=K/g\) と原始化する。
このhはv17の別の残差変数hとは区別する。

小分岐 \(k=r\) では \(\varepsilon=0\)、補分岐 \(k=A-r\) では \(\varepsilon=1\) とし、
\[
T_\varepsilon=(r-\varepsilon)^2-9n^2-6n-10,\quad
G=\gcd(n^2+2,T_\varepsilon),\quad
w=\frac{n^2+2}G,\quad J=\frac{T_\varepsilon}G.
\]

今回、実際に
\[
I_\varepsilon=
\langle cr^2-hn(n-1),\ n^2+2,\ (r-\varepsilon)^2-6n+8\rangle
\subset\mathbb Q[r,n,h,c]
\]
を作り、辞書式グレブナー基底でr,nを消去した。
ここで各生成元は、元の整数解において**法Gで0**になる。
整数として \(n^2+2=0\) と置いたわけではない。

結果は
\[
\boxed{G\mid E_0=2(3h^2-4ch+68c^2)}\qquad(k=r),
\]
\[
\boxed{G\mid E_1
=3(12h^4-16ch^3+404c^2h^2-1752c^3h+7803c^4)}
\qquad(k=A-r).
\]

有理数上の計算では係数2や3を割れても、法Gでその操作が許されるとは限らない。
そこで、整数係数のBézout恒等式を保存し、標準Pythonだけの別検査器で係数ごとに確認した。
小分岐では、機械的な結果式に現れる不要な二乗も外した。
したがって「Gの素因数がこの式の素因数に含まれる」だけでなく、
**Gそのものが、指数込みで割る**。

既存の \(9<h/c<45/4,\ c\le6\delta\) を使うと、
\[
G<2^{15}\delta^2,\qquad G<2^{30}\delta^4
\]
がそれぞれ得られる。

### 高さと有限再構成への接続

\(a_0=h-9c\ge1\) とする。小分岐では
\[
a_0n^2-(h+6c)n-c(JG+10)=0.
\]
補分岐では
\[
L(n)=a_0n^2-(h+6c)n-c(JG+9)=2cr>0,
\]
\[
L(n)^2-4ch\,n(n-1)=0.
\]

これにGの評価を入れ、線形項も評価することで
\[
\boxed{n^2<2^{18}\delta^3J\quad(k=r)},\qquad
\boxed{n^2<2^{33}\delta^5J\quad(k=A-r)}
\]
を得た。δ,Jに探索上限を仮定しない、一様な記述証明である。

固定した(δ,J)なら、M,Kは既存の係数区間で有限個になる。
各組で \(E_\varepsilon\) を計算し、その正の約数Gごとに上の二次式／四次式の整数根を調べる。
復元後には正符号、実際のM,δ,G、整数r、その他の必要条件、最後に元式を確認する。
この手順の必要性と完全性は記述したが、無制限の(δ,J)を全て処理したわけではない。

## 3. 格子基底縮小を実際の全候補生成に使った

二次曲線 \(Cr^2=Kn(n-1)\) を
\[
x=2n-1,\quad y=2r,\qquad Cy^2-Kx^2=-K
\]
へ変換する。

\(B\le x<2B\) の各区間で
\[
L=B^2,\quad a_B=\left\lfloor B^2\sqrt{K/C}\right\rfloor,\quad
e=Ly-a_Bx
\]
とおくと、すべての解は
\[
(x,e)\in
\mathbb Z(1,-a_B)+\mathbb Z(0,L),\qquad
-4B<e<2B
\]
という二次元格子の細い長方形に入る。
平方根の切り捨ても整数平方根だけで確定する。

この格子にGauss縮小を実行し、LLLのサイズ縮小条件とLovász条件
（パラメータ3/4）も各区間で検査した。
基底変換の行列式±1、格子の行列式 \(B^2\)、直交化の恒等式を確認し、
逆行列から得た係数区間を尽くして全点を生成する。
短いベクトルを数本拾うだけの探索ではない。

v16の証明済み高さ \(n<2^{42\delta}\) の下で、
**δ=13〜24の全3,571係数族**を処理した。

| 段階 | 件数 |
|---|---:|
| 完全に覆った係数族 | 3,571 |
| 格子区間・基底の検査 | 2,818,386 |
| 長方形に含まれる格子ベクトル | 16,810,125 |
| \(n\ge104\) の正の整数二次曲線点（係数族ごとの合計） | 112,249 |
| 既存の必要条件を通る(n,r) | 93 |
| 両分岐を元式の合同式で排除した証人 | 186 |
| 元式で未排除 | 0 |

生成ではPellの基本単数・漸化式・保存済み候補リストを使わず、生成後に集合を照合した。
さらに、初期基底、丸めの扱い、長方形の係数計算を変えた別実装でも全体を再計算した。
SymPyの `Matrix.lll_transform` も、実際の係数族C=78,K=703の3区間で実行し、
変換行列とLLL条件を確認した。全区間をSymPyで処理したという意味ではない。

この再計算の役割は、既存のδ≥25を別の完全被覆で点検し、
今後の係数条件と接続できる格子計算を用意することである。
既存Pell法より高速だという結論は出していない。実測時間と比較範囲を記録に残す。

## 4. 楕円曲線の残差を、整数の立方因子へ戻す

v17/v18の残差 \(y^2=F(a,b,\rho)\) では
\[
b\mid486,\quad \gcd(a,b)=1,\quad \rho\equiv a^2\pmod b.
\]
新しい整理として
\[
Z=\frac{a^2-b^2-\rho}{b},\qquad Y=\frac yb,\qquad
D=9a^2-b^2,\quad L=D-3bZ
\]
とおく。Yは整数になり、
\[
Y^2-L^2=4bZ^3.
\]
正のyを選び、
\[
U=\frac{Y-L}{2},\quad V=\frac{Y+L}{2}
\]
とすると、原式に必要な領域ではU,V,Zが正整数で
\[
\boxed{UV=bZ^3,\qquad V-U=D-3bZ}
\]
となる。

Zの正値は新しい排除結果ではない。実際、
\[
81n(n-1)\frac Zb=(t^2-9n)(9n+t^2+6t),\qquad t=r-3n
\]
であり、v17の \(t^2>9n\) から従う。この依存関係を明示する。

一方、素数 \(p\nmid bD\) はU,Vを同時には割れないため、
U,V中のその指数はそれぞれ3の倍数になる。
したがって立方因子を除いた係数α,βは、bDの素因数だけに支えられる。
\[
U=\alpha u^3,\quad V=\beta v^3,\quad
\gamma^3=\alpha\beta b^2
\]
とすると
\[
\boxed{\beta v^3-\alpha u^3+3\gamma uv=D},\qquad
Z=\gamma uv/b
\]
という有限個の三次被覆に帰着する。
固定(a,b)あたり係数型は高々 \(3^{\omega(bD)}\) 個。
整数への復元条件と元の残差条件も併記した。

これは既存の3位数点を利用した具体的な降下の整理である。
完全なSelmer群・Mordell–Weil基底・全整数点を計算したとはしていない。
また、固定(a,b)での有限個の被覆であって、全aを有限にしたという意味ではない。

有限体の実計算では、496繊維を完全に調べ、
良い還元を持つ464繊維で3位数点の倍加を確認した。
従来の残差上限から有限化できる負のZの6,221件についても、
61以下の良い還元の素数で非平方となる証明書を保存した。
これは正符号への別検証であり、上の既存条件の帰結を新しい領域排除として数えない。

詳細：[残差の3次被覆](v19_residual_cube_cover.md)、
[独立監査](v19_residual_cube_cover_audit.json)。

### 素数を増やすだけでは強くならない検査を特定した

さらに、任意の素数 \(p\ge5\) と \(s\in\mathbb F_p\) に対して
\[
y^2=F(x,1,s)
\]
がアフィン点を持たないのは、**正確に \((p,s)=(5,1)\) のときだけ**と証明した。

特異な3種類 \(s=0,-3/4,-8/9\) には明示点を与える。
その他は滑らかな種数2の曲線であり、無限遠点は2個。
Hasse–Weilの評価によって、\(p\ge19\) なら射影曲線の点数は
\[
\#C(\mathbb F_p)\ge p+1-4\sqrt p>2
\]
なので、少なくとも1点はアフィン部分にある。
残る \(p=5,7,11,13,17\) を全剰余類で調べると、唯一の例外が上の組となる。
Hasse–Weilの出典は[Poonenの講義録 §3.3](https://math.mit.edu/~poonen/papers/curves.pdf)。

これは有限個の素数からの外挿ではない。
**ρ/b²だけを指定する法素数の検査では、より大きい素数に進んでも新たな全繊維排除は出ない**、
という範囲を特定した定理である。a/bも指定する検査、素数冪、n,tの復元条件、
大域的な群の条件まで否定するものではない。
