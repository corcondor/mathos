# v36：二次K3の非巡回点 mR±Q（|m|≤4）からの整数候補の排除

2026-11-08。入れ子二項係数方程式の \(\ell=1,\ j=i-3\) 枝から得た補助整数条件の研究であり、元の四変数問題の全解決ではない。既存v35で排除した \(Q,R\pm Q\) を、新たに \(2R\pm Q,3R\pm Q,4R\pm Q\) まで拡張した。

## 定理（対象と正確な適用範囲）

v33/v34の補助楕円曲線
\[
E_T:Y^2=X^3+B(T)X^2+A(T)C(T)X+4A(T)^2,\quad
A=-T^2(4T+3),\ B=12(T^2+5T+3),\ C=12(2-T)
\]
上の点 \(R=(8T(4T+3),\,6T(4T+3)(9T+8))\) をとる。二次基底変換
\[
T=q^2-1=\rho/b^2,\quad q=p/b>1,\quad p,b\in\mathbb Z_{>0},\quad b\mid486,\quad \rho=p^2-b^2
\]
では \(Q=(A/q^2,\,A(9T+8)/q^3)\) が有理点である。

元の整数点が \(P\in E_T(\mathbb Q)\) に写るためには少なくとも
\[
a^2=b^2A/X(P)\in\mathbb Z_{>0},\quad
a^2>p^2,\quad
\gcd(a,b)=1,\quad
\gcd(a,\rho)=\gcd(a,3),\quad
\rho\bmod9\in\{1,4,6,7\},\quad
\rho\ge32770
\tag{36.1}
\]
が必要（v20〜v23とv27の既存の入力）。

**定理：任意の整数 \(m\) で \(|m|\le4\)、点 \(P=mR+Q\) または \(P=mR-Q\) から、条件(36.1)を満たす整数点は復元できない。**

\(|m|\le1\) はv35を継承する。楕円曲線の \(X(-P)=X(P)\) により、残る \(m=2,3,4\) と \(Q\) の両符号を検査すれば十分。

## 1. 群法則：6つの有理恒等式

Weierstrass加法公式を厳密な有理関数として計算すると、\(a^2/b^2=A/X(P)\) は

| \(P\) | \(a^2/b^2\) |
|---|---|
| \(2R+Q\) | \((q-1)(q+1)^2/(q-5)\) |
| \(2R-Q\) | \((q-1)^2(q+1)/(q+5)\) |
| \(3R+Q\) | \((q-1)^2(q+1)(4q^2-1)/(4q(q^2-10q+1))\) |
| \(3R-Q\) | \((q-1)(q+1)^2(4q^2-1)/(4q(q^2+10q+1))\) |
| \(4R+Q\) | \((q-2)^2(q-1)/(q-17)\) |
| \(4R-Q\) | \((q+2)^2(q+1)/(q+17)\) |

となる。負符号の3系列では \(q>1\) に対し
\[
\begin{aligned}
A/X(2R-Q)-q^2&=-\frac{(2q+1)(3q-1)}{q+5}<0,\\
A/X(3R-Q)-q^2&=-\frac{(3q-1)(3q+1)(4q^2+q+1)}{4q(q^2+10q+1)}<0,\\
A/X(4R-Q)-q^2&=-\frac{4(q-1)(3q+1)}{q+17}<0.
\end{aligned}
\tag{36.2}
\]
よって \(a^2>p^2=b^2q^2\) に反する。残る正符号の3系列だけを調べる。

## 2. 2R+Q：819個の約数へ厳密に有限化

正の \(a^2\) が可能なのは \(q>5\) のみ（\(q=5\) では \(X=0\)）。\(d=p-5b>0\) とおくと、
\[
\boxed{a^2=\frac{(d+6b)^2(d+4b)}{d}}.\tag{36.3}
\]
\(a\in\mathbb Z\) なら分母 \(d\) が分子を割るため、\(d\) を法として評価すると
\[
\boxed{d\mid144b^3.}\tag{36.4}
\]
\(b=2^e3^f\)、\(e=0,1,\ f=0,\ldots,5\) より、
\(d=2^i3^j\) で \(0\le i\le4+3e,\ 0\le j\le2+3f\)。従って候補総数は
\[
\sum_{e=0}^1\sum_{f=0}^5(5+3e)(3+3f)=819.
\]
完全平方の \(a^2\) は25件。さらに (36.1) の残差下限、\(\gcd(a,b)=1\)、法9条件まで課すと、唯一
\[
(b,d,p,a,\rho)=(18,128,218,295,47200)
\]
が残る。しかし \(47200=160\cdot295\) なので \(\gcd(a,\rho)=295\ne1=\gcd(a,3)\)。従って全排除。

## 3. 3R+Q：pの素因数が2,3だけと分かり全排除

\(q>1\) では \(q^2-10q+1>0\) が \(a^2>0\) の必要条件である。整数式に直すと
\[
\boxed{a^2=\frac{(p-b)^2(p+b)(4p^2-b^2)}
{4p(p^2-10pb+b^2)}}.\tag{36.5}
\]
もし \(a^2\) が整数なら分母因子 \(p\) が分子を割る。分子を法 \(p\) に落とすと \(-b^5\) なので、
\[
\boxed{p\mid b^5.}\tag{36.6}
\]
従って \(p=2^i3^j,\ 0\le i\le5e,\ 0\le j\le5f\) に限られる。\(p>b\) と \(p^2-10pb+b^2>0\) も課すと391件の候補しかない。その**391件すべてで (36.5) の分子が分母で割り切れず**、整数 \(a^2\) が存在しない。これで全排除。

## 4. 4R+Q：2457個の約数へ厳密に有限化

\(q>17\) が必要（\(q=17\) では \(X=0\)）。\(d=p-17b>0\) とすると
\[
\boxed{a^2=\frac{(d+15b)^2(d+16b)}d.}\tag{36.7}
\]
整数性から
\[
\boxed{d\mid3600b^3.}\tag{36.8}
\]
\(3600=2^4 3^2 5^2\) だから、\(d=2^i3^j5^k\)、\(0\le i\le4+3e,\ 0\le j\le2+3f,\ 0\le k\le2\)。候補総数は \(3\cdot819=2457\)。

完全平方の \(a^2\) は81件。残差下限、\(\gcd(a,b)=1\)、法9まで課すと唯一
\[
(b,d,p,a,\rho)=(18,1,307,4607,93925)
\]
が残る。しかし \(\gcd(4607,93925)=17\ne1=\gcd(4607,3)\)。従って全排除。

## 5. 別の因数対パラメータによる独立照合

2R+Qまたは4R+Qの完全平方条件を
\[
a^2=L(p,b)^2\frac{d+cb}{d},
\quad(c,L)=(4,p+b)\text{ または }(16,p-2b)
\]
と書く。平方根を既約な \(k/h\)、\(\gcd(k,h)=1\)、\(k>h>0\) で表せば
\[
d(k^2-h^2)=cbh^2,\quad
\gcd(h^2,k^2-h^2)=1
\]
より \(d=c_0h^2,\ c_0(k^2-h^2)=cb,\ c_0\mid cb\) である。
\[
u=k-h,\quad v=k+h
\quad\Longrightarrow\quad
uv=cb/c_0,\quad u<v,\quad u\equiv v\pmod2.
\]
また \(a\in\mathbb Z\) から \(h\mid6b\)（2R+Q）または \(h\mid15b\)（4R+Q）。従って \(c_0\mid cb\) の約数と \(uv=cb/c_0\) の因数対を独立に列挙しても、平方候補25件・81件が**集合として完全一致**する。
