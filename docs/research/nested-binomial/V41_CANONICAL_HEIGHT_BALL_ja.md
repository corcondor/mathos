# v41：Mordell–Weil格子の高さが13/6未満の全切断を一括排除

2026-11-08。対象は入れ子二項係数方程式 \(\ell=1,j=i-3\) 枝の**必要条件**と、v38の二次基底変換 \(T=q^2-1\) により得た幾何学的Mordell–Weil格子。新しい結論は点を一つずつ指定するのではなく、**全ての整数係数 \(m,n\) のうち高さが指定値未満の点を同時に排除**する。特殊化 \(T=T_0\) 後に新規出現する有理点や元の四変数方程式の全解決ではない。

## 定理：高さ \(\hat h<13/6\) から元の整数候補は復元できない

\(b\mid486,\ p>b>0\)、\(T=(p/b)^2-1=\rho/b^2\)、\(\rho=p^2-b^2\) とする。v38で得た完全な幾何学的関数体MW基底 \(R,H\) と、関数体上のShioda高さ
\[
\begin{pmatrix}
\langle R,R\rangle&\langle R,H\rangle\\
\langle H,R\rangle&\langle H,H\rangle
\end{pmatrix}
=\begin{pmatrix}1/15&1/30\\1/30&1/6\end{pmatrix}
\]
を使用する。任意の \(m,n\in\mathbb Z\) に対し \(P=mR+nH\) の高さは
\[
\boxed{
\hat h(P)=\frac{2m^2+2mn+5n^2}{30}
=\frac{(2m+n)^2+9n^2}{60}.
}\tag{41.1}
\]
特に整数係数を予め制限しなくても、\(\hat h(P)<13/6\) なら
\[
(2m+n)^2+9n^2<130.\tag{41.2}
\]

**定理：** 任意の \(m,n\in\mathbb Z\) で(41.2)を満たす点 \(P=mR+nH\) から、元の整数候補の必要条件
\[
a^2=b^2A(T)/X(P)\in\mathbb Z_{>0},\quad
a^2>p^2,\quad \gcd(a,b)=1,\quad
\rho\ge32770,\quad
\rho\bmod9\in\{1,4,6,7\},\quad
\gcd(a,\rho)=\gcd(a,3)
\tag{41.3}
\]
を満たすものは存在しない。\(P=O\) や \(X(P)=0\) はそもそも有限の \(a\) を復元しない。

### 証明1：高さ球を7つの薄い層へ完全分解

(41.2)から \(9n^2<130\) なので \(|n|\le3\)。各 \(n\) で \((2m+n)^2<130-9n^2\) を厳密に解くと次の表となる。

| \(n\) | 許される整数 \(m\) |
|--:|---|
| 0 | \(-5\le m\le5\) |
| 1 | \(-5\le m\le4\) |
| -1 | \(-4\le m\le5\) |
| 2 | \(-5\le m\le3\) |
| -2 | \(-3\le m\le5\) |
| 3 | \(-4\le m\le1\) |
| -3 | \(-1\le m\le4\) |

これは**高さの不等式から導いた全係数の厳密な分類**であり、\(|m|\) や \(|n|\) を任意に切って総当たりしたのではない。

\(X(-P)=X(P)\) なので \((m,n)\mapsto(-m,-n)\) で \(n<0\) は \(n>0\) と同じ。\(n=1\) はv39・v40の \(mR+H,\ |m|\le5\) 排除に含まれる。

\(n=2\) では v34の \(Q=2H-R\) より
\[
mR+2H=(m+1)R+Q,\quad -5\le m\le3
\quad\Longrightarrow\quad |m+1|\le4.
\]
これはv35・v36の \(|j|\le4\) に対する \(jR+Q\) の排除に含まれる。

残る \(n=0\) および \(n=3\) を次の2段階で処理する。

### 証明2：n=3 の6点は全て復元値が負

\(3H+mR\) の \(A/X(P)\) を群法則で有理関数化すると（下表の \(q=p/b>1\)）：

| \(m\) | \(\dfrac{A}{X(mR+3H)}\) |
|--:|---|
| -4 | \(-\dfrac{(2q-1)(5q+1)^2}{2(11q+7)}\) |
| -3 | \(-\dfrac{(q-1)(2q+1)}6\) |
| -2 | \(-\dfrac{(q-1)^2(q+1)(2q-1)}{2(5q-1)(7q-1)}\) |
| -1 | \(-\dfrac{(q-1)(q+1)^2(2q+1)}{2(5q+1)(7q+1)}\) |
| 0 | \(-\dfrac{(q+1)(2q-1)}6\) |
| 1 | \(-\dfrac{(2q+1)(5q-1)^2}{2(11q-7)}\) |

\(q>1\) では全分母・正の因子が正で、表の各値は厳密に負。従って \(a^2\in\mathbb Z_{>0}\) に矛盾する。これで \(n=\pm3\) の全点を排除。

### 証明3：n=0 の4R・5Rは独立した構造的約数で処理

\(P=mR,\ |m|\le5\) では \(m=\pm1,\pm2\) の \(A/X(mR)\) は負、\(m=\pm3\) は \(X(mR)=0\)、\(m=0\) は無限遠点 \(O\)。残る \(m=4,5\) を、既存v26・v27の結果に頼らずこの二次基底変換族について独立に再検算する。

\(m=4\)：
\[
a^2=\frac{4(p^2-b^2)(4p^2-b^2)}{D_4},\quad
D_4=7p^2+17b^2.
\]
\(N_4=4(p^2-b^2)(4p^2-b^2)\) とおくと
\[
\boxed{49N_4=D_4(112p^2-412b^2)+7200b^4.}\tag{41.4}
\]
よって \(a^2\in\mathbb Z\) なら
\[
\boxed{D_4\mid7200b^4.}
\]
\(7200=2^5 3^2 5^2\)、\(b=2^e3^f\) なので、全ての \(b\mid486\) の正約数候補は**3744件**。\(p^2=(D_4-17b^2)/7>b^2\) が整数平方となるものは84件で、\(a^2\) が平方となるものは12件。その12件は**すべて \(p=a=2b\)**、すなわち \(a^2=p^2\) なので厳密不等式に反する。

\(m=5\)：
\[
a^2=\frac{25(p^2-b^2)^2}{16D_5},\quad D_5=p^2+11b^2.
\]
\(N_5=25(p^2-b^2)^2\) とおくと
\[
\boxed{N_5=D_5(25p^2-325b^2)+3600b^4.}\tag{41.5}
\]
整数性から \(\boxed{D_5\mid3600b^4}\)、\(3600=2^4 3^2 5^2\)。全 \(b\mid486\) で**3276正約数候補**。正整数 \(p\) は120件、整数 \(a^2\) は78件、平方となる12件はすべて **\(p=a=5b\)**。やはり \(a^2>p^2\) と矛盾。

これで全7層が排除され、定理が証明された。\(\square\)

## 幾何学的意味と次の境界

高さは正定値の2次形式なので、\(\hat h<13/6\) はMordell–Weil格子の楕円状の**有限な高さ球**。今回、元の整数候補が存在し得るなら必ず
\[
\boxed{\hat h(P)\ge13/6}
\tag{41.6}
\]
が成立するという**全切断に対する一様な高さ下限**が得られた。

これは二次基底変換 \(T=(p/b)^2-1\) 上の**関数体切断の高さ**であって、固定した \(T_0\) に特殊化した曲線のNéron–Tate高さの下限とは同じではない。特殊化で追加される有理点にも自動適用されない。

境界 \(\hat h=13/6\) に残る新しい整数係数方向は、例えば \(6R-H\)、\(2R+3H\)、\(-5R+3H\)。次はこれら3方向に対する有理式を計算し、結果式・局所合同条件を結合して高さ下限をさらに押し上げる。
