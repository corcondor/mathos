# v39：真のMordell–Weil生成元Hから生まれる新しい整数候補の初期完全排除

2026-11-08。v38で二次基底変換 \(T=q^2-1\) 上の全幾何学的Mordell–Weil群が
\(E(\overline{\mathbb Q}(q))=\mathbb ZR\oplus\mathbb ZH\) と決まった。以前の基底 \(R,Q\) は \(Q=2H-R\) のため指数2の部分格子しか見ていなかった。本ノートは新基底の**奇数H係数**である
\[
\boxed{P=mR\pm H,\qquad |m|\le2}
\]
について、元の入れ子二項係数方程式の整数候補がないことを示す。\(m,n\) 無制限の全群・元方程式全体の解決ではない。

## 設定

v38の第二楕円商を使い、\(q=p/b>1\)、\(b\mid486\)、\(\rho=p^2-b^2\) と置く。元の整数解が \(P\) に射影される場合は少なくとも
\[
a^2=b^2\frac{A(T)}{X(P)}\in\mathbb Z_{>0},\quad
a^2>b^2+\rho=p^2,\quad
\gcd(a,b)=1,\quad \rho\ge32770,\quad
\rho\bmod9\in\{1,4,6,7\},\quad
\gcd(a,\rho)=\gcd(a,3)
\tag{39.1}
\]
が必要。

## 1. 群法則からの厳密な5有理式

\[
H=\left(-2(q-1)(q+1)^2(2q+1),\
6(q-1)(q+1)^2(2q+1)(3q-1)\right).
\]
群法則を使うと、\(a^2/b^2=A/X(P)\) は

| \(P\) | \(A/X(P)\) |
|---|---|
| \(H\) | \((q-1)(2q-1)/2\) |
| \(R+H\) | \((q-1)^2(2q+1)/(2(q+3))\) |
| \(R-H\) | \((q+1)(2q+1)/2\) |
| \(2R+H\) | \((q-1)(q+1)(2q-1)/(2(q+7))\) |
| \(2R-H\) | \((q+1)^2(2q-1)/(2(q-3))\) |

となる。\(q>1\) において、\(H,R+H,2R+H\) はそれぞれ
\[
\begin{aligned}
A/X(H)-q^2&=-(3q-1)/2<0,\\
A/X(R+H)-q^2&=-\frac{(3q-1)(3q+1)}{2(q+3)}<0,\\
A/X(2R+H)-q^2&=-\frac{(3q+1)(5q-1)}{2(q+7)}<0.
\end{aligned}
\]
従って3点は直ちに(39.1)の厳密不等式に反する。

## 2. R−H：b²の78個の因数対で完全分類

整数復元式は
\[
\boxed{2a^2=(p+b)(2p+b).}\tag{39.2}
\]
これを平方完成して
\[
\boxed{(4p+3b)^2-(4a)^2=b^2.}\tag{39.3}
\]
よって
\[
u=4p+3b-4a>0,\quad v=4p+3b+4a>u,\quad
uv=b^2,
\]
\[
\boxed{p=(u+v-6b)/8,\qquad a=(v-u)/8.}\tag{39.4}
\]
\(b=2^e3^f\) は12通りなので、\(uv=b^2\) の正整数因数対 \(u\le v\) は全b合計**78組**。式(39.4)で \(p>a\) を要求する必要はない（要求するのは \(p>b,\ a>p\)）が、実際に \(p>b\) と \(a\in\mathbb Z_{>0}\) を課すと10組だけが残る。

さらに \(\rho\ge32770,\ \gcd(a,b)=1,\ \rho\bmod9\in\{1,4,6,7\}\) を課すと唯一
\[
\boxed{(b,p,a,\rho)=(243,7199,7381,51766552)}
\]
が残る。しかし
\[
\gcd(7381,51766552)=61\ne1=\gcd(7381,3)
\]
なので、これも元問題の必要条件に反する。

## 3. 2R−H：80b³の1326個の約数で完全分類

\(A/X(2R-H)>0\) には \(q>3\) が必要（\(q=3\) で \(X=0\)）。\(d=p-3b>0\) と置くと
\[
\boxed{a^2=\frac{(p+b)^2(2p-b)}{2(p-3b)}.}\tag{39.5}
\]
もし整数 \(a\) が存在するなら、特に \(d\) が \((p+b)^2(2p-b)\) を割り、\(p\equiv3b\pmod d\) から
\[
\boxed{d\mid80b^3.}\tag{39.6}
\]
\(80=2^4\cdot5\) なので
\(d=2^i3^j5^k,\quad0\le i\le4+3e,\ 0\le j\le3f,\ 0\le k\le1\)。
候補は \(\sum_{e,f}(5+3e)(3f+1)\cdot2=\boxed{1326}\) 個に限られる。

全1326個を整数計算すると、(39.5)の右辺が整数であるのは1020件、そのうち平方は38件。**38件はすべて** \(\rho\ge32770\)、\(\gcd(a,b)=1\)、\(\rho\bmod9\in\{1,4,6,7\}\) の少なくとも1つに反し、元の必要条件を満たす候補はない。

## 4. 総合結果・重要性と限界

\(X(-P)=X(P)\) なので \(m\mapsto-m\) と \(H\mapsto-H\) の符号対称性を利用すれば、以上で
\[
\boxed{
P=mR\pm H,\quad m\in\mathbb Z,\quad |m|\le2
\Longrightarrow
\text{元問題の許容整数候補は生じない}.
}\tag{39.7}
\]

特に、以前の \(mR\pm Q\) は真の格子では \(H\) 係数が偶数の部分だけを見ていた。今回のv39は **初めて奇数H係数の点を元の整数点制約へ接続して排除した**。
ただし全ての \((m,n)\in\mathbb Z^2\) の点、固定された有理数 \(T\) への特殊化での新しい点、元の四変数方程式は未解決。
