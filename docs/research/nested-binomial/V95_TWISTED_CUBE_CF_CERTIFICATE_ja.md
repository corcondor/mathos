# v95：原始連分数曲線の立方不足約数を「ねじれた立方数」へ完全還元

2026-11-09。DeepSeekの凍結された最終目標 CFSmallDefectGoal と ThirtyCofactorGoal は依然未完了。本研究は、v11で既に証明済みの D | 6ST と、元の主枝に固有の S | n−2 を結び付け、**解が存在する場合の n−1 を有限個の係数を持つ完全な三乗型へ制限する**。v11の約数補題そのものを新規発見とは呼ばない。

## 定理（ねじれ立方数による新しい必要条件）

正整数 S,T,n,r が
\[
6Sr^3=Tn(n-1)(n-2),\qquad S\mid n-2,\qquad n\ge104
\]
を満たすとする。\(g=\gcd(r,n-1)>0\)、\(r=gp\)、\(n-1=gq\) と置く。よって \(\gcd(p,q)=1\)。

v9/v11により
\[
D=Tq^3-6Sp^3>0,\qquad g^2D=Tq.
\]
次の整数を定義する：
\[
h=\gcd(D,q),\quad e=D/h,\quad w=T/e.
\]
このとき \(e\mid T\) であり、正整数 \(A,z\) と平方因子を持たない正整数 \(s\) が存在して
\[
\boxed{\begin{gathered}
h=\gcd(6,q)\mid6,\qquad
w=sA^2,\\
q=hsz^2,\qquad g=Asz,\qquad
n-1=hAs^2z^3.
\end{gathered}}\tag{95.1}
\]
加えて
\[
\boxed{
\gcd(h,S)=\gcd(w,S)=\gcd(e,s)=\gcd(s,6/h)=1,\qquad
hAs^2z^3\equiv1\pmod S.
}\tag{95.2}
\]
さらに元の三次曲線は
\[
\boxed{\frac{6S}{h}p^3+e=Th^2s^3z^6.}\tag{95.3}
\]
に帰着する。これは無限の \(n\) を単に有限走査に置き換えたものではなく、\(S,T\) に依存する有限個の係数の下で **\(n-1\) が立方数の定数倍**であることを示す全称的な必要条件。

### 証明

まず \(D\equiv-6Sp^3\pmod q\) と \(\gcd(p,q)=1\) より
\[
h=\gcd(D,q)=\gcd(6S,q).
\]
\(S\mid n-2\) と \(q\mid n-1\) から、連続する2整数の互いに素性により \(\gcd(S,q)=1\)。従って
\[
\boxed{h=\gcd(6,q)\mid6,\qquad\gcd(h,S)=1.}
\]
既存の \(g^2D=Tq\) より \(D\mid Tq\)。\(D=he,q=hq'\) と \(\gcd(e,q')=1\) を用いると
\[
e\mid T,\quad w=T/e,\quad g^2=wq'.
\]
\(w\) の素因数指数を偶奇で分け \(w=sA^2\)（sは平方因子なし）とする。\(g^2=sA^2q'\) の両辺の素因数指数を比較すれば、
\[
\boxed{q'=sz^2,\quad g=Asz}
\]
と書ける。従って \(q=hsz^2\)、\(n-1=gq=hAs^2z^3\)。
\(\gcd(e,q')=1\) から \(\gcd(e,s)=1\)。一方 \(gq=n-1\) はSと互いに素なので \(w=sA^2\) もSと互いに素。\(h=\gcd(6,q)\) と \(q=hsz^2\)、\(h\mid6\) より \(\gcd(s,6/h)=1\) が必要。

最後に \(S\mid n-2\) なので **\(n-1\equiv1\pmod S\)**。これが(95.2)の最後の合同式である（符号は＋1であり－1ではない）。元のD等式に \(D=he\)、\(q=hsz^2\) を代入してhで割れば
\[
\frac{6S}{h}p^3+e=Th^2s^3z^6
\]
を得る。これで示された。\(\square\)

## 有限係数証明書：全5214曲線への適用

凍結目標の範囲
\[
1\le S\le12,\qquad 162S<T<229S
\]
には、合計5214通りの整数 \((S,T)\) がある。各曲線の \(h\mid6S\)、\(e\mid T\) を初期候補とし、上記の必要条件を正確な整数演算で順に課す。

| 段階 | \((S,T,h,e)\) の必要パラメータ数 |
|---|---:|
| h∣6S, e∣T（初期集合） | 409,728 |
| h∣6, gcd(h,S)=1 | 104,588 |
| gcd(e,s)=gcd(T/e,S)=1 | 61,571 |
| gcd(s,6/h)=1 | 53,003 |
| hAs²z³≡1 (mod S) の解が存在 | **43,922** |

よって有限係数パラメータを約89％削減できる。これは**43,922個の整数解候補という意味ではない**。実際の整数解に必要な \(p,z\) はさらに(95.3)、\(\gcd(p,q)=1\)、\(n\ge104\)、rの範囲などを満たす必要がある。各ケースの曲線に解が存在するとは主張しない。

特に \(S=7,9\) では、単元群の三次剰余が一般の単元に比べ少ないため(95.2)が強く働く。これが以前のCF候補リストとは異なる独立の指数条件となる。

[正確な整数計算検証器](v95_twisted_cube_parameter_verify.py) は全5214曲線を枚挙し、上記の5段階の数を完全再現する。別の既知の小さな実点 \((S,T,n,r)=(13,2352,28,84)\)（これはS∣n−2を満たす）で(95.1)〜(95.3)を独立に代入検算した。
