# v79：残差を固定したときの整数点の全てを、Mの素因数だけで決まる三次曲線に降下する

2026-11-08。v74の第一楕円商の整数モデルを使い、任意の正整数 \(b,\rho\) に対して、**全ての正のXを持つ整数点の立方因子を、Xやaの値に依存しない有限個の係数へ正確に分類**する。既存v20の \(\gcd(U,V)^2\mid D^3\) は \(D=9a^2-b^2\) に依存していたが、今回は**\(M=b(8b^2+9\rho)\) のみに依存**する。元の四変数二項係数方程式やこの有限個の三次曲線の全整数点はまだ解いていない。

## 定理1：共通因子の強い一様上界

\[
E_{b,\rho}:\quad Y^2+6bXY+MY=X^3,\qquad
M=b(8b^2+9\rho)>0
\]
とする。\(b,\rho,X,Y\) が整数で \(b,\rho,X>0\)、\((X,Y)\in E_{b,\rho}(\mathbb Z)\) と仮定する。

\[
C=6bX+M>0,\qquad U=|Y|,\quad V=|Y+C|.
\]
\(Y(Y+C)=X^3>0\) なので、\(Y,Y+C\) は同符号で \(U,V>0\)。また
\[
UV=X^3,\qquad V-U=\varepsilon C,\quad
\varepsilon=\operatorname{sgn}(Y)\in\{\pm1\}.
\]
このとき
\[
\boxed{\gcd(U,V)^2\mid M^3.}\tag{79.1}
\]

**証明**：任意の素数 \(p\) に対し
\[
e=v_p(M),\quad f=v_p(X),\quad
h=v_p(\gcd(U,V)).
\]
\(UV=X^3\) より \(v_p(U)+v_p(V)=3f\)、従って \(2h\le3f\)。もし \(f\le e\) なら直ちに \(2h\le3e\)。
\(f>e\) のとき、\(v_p(6bX)\ge f>e\) だから
\[
v_p(C)=v_p(6bX+M)=e.
\]
一方 \(\gcd(U,V)\mid V-U=\pm C\)、したがって \(h\le e\)、特に \(2h\le3e\)。これですべての素数について \(2v_p(\gcd(U,V))\le3v_p(M)\) が示され、(79.1)が従う。\(\square\)

**注意**：一般には \(\gcd(U,V)\mid M\) まで強められない。実例
\[
(b,\rho,X,Y)=(1,63,50,125),\quad M=575,
\quad (U,V)=(125,1000)
\]
では \(125\cdot1000=50^3\)、\(V-U=875=6\cdot50+575\) だが
\[
\gcd(U,V)=125\nmid575=M,\quad
125^2\mid575^3.
\]
従って式(79.1)の指数形は実質的な内容を持つ。

## 定理2：整数点の完全な立方核降下

正整数 \(U,V\) を素因数分解し、その立方因子を除くと一意に
\[
U=c u^3,\qquad V=d v^3,\quad
c,d\text{ は立方因子を持たない正整数},\quad u,v\in\mathbb Z_{>0}
\]
と書ける。\(UV=X^3\) から、素数ごとに \(v_p(c)+v_p(d)\equiv0\pmod3\)。両指数は0,1,2なので、可能な組は
\[
(0,0),\quad (1,2),\quad (2,1)
\]
の3通りだけ。このうち後二者を選んだ素数の積を \(t\) と置けば
\[
\boxed{cd=t^3,\quad t\text{ は平方因子を持たない},\quad X=tuv.}\tag{79.2}
\]

もし \(p\nmid M\) なら(79.1)から \(p\nmid\gcd(U,V)\)。ところが \((1,2),(2,1)\) の場合はどちらの因子も \(p\) で割れるため矛盾。従って \(p\nmid M\) では必ず \((0,0)\) である。よって
\[
\boxed{t\mid\operatorname{rad}(M),\qquad c,d\mid\operatorname{rad}(M)^2.}\tag{79.3}
\]
また
\[
V-U=\varepsilon(6bX+M)
\]
に代入して、すべての整数点は
\[
\boxed{
d v^3-c u^3=\varepsilon(6btuv+M),
\quad
X=tuv,\quad Y=\varepsilon c u^3.
}\tag{79.4}
\]
を満たす。逆に、(79.2)(79.3)(79.4)を満たす正整数 \(u,v\) と \(\varepsilon\in\{\pm1\}\) から、\(X=tuv,\ Y=\varepsilon c u^3\) と置けば元の整数モデルの点が正確に復元できる。これは必要条件だけでなく**整数点との完全な対応**である。

\(M\) の異なる素因数の個数を \(\omega(M)\) とすると、各素数につき指数の選択は3通りなので、係数組 \((c,d,t)\) は**ちょうど \(3^{\omega(M)}\) 通り**、符号込みで高々 \(2\cdot3^{\omega(M)}\) 通りの三次曲線に分解される。

ただし元の整数解に必要なのはX座標であり、楕円群の標準的対称性
\[
(X,Y)\longmapsto(X,-Y-6bX-M)
\]
によって負のYと正のYは対になりXが同じ。従って元の整数解の**X候補だけを求める**なら \(\varepsilon=+1\) に正規化し、**\(3^{\omega(M)}\) 通りだけ**で十分。
