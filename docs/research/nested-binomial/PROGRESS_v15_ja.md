# v15：候補数の平方根評価と、立方因子・隣接多項式による新しい制約

2026年11月6日 JST。

## 今回の到達点

対象は引き続き、**上下の添字を二乗した**元の方程式

\[
\binom{\binom ij}{\binom{k}{\ell}}
=\binom{i^2}{j^2}+\binom{k^2}{\ell^2}
\]

です。今回の結果は、主に調べている **\(\ell=1,\ j=i-3\)** の枝に適用します。
\(n=i\)、\(A=\binom n3\)、\(r=\min(k,A-k)\) とし、
**\(k=r\) と \(k=A-r\) の両方**を扱います。

v15では、素数や第一添字の任意の探索上限を広げず、次の四つを得ました。

| 結果 | 内容 | 証明・検証の方法 |
|---|---|---|
| 第一添字の個数 | 従来の \(O(X^{3/4})\) を **\(O(\sqrt X\log X)\)** に改善 | 標準分解と和の評価による一様な証明 |
| 隣接多項式 | **\(n^2+2\) は合成数**。さらに各素因数に上限 | 元の二項係数の合同式、法9、整除条件 |
| 必須の立方因子 | **\(Q\nmid r^2\)**。従って素数の三乗が \(n\) または \(n-1\) を割る | 証明済み高さ、25本の Pell 方程式、独立した整数計算 |
| 立方因子による高さ | **\(\log n<28\kappa\)** | 整数が連続する二整数の間に入ることによる矛盾 |

ここで

\[
M=\gcd(n,3)\gcd(n-1,6)\in\{1,2,3,6\},\qquad
Q=\frac{n(n-1)}M,\qquad
\kappa=\prod_p p^{\lfloor v_p(Q)/3\rfloor}.
\]

\(\kappa\) は、\(\kappa^3\mid Q\) となる最大の正整数です。
これらは既存の枝の必要条件からの新しい帰結であり、**元の四変数問題の全解分類や、具体的な解の発見には至っていません**。

## 1. 候補の個数を \(O(\sqrt X\log X)\) まで抑える

この枝の解に現れ得る異なる第一添字 \(104\le n\le X\) の個数を
\(\mathcal N(X)\) とします。異なる \(k\) を重複して数えません。
すべての実数 \(X\ge104\) に対し、

\[
\boxed{\mathcal N(X)\le
4\sqrt{21X}\,H_{\lfloor X^{1/3}\rfloor}
\le4\sqrt{21X}\left(1+\frac{\log X}{3}\right).}
\]

\(H_m=1+1/2+\cdots+1/m\) は調和数で、原始不足分の \(H\) とは別の記号です。

証明の要点は、

\[
c_3(m)=\prod_p p^{\lceil v_p(m)/3\rceil},\qquad f(m)=m/c_3(m)
\]

とおき、既存の \(Q\mid r^3\)、\(3n<r<10n/3\) から

\[
n-1<20f(n)f(n-1)
\]

を得ることです。従って \(m=n,n-1\) の少なくとも一方は
\(m<21f(m)^2\) を満たします。

一意な分解

\[
m=ab^2c^3,\qquad a,b\text{ は平方因子を持たず、}\gcd(a,b)=1
\]

では、\(f(m)=bc^2\)、\(m/f(m)^2=a/c\) なので、条件は **\(a<21c\)** に変わります。
この条件を満たす整数三つ組を数えると、

\[
\sum_{c\le X^{1/3}}\sum_{a\le21c}
\left\lfloor\sqrt{\frac{X}{ac^3}}\right\rfloor
\le2\sqrt{21X}\sum_{c\le X^{1/3}}\frac1c.
\]

各 \(m\) が対応する \(n\) は最大二つなので、主張が従います。
隣り合う整数の素因数が独立に分布するという仮定は使っていません。
また、有限範囲で見られた減少率からの外挿でもありません。

厳密な対数幅を使えば、定数を改善した
\(\mathcal N(X)\le920+4\sqrt{19X}H_{\lfloor X^{1/3}\rfloor}\) も得られます。
これは必要条件を満たす集合の上界であり、解が存在することや、この次数が最適であることは示しません。

詳細：[一様な個数評価の証明](v15_cubic_defect_sparsity.md)。

## 2. \(n^2+2\) が素数の場合を、短い証明で全排除

\(B=\binom{n^2}{6n-9}\) とおけば、元の枝の等式は
\(\binom Ar=B+k^2\) です。
\(p\mid n^2+2\)、\(p>6n-9\) を満たす任意の素数について、

\[
B\equiv\binom{-2}{6n-9}=8-6n\pmod p,
\qquad A-1=\frac{(n-3)(n^2+2)}6
\]

より \(A\equiv1\pmod p\) となります。\(1<r<p\) なので、
\(\binom Ar\equiv0\pmod p\)。
\(k=r\) のとき \(\varepsilon=0\)、\(k=A-r\) のとき \(\varepsilon=1\) とおくと、

\[
\boxed{(r-\varepsilon)^2\equiv6n-8\pmod p.}
\]

従って \(6n-8\) は法 \(p\) で非零の平方剰余でなければなりません。

特に \(p=n^2+2\) 自体が素数だと仮定します。
\(s=r-\varepsilon\)、\(z=(s^2-6n+8)/p\) とおくと、既存の厳密区間から
\(8<z<100/9\)、すなわち **\(z\in\{9,10,11\}\)**。
一方、\(n^2+2\) が3より大きい素数なら \(3\mid n\) です。法9で

\[
2z\equiv s^2-1\pmod9
\]

となり、平方剰余 \(\{0,1,4,7\}\) に照らすと、三候補のうち \(z=9\) だけが残ります。
ところが、それは

\[
s^2=9n^2+6n+10=(3n+1)^2+9
\]

を意味します。\(n\ge104\) では右辺は隣り合う平方数
\((3n+1)^2\) と \((3n+2)^2\) の間にあり、矛盾です。
よって **\(n^2+2\) は合成数**です。この排除に有限探索は必要ありません。

合成数の場合も制約が残ります。任意の素因数 \(p\mid n^2+2\) に対し
\(w=(n^2+2)/p\) とおくと、

\[
\boxed{n<20000w^3+1\quad\text{（両分岐）}},\qquad
\boxed{n<240w^{3/2}+1\quad\text{（}k=r\text{）}}.
\]

従って、各素因数について

\[
\boxed{p<28n^{5/3}\quad\text{（両分岐）}},\qquad
\boxed{p<40n^{4/3}\quad\text{（}k=r\text{）}}.
\]

これは素数 \(p\) への上界であり、その正確な素数冪 \(p^{v_p(n^2+2)}\) への上界とは区別します。
また、\(n^2+2\) が素数になる \(n\) が無限に存在するという主張はしていません。

詳細：[合同式・補因子上界・素数の場合の排除](v15_neighbor_prime_obstruction.md)。

## 3. \(Q\mid r^3\) は、二乗では足りない

新たに

\[
\boxed{Q\nmid r^2}
\]

を示しました。既存の \(Q\mid r^3\) と合わせると、
\(Q\mid r^a\) を満たす最小の正整数 \(a\) は **正確に3** です。
従って、ある素数 \(p\) に対して

\[
2v_p(r)<v_p(Q)\le3v_p(r).
\]

この素数で \(v_p(Q)=3\) または \(v_p(Q)\ge5\) が必要です。
つまり、\(Q\) の全ての素因数指数が \(\{0,1,2,4\}\) に属する場合を排除できます。
特に **\(n\) と \(n-1\) の少なくとも一方に、素数の三乗が含まれます**。
2と3については \(Q\) の定義で約分される指数があるため、正確な指数条件は証明ノートの表を参照してください。

### 有限計算が全候補を尽くす理由

反対に \(Q\mid r^2\) を仮定し、\(L=r^2/Q\) とおくと

\[
Mr^2=Ln(n-1),\qquad 9M<L<\frac{10400M}{927}.
\]

\(M\in\{1,2,3,6\}\) なので、係数対 \((M,L)\) は **25組**に限られます。
また、既存の対数幅と整数 \(L\) の間隔から **\(n<e^{30}<2^{45}\)** が従います。
これは計算時間に合わせて設定した上限ではなく、仮定から証明した上限です。

\(ML=s^2d\)、\(d\) は平方因子を持たない、と分解すれば、

\[
x^2-dy^2=1,\qquad
n=\frac{x+1}{2},\qquad r=\frac{sdy}{2M}
\]

という通常の Pell 方程式になります。
全正解が最小の正単数の冪で尽くされることを本文中で証明し、各列の最初の上限外の点まで記録しました。

| 段階 | 残る件数 |
|---|---:|
| 25係数対の証明済み高さ未満の Pell 点 | 188 |
| 整数 \(n,r\) に戻る点 | 160 |
| \(n\ge104\) | 140 |
| 実際の \(M\) と一致 | 66 |
| \(3n<r<10n/3\) | 62 |
| 有理数による対数幅の必要条件を通過 | 11 |
| 元の二つの \(k\) の分岐 | 22 |
| 元の等式の合同条件を通過 | **0** |

最後の22件は、すべて **13以下の素数** \(p\) で
\(\binom Ar\equiv B\equiv0\pmod p\)、\(k^2\not\equiv0\pmod p\) となり排除できます。
巨大な二項係数の整数そのものを計算せず、各二項係数がゼロになる基数 \(p\) の桁を証明書に残しています。

別実装は、基本解を連分数から求め、二階漸化式で全列を再生成し、
元の \(k\) と \(j^2=(n-3)^2\) を使った Lucas の計算で全22件を再検証しました。
両実装の全件数と排除結果は一致しました。

詳細：[Pell 帰着の証明](v15_pell_square_divisor.md)、[全証明書](v15_pell_square_divisor_results.json)、[独立再検証](v15_pell_independent_audit.json)。

## 4. 必要な立方因子は、\(n\) とともに大きくなる

\(Q=ab^2\kappa^3\)、\(a,b\) は互いに素な平方因子を持たない整数、と分解します。
\(Q\mid r^3\) から \(r=ab\kappa v\) となる正整数 \(v\) が存在するので、

\[
K=\frac{\kappa r^2}{Q}=av^2\in\mathbb Z,
\qquad K>9M\kappa.
\]

ここで \(\log n\ge28\kappa\) と仮定すると、既存の対数幅から

\[
K-9M\kappa<\frac{50111163}{51380224}<1.
\]

整数 \(K\) が連続する二整数 \(9M\kappa\)、\(9M\kappa+1\) の間に入ってしまいます。
従って、

\[
\boxed{\log n<28\kappa,\qquad n<e^{28\kappa}.}
\]

前節と合わせて **\(\kappa\ge2\)**、かつ **\(\kappa>\log n/28\)** が必要です。
\(n\) が大きくなるほど、\(Q\) に含まれる立方因子も大きくなければなりません。
これは \(\kappa\) を固定したときの一様な高さ上限です。\(\kappa\) 自身には上限を与えていないため、第一添字全体の有限化ではありません。

詳細：[立方因子による高さ上限の証明](v15_cube_height.md)。

## 6. 残る問題がどう変わったか

v14からの条件として、\(n,n-1,n-2\) の少なくとも二つには、
それぞれ異なる11以上の素数が3の倍数でない指数で現れる必要があります。
v15では、さらに次を同時に満たす場合だけが残ります。

- \(Q\mid r^3\) だが \(Q\nmid r^2\) となる素因数指数の構造。
- \(\kappa\ge2\)、かつ \(\log n<28\kappa\) を満たす十分な立方因子。
- 合成数 \(n^2+2\) の全素因数が今回の上界を満たし、大きな素因数では \(6n-8\) が平方剰余になること。
- 以前の原始不足分、平方合同式、CRT、厳密区間などの必要条件をすべて満たすこと。

**原始不足分 \(H\ge21\) の数値下限は v12 のまま**です。
今回の前進は、この下限を順番に増やすことではなく、\(H\) に上限を置かずに
残存候補の個数と素因数構造を制限した点にあります。
残る構造が矛盾すること、あるいは実際の解を与えることは、まだ証明していません。
