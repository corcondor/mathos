# v30追補：法7の局所条件と法25・法20の結合合同ふるい

2026-11-07 JST。対象は入れ子二項係数方程式の \(\ell=1,\ j=i-3\) 枝から生じる**必要条件**である。
本追補は v28 の局所公式と v29 の5進条件を再利用し、独立に合同類の交差を検査したものであり、元の四変数方程式の全解決ではない。

## 既存結果と適用範囲

正整数 \(b\mid486,\ \rho>0\) と \(T=\rho/b^2\) を用いる。元問題の補助整数点が第二楕円商の巡回部分群 \(\langle R\rangle\) の点 \(mR\) に写ると仮定する。
既存の v20、v28、v29 から
\[
\rho\bmod9\in\{1,4,6,7\},
\quad m\equiv2,3\pmod5\quad(7\mid\rho),
\]
また（非例外の残差に対して）
\[
T\bmod25\in\{8,13,18,23\},
\]
を必要条件として使用する。\(T\equiv8\pmod{25}\) なら \(m\equiv8,12\pmod{20}\)、\(T\equiv23\pmod{25}\) なら \(m\equiv2,18\pmod{20}\) という v29 の既存条件を使用する。

> **重要**：巡回部分群に属さない特殊化された楕円曲線の有理点には、このふるいは適用できない。また \(\rho=2^{2u}\) または \(3\cdot2^{2u+1}\) という既存の2つの疎な例外族は、以下の合同類密度に現れない（自然密度0）。これらを排除したと主張しない。

## 定理（法7による指数の必要条件）

\(7\mid\rho\) とする。v28 式 (7) の局所公式を適用し、\(m=5k+2\) または \(m=5k+3\) に対して \(Z=X(mR)/T^2\) の7進還元を取る：
\[
Z\equiv\begin{cases}
1+4(-4)^k &(m=5k+2),\\
1-(-4)^{-k}&(m=5k+3)
\end{cases}\pmod7.
\]
\(7\nmid ab\) であるから、元問題の整数復元の必要条件は \(Z\ne0\) かつ \(\left(\frac{-3/Z}{7}\right)=1\)。\(-4\equiv3\pmod7\) の位数は6、\(-3\equiv4\) は平方剰余である。従って \(Z\) が非零平方剰余となる \(k\) は各分岐とも \(k\equiv2,3\pmod6\) のみ。

\[
\boxed{7\mid\rho\Longrightarrow m\bmod30\in\{12,13,17,18\}.}
\]

この結論は全整数 \(m\) についての必要条件で、有限な \(m\) の走査上限は仮定しない。v28 に記録済みの局所加法公式を入力とする。

## 合同類の残存率（誤解のない定義）

固定した \(b\mid486\) に対して、\((\rho,m)\in\mathbb Z^2\) を合同類の周期
\(M_\rho=9\cdot25\cdot7\cdot13=20475,\ M_m=60\)
で数える。\(\rho\bmod9\in\{1,4,6,7\}\)、\(13\nmid\rho\)、\(T\bmod25\in\{8,13,18,23\}\)、v29の \(m\) 条件、\(7\mid\rho\) なら上記条件を課す。

完全な剰余類数は
\[
\#\{(\rho,m)\bmod(M_\rho,M_m)\}=18240
\]
であり、
\[
\boxed{
\frac{18240}{20475\cdot60}
=\frac{304}{20475}
\approx1.484737485\%.
}
\]
これは巡回部分群からの復元に対する**必要条件の合同類密度の上界**であり、「元の方程式の全候補の98.5%を排除した」という主張ではない。個々の算術解は疎であり、自然密度の比較だけでは解の有限性も不存在も従わない。
