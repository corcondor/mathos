# v21：導出と厳密性の補遺

すべて自然対数。元の添字二乗方程式の `ell=1,j=i-3` 分岐を扱う。\(n\ge104\)、\(0<t<n/3\)、\(t>3\sqrt n\)、\(\rho\ge13\)、\(b\mid486\)、\(a,b\) は正整数で既約。\(n\ge1024\) では v20 より \(t>2n/(5\log n)\)。

## A. \(a^2<152\rho\log\rho\)

\(q=t^2+3t+3\)、\(H=9nq+t^3\)、\(D=81n(n-1)\) とする。定義から \(a/b=H/D\) および

\[
\frac{\rho}{b^2}=\frac{P}{D^2},\quad
P=H^2+HD(9n-t-6)-qD^2.
\]

直接展開すると

\[
P=t^6+n(18t^5+135t^4+540t^3)
+n^2(1215t^2-2916t-5832)+n^3(4374t+6561).
\]

\(t>3\sqrt{104}>30\) なので整数 \(t\ge31\)。よって \(1215t^2-2916t-5832>0\)、従って \(P>18nt^5\)。また \(q\le 11t^2/10\)（\(t^2-30t-30>0\)）、\(t<n/3\) より \(H<11nt^2\)。したがって

\[
\frac{a^2}{\rho}=\frac{H^2}{P}<\frac{121n}{18t}.\tag{A1}
\]

\(n\ge1024\) なら v20 の \(t>2n/(5\log n)\) より

\[
\frac{a^2}{\rho}<\frac{605}{36}\log n.\tag{A2}
\]

\(\log n<9\log\rho\) を示す。\(n<2^{25}\) では \(\log n<25\log2<35/2<18<9\log\rho\)（\(\log2<7/10\)、\(\rho\ge13>e^2\)）。\(n\ge2^{25}\) では \(b\ge1\) と \(P>18nt^5\) から

\[
\rho>\frac{18t^5}{6561n^3}>
\frac{64}{2278125}\frac{n^2}{(\log n)^5}.\tag{A3}
\]

関数 \(n^{3/2}/(\log n)^5\) は \(\log n>10/3\) で増加し、\(n=2^{25}\) において

\[
\frac{64\cdot2^{37}}{2278125}>
\left(\frac{35}{2}\right)^5
\]

（両辺の分母を払って \(64\cdot2^{42}>2278125\cdot35^5\)）。ゆえに (A3) は \(\rho>\sqrt n\) を意味し、\(\log n<2\log\rho\)。これで \(n\ge1024\) の全域で \(\log n<9\log\rho\) が成立し、(A2) から \(a^2<(5445/36)\rho\log\rho<152\rho\log\rho\)。

\(104\le n<1024\) では (A1) に \(t>3\sqrt n\) を用い \(a^2/\rho<121\sqrt n/54<121\cdot32/54<72<152\log\rho\)。全域で成立。

**高さ移送**：v18 に証明された \(n<36a^5/(b\rho^2)\)、\(b\ge1\) と \(36^2\cdot152^5<2^{48}\) の整数比較で
\[
n<2^{24}\sqrt\rho(\log\rho)^{5/2}.
\]

## B. \(\delta\) 係数との二次式と判別式

v19 の \(M,Q,\delta,C,K,g,c,h\) に対して \(x=h/c=r^2/[n(n-1)]\)。\(A_0=a/b\)、\(S_0=\rho/b^2\) を導入し、\(A_0=H/D\)、\(S_0=P/D^2\)、\(x=(3n+t)^2/[n(n-1)]\) を同時に代入する。

\[
\begin{aligned}
L_0&=(A_0^2-6A_0-S_0-3)(A_0^2+6A_0-S_0-3),\\
T_0&=13A_0^4-17A_0^2S_0-6A_0^2+4S_0^2+15S_0+9,\\
W_0&=5A_0^2+4S_0+3.
\end{aligned}
\]

分母を払うと、\(E=n(n-1)\)、\(R=3n+t\)、\(P=H^2+HD(9n-t-6)-qD^2\)、\(D=81E\)、
\[
\begin{aligned}
\widehat L&=(H^2-6HD-P-3D^2)(H^2+6HD-P-3D^2),\\
\widehat T&=13H^4-17H^2P-6H^2D^2+4P^2+15PD^2+9D^4,\\
\widehat W&=5H^2+4P+3D^2
\end{aligned}
\]

とおいた恒等式
\[
\boxed{\widehat L R^4-18\widehat T R^2E+81\widehat W^2 E^2=0}
\]

を得る。これは \(\mathbb Z[n,t]\) 上の全係数が0であることを、独立実装 `v21_residual_verify.py` の疎多項式演算で確認している。\(L_0=\mathcal L/b^4\)、\(T_0=\mathcal T/b^4\)、\(W_0=\mathcal W/b^2\) より \(\mathcal L h^2-18\mathcal T hc+81\mathcal W^2c^2=0\)。何も除算していない。

さらに \(\mathbb Z[a,b,\rho]\) の恒等式
\[
324(\mathcal T^2-\mathcal L\mathcal W^2)=11664a^2F
\]

も疎多項式による全係数比較で証明書化した。\(\gcd(c,h)=1\) を使い上の二次式を法 \(c\)、法 \(h\) でとれば \(c\mid\mathcal L\)、\(h\mid81\mathcal W^2\)。\(h>9c\ge9\delta\)、\(a^2<152\rho\log\rho\)、\(b\le486\) を入れれば
\[
\delta<9(760\rho\log\rho+4\rho+3\cdot486^2)^2.
\]

## C. 完全有限監査の境界

計算範囲 \(13\le\rho\le4096\) は元式に由来する \(a^2<152\rho\log\rho\) によって各 \(\rho\) ごとに**無条件に完結**し、人工的な \(n\) や \(a\) の打切りを持たない。\(\log\rho<\rho.\mathrm{bit\_length}()\) により正確な整数平方根のみで \(a\) の全上限を求める。以下の必要条件をすべて使う：

- \(b\mid486\)、\(27a\ge31b\)、\(\gcd(a,b)=1\)
- \(\rho\bmod9\in\{1,4,6,7\}\)、\(\gcd(a,\rho)=\gcd(a,3)\)、\(\rho\equiv a+b\bmod2\)、\(\rho\equiv a^2\bmod b\)
- \(a^2>b^2+\rho\)、\(1377\rho<216a^2+760b^2\)
- \(F(a,b,\rho)\) が整数平方、**両符号**の \(t\) が正整数、復元 \(n\) が整数、\(n\ge104\)、\(t^2>9n\)、\(3t<n\)
- \(\delta=Q/\gcd(Q,r^2)\ge25\)、元の二項係数等式を \(k=r,A-r\) の**両方**で別々に Lucas 剰余検査

生成器は直接 sextic と \(n\) の線形復元、独立検査器は因数分解した sextic \(F=b^2(6a^2+2b^2+3\rho)^2+4(a^2-b^2-\rho)^3\) と \(n\) の**別の二次判別式**を使う。独立検査器の反復は \(b\) ごとの平方剰余類から進め、両者の完全件数・8候補・小素数の排除を照合して `PASS` を得た。有限領域の完全性は列挙アルゴリズムを前提とする計算機援用証明であり、Lean のカーネル証明や第三者査読を装うものではない。
