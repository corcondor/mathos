# v16：実際の不足約数、五分の三の下側評価、二次式の素因数制限

2026年11月6日 JST。

## 今回の到達点

元の方程式は、引き続き上下の添字を二乗する

\[
\binom{\binom ij}{\binom{k}{\ell}}
=\binom{i^2}{j^2}+\binom{k^2}{\ell^2}
\]

です。今回の結果は **\(\ell=1,\ j=i-3\)** の枝に対するものです。

\[
n=i,\quad A=\binom n3,\quad B=\binom{n^2}{6n-9},\quad
r=\min(k,A-k),\quad t=r-3n,
\]

\[
M=\gcd(n,3)\gcd(n-1,6),\qquad Q=\frac{n(n-1)}M
\]

とおきます。**\(k=r\) と \(k=A-r\) の両分岐**を含みます。
既存の入力は \(n\ge104\)、\(M\in\{1,2,3,6\}\)、\(Q\mid r^3\)、
\(3n<r<10n/3\)、および \(n\ge1024\) のときの対数幅です。

| 項目 | v16で得られた結果 |
|---|---|
| 実際の不足約数 | \(\delta=Q/\gcd(Q,r^2)\) に対して **\(\delta\ge13\)**、**\(\log n<28\delta\)** |
| 原始不足分との関係 | \(H=A/\gcd(A,r^3)\) に対して **\(\gcd(\delta,H)=1\)**、**\(\delta^3\mid A/H\)** |
| \(r\) の新しい下限 | **\(t+3>n^{3/5}/64\)**。全素数・全 \(H\) に一様 |
| 二次式の素因数 | **\(P^+(n^2-10)<r\)**。剰余条件に応じて他の二次式にも同時適用 |
| 重複する大きな素因数 | \(p^2\mid n^2-10\)、\(p^2>6n-9\) なら、小さい \(k=r\) の枝は排除。残る枝でも指数は正確に3 |

\(P^+(u)\) は \(u>1\) の最大素因数です。
今回も、元の四変数方程式全体の解決や具体解の発見には至っていません。

## 1. 立方因子全体から、実際に不足している部分へ

v15では、\(\kappa^3\mid Q\) となる最大の正整数 \(\kappa\) を使い、
\(\log n<28\kappa\) を得ていました。
今回使うのは

\[
\boxed{\delta=\frac{Q}{\gcd(Q,r^2)}}
\]

です。これは **\(r^2/Q\) を既約分数にしたときの分母**です。
素数ごとに \(\alpha=v_p(Q)\)、\(e=v_p(r)\) とすると、

\[
v_p(\delta)=\max(\alpha-2e,0).
\]

\(Q\mid r^3\) により \(\alpha\le3e\) なので、

\[
\boxed{\delta\mid r,\qquad \delta^3\mid Q,\qquad\delta\mid\kappa.}
\]

また、

\[
K=\frac{\delta r^2}{Q}\in\mathbb Z_{>0},\qquad\gcd(K,\delta)=1.
\]

\(\log n\ge28\delta\) と仮定すると、v15と同じ整数間隔の議論がこの \(K\) に適用でき、

\[
0<K-9M\delta<\frac{50111163}{51380224}<1
\]

となって矛盾します。従って、

\[
\boxed{\log n<28\delta,\qquad n<2^{42\delta}.}
\]

\(\delta\le\kappa\) なので、\(r^2\) に既に吸収されている立方因子を除いた、より強い条件になっています。

### 正確な構造と、以前の \(H\) との接続

\(Q\mid r^3\) となる正整数対は、正確に

\[
Q=\delta^3ab^2,\qquad r=\delta abu,
\qquad a\text{ は平方因子を持たず、}\gcd(\delta,au)=1
\]

と書けます。逆も成立します。ここでは \(b\) は平方自由とは限りません。

さらに、\(p\mid\delta\) の各素数では \(v_p(A)=v_p(Q)\) が成り立ちます。
2と3での約分も調べると、既存の原始不足分
\(H=A/\gcd(A,r^3)\) との間に

\[
\boxed{\gcd(\delta,H)=1,\qquad\delta^3\mid A/H}
\]

が得られます。二種類の不足分が同じ素数を共有できない、という接続です。

詳細：[不足約数の構造・高さ・Pell帰着](v16_square_defect_pell.md)。

## 2. \(\delta\le12\) をまとめて完全排除

固定した \(\delta\) について \(C=M\delta\) とおくと、

\[
Cr^2=Kn(n-1),\quad \gcd(K,\delta)=1,
\quad9C<K<\frac{10400C}{927}.
\]

係数 \(K\) の区間が有限になり、\(CK=s^2d\)、\(d\) は平方因子を持たない、と分解すれば、

\[
x^2-dy^2=1,\qquad
n=\frac{x+1}{2},\qquad r=\frac{sdy}{2C}
\]

へ帰着できます。先に証明した \(n<2^{42\delta}\) の下で、基本解の冪を尽くせば全候補が得られます。

今回、\(1\le\delta\le12\) を一括して処理し、別実装でも全結果を再現しました。

| 段階 | 両実装で一致した件数 |
|---|---:|
| 係数三つ組 \((\delta,M,K)\) | 1,223 |
| 異なる非平方の根号内の整数 | 570 |
| 証明済み高さ未満の全Pell点 | 34,010 |
| 整数 \(n,r\) に復元 | 24,114 |
| \(n\ge104\) | 23,920 |
| 実際の \(M,\delta\) と一致 | 9,324 |
| \(Q\mid r^3\) | 1,929 |
| 粗い厳密区間を通過 | 1,762 |
| 対数幅の必要条件を通過 | 123組 |
| 元の二つの \(k\) の分岐 | 246件 |
| 元の等式を合同条件で排除できずに残るもの | **0件** |

全246件が、**23以下の素数**を法として左右不一致になります。
242件は両二項係数がゼロになる型ですが、4件は別の剰余の不一致です。
この違いも全証明書と監査に記録しています。
最終候補には150桁の第一添字も含まれます。これは必要条件を通過する候補で、元方程式の解ではありません。

以上により、

\[
\boxed{\delta\ge13,\qquad\kappa\ge13.}
\]

さらに、ある整数 \(b\ge5\) の三乗が \(n\) または \(n-1\) を割ります。
理由は、二つの正規化因子に分かれる立方根部分が互いに素で、その積が13以上だからです。
両方が4以下なら積は最大12にしかなりません。
ここで \(b\) は素数である必要はなく、必ず \(5^3\) が割るという意味でもありません。

### 任意の固定した不足分にも使える有限化

帰着の仕組み自体は12までに限定されません。固定した \(\delta\) について、
係数族は最大 \(27\delta-1\) 本、各族で必要な基本解の冪は最大 \(28\delta+1\) 個です。
従って、調べるPell点は

\[
\boxed{(27\delta-1)(28\delta+1)}
\]

個以下です。\(\delta\le D\) をまとめても、

\[
\boxed{126D(D+1)(2D+1)-\frac{D(D+1)}2-D}
\]

個以下です。これは候補点数の上界であり、基本単数計算のビット計算量や、無制限の \(\delta\) に対する有限性は主張しません。

詳細：[全証明書の概要](v16_square_defect_pell_summary.json)、[独立監査](v16_square_defect_independent_audit_note.md)。

## 3. \(r\) が \(3n\) に近すぎる領域を一様に排除

\(t=r-3n\) とおくと、新たに

\[
\boxed{n^3<2^{30}(t+3)^5}
\]

を得ました。同値な形は

\[
\boxed{t+3>\frac{n^{3/5}}{64}},\qquad
\boxed{n<1024(t+3)^{5/3}}.
\]

この証明には、今回のPell計算、\(H\) の上限、素数の上限、有限探索は不要です。

### 証明の中心となる二段階の整数間隔

\(Q\mid r^3\) と恒等式

\[
r^3=(27n+27t+27)n(n-1)+(9t^2+27t+27)n+t^3
\]

から、

\[
h=\frac{M\{(9t^2+27t+27)n+t^3\}}{n(n-1)}
\in\mathbb Z_{>0}
\]

が得られます。これは \(n\) の二次方程式

\[
hn^2-\{h+M(9t^2+27t+27)\}n-Mt^3=0
\]

を与えます。判別式の平方根は整数です。
この平方根を、分母を \(729M\) に固定した有理二次式で近似すると、
正の差は少なくとも \(2/(729M)\) 必要になります。
一方、平方の差を正確に展開し、\(h<28M(t+3)^2/(3n)\) と組み合わせると、

\[
n^3<\frac{124567589888}{153}(t+3)^5<2^{30}(t+3)^5
\]

となります。近似誤差は漸近記号で捨てず、符号を含めて多項式恒等式で処理しています。

既存の対数上界と合わせると、\(n\ge1024\) では

\[
\boxed{
\max\left(3,\frac{n^{3/5}}{64}-3\right)
<r-3n<\frac{3n}{4\log n}
}
\]

が必要です。上下の条件は大きな \(n\) でも両立し得るため、これだけで全非存在を示したことにはなりません。
また、この結果だけでv15の候補数 \(O(\sqrt X\log X)\) がさらに改善したとは主張しません。

詳細：[五分の三の下側評価の全証明](v16_lower_gap.md)。

## 4. \(n^2-10\) の最大素因数を \(r\) 未満に抑える

新しく

\[
\boxed{P^+(n^2-10)<r<\frac{10n}{3}}
\]

を示しました。\(n\) の剰余条件はありません。

恒等式

\[
A-(2n-5)=\frac{(n-3)(n^2-10)}6
\]

により、\(p\mid n^2-10\)、\(p>r\) なら、\(A\bmod p=2n-5<r<p\) なので
外側の二項係数は法 \(p\) でゼロです。

内側の \(B=\binom{n^2}{6n-9}\) も、Lucasの桁の条件からゼロになります。
ここでは \(r<p\le6n-9\) の範囲も処理しています。
ゼロを逃れる可能性は \(p=6n-9-t_0\)、\(0\le t_0\le10\) に限られますが、
このとき \(p\mid(9+t_0)^2-360\) となり、非零の小さい整数を大きな \(p\) が割る矛盾が生じます。

両二項係数がゼロで \(k^2\) だけが非零となるため、元の式は成立しません。
境界 \(p=r\) は \(Q\mid r^3\) によって別途排除しています。

### 複数の二次式に同時に適用できる

一般に \(0\le c\le16\)、\(6\mid(c+2)n-3c\) なら

\[
\boxed{P^+(n^2-c)<r}.
\]

通常の因数分解で分かる平方の \(c\) を除くと、同時に適用される条件は次のとおりです。

| \(n\bmod6\) | 制約される \(n^2-c\) の \(c\) |
|---|---|
| 0 | 2, 6, 8, 10, 12, 14 |
| 1 または5 | 7, 10, 13 |
| 2 または4 | 10 |
| 3 | 2, 3, 5, 6, 7, 8, 10, 11, 12, 13, 14, 15 |

任意の該当する素因数の補因子 \(w=(n^2-c)/p\) について、\(3n\le10w\) も必要です。
例えば \((n^2-10)/\gcd(n^2-10,6)\) は必ず合成数になります。
別の議論により、\(n\equiv3\pmod6\) なら \(P^+(n^2+1)\le6n-9\) も得ました。

詳細：[二次式の同時制約](v16_quadratic_neighbors.md)。

## 5. 大きな素数の二乗が含まれる場合は、分岐と指数まで決まる

さらに、任意の素数 \(p\) に対して

\[
p^2\mid n^2-10,\qquad p^2>6n-9
\]

が成り立つ場合を調べました。この場合、

\[
\boxed{k=A-r,\qquad v_p(n^2-10)=3,
\qquad v_p(r-(2n-5))=1}
\]

が必要です。従って **小さい方の分岐 \(k=r\) では、このような素因数は存在できません**。

証明では、二項係数の素因数指数を階乗から正確に求めます。
例外になり得る素数は、11個の明示的な整数
\((9+t_0)^2-360\)、\(0\le t_0\le10\)、の素因数に限定できます。
その例外と境界の小さい素数は、法 \(p^2\) の平方根をすべて求めて処理しました。
最後に残る \(n=275,5382\) も、既存の \(Q\mid r^3\) と厳密区間で排除できます。

この付値の議論では \(p\mid6n-9-t_0\) しか分からず、\(p=6n-9-t_0\) とは限りません。
前節の端点の議論と違い、\(t_0\) を偶数に限定せず、\(p=41\) も含む全例外を処理しています。

詳細：[重複する素因数の全素数に対する分類](v16_repeated_neighbor_primes.md)。

## 7. 残る問題

原始不足分の数値下限 **\(H\ge21\)** と、v15の第一添字の個数 **\(O(\sqrt X\log X)\)** は据え置きです。
v16で加わったのは、\(H\) と互いに素な実際の不足約数、\(r\) の下側の幅、複数の二次式の素因数構造への制限です。

残る候補は、\(\delta\ge13\)、\(\log n<28\delta\)、\(\gcd(\delta,H)=1\)、
五分の三の下限、二次式の素因数制限、v14の二因子の大きな素数条件、
従来の付値・平方合同式・CRT条件をすべて同時に満たす必要があります。
これらを同時に満たす整数が存在しないことも、実際の解が存在することも、まだ示していません。
