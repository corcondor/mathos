# 近似分数の候補被覆と有限分母列の区間選択

`v10_formal/CFCandidateCoverage.lean` は既存の係数範囲補題を、近似分数の被覆へ接続する2定理。
正確な仮定と型はLeanソース、検証結果は `additional_kernel_check.json` と `deepseek_generation_checks.json` に記録する。

## 近似分数から係数と候補集合への接続

`reduced_approximation_mem_coefficientCandidates` は、整数の連続した3列、行列式の絶対値1、分母の正値・順序、次の列への漸化式、既約性、誤差評価から、整数係数a,b,cを導出する。
係数の存在は `unimodular_coordinates_abs` を使い、行列式−1の場合も含む。

結論は次を同時に満たす係数の存在である。

- `p=aP+bP_previous`, `q=aQ+bQ_previous`。
- `c=a-b*aNext`。
- `p=bP_next+cP`, `q=bQ_next+cQ`。
- `(a,b)` は `coefficientCandidates aNext` に入る。

元の近似条件 `|alpha-p/q|<3/(2q²)` を保つ。
候補集合の要素数65以下は、既に検証した `coefficientCandidates_card_le` を再利用できる。
次の列の誤差には `|Q_next*alpha-P_next|<1/Q_next` を仮定する。
実CFの `1/Q_nextnext` 評価からこれを供給するには、次の分母がさらに大きいことを証明する必要がある。

## 有限な証明書から区間を選ぶ

`finite_prefix_interval` は自然数列Q、正の長さnについて、`Q0=1`、隣接項の厳密増加、`H≤Qn`、`1≤q<H` から、
`i<n` かつ `Qi≤q<Q(i+1)` となる添字を導出する。
無限列の収束や任意の実数の連分数理論を仮定しているという意味ではなく、実際の有限証明書の分母列に適用するための一般補題である。

## 実施と残る課題

DeepSeekに既存Leanソース、v9の実証明ノート、研究スキル・状態・参考資料を渡し、max指定で次の定理を検討させた。
APIはmaxと出力上限131072を受理し、提案には63.8秒・25004推論トークンを使用した。
このAPI受理をHighとの品質比較の実験とは扱わない。
固定後の2定理の証明本文と修正はDeepSeekが担当し、両方とも初回のLean検査を通過した。
ホストは証明本文を手作業で編集していない。

まだ必要なのは、実際の収束分数・証明書から行列式、漸化式、既約性、誤差評価、分母の単調性・終端の高さを供給する接続。
自然数の有限分母列と、整数で表した列の被覆定理の間のキャストも実データ側で結ぶ必要がある。
有理な立方根の場合の別処理、円筒区間認証、全5214曲線の必要条件の検査、最終定理への接続は未完了。
従って30余因子最終定理のCF仮定を外した、元の四変数方程式を解決した、とは主張しない。
