## 1. 平方根境界と h/M の有限領域

証明ノート： [v17_square_root_gap.md](v17_square_root_gap.md)。

有限性は `h/(81M)=a/b`、`b|486` と正整数残差の上限から得る。
`h/M<93` の全領域は557係数対・94,710残差であり、nの走査上限は用いない。
生成器は各残差の分類、平方判別式の両根、整数復元結果を省略せず保存する。

独立監査器は、すべてのMをM=6に換算した生変数Hと生の残差から、
別の消去二次式でtを求め、元のhの判別式からnを再構成する。
生成器をimportも実行もしない。以下が全件一致した。

| 項目 | 件数 |
|---|---:|
| 係数対 | 557 |
| 残差 | 94,710 |
| 平方判別式 | 272 |
| 整数t>=4 | 30 |
| 整数n>=104・必要条件を満たす組 | 13 |
| t²<9n | 0 |
| t²=9n | 13 |
| 元のk分岐の合同式による排除 | 26 |

元式の合同証拠は元の添字 `(n-3)^2` を用いる。
24件では両二項係数がゼロ、n=5329の2件では内側が法5で3となる。
「26件すべてで両二項係数がゼロ」とはしていない。

復元時にt²<=9nを仮定していないため、原式ではh>=93Mも従う。
そこからの `(t+3)^2>31n/3` は正確な多項式差と不等式で確認した。
旧条件だけではh>81Mが鋭いが、その達成例は原式の解ではない。

楕円曲線への変換、判別式、唯一の正の既約特異係数(1,3)も確認した。
特異係数は捨てずに処理した。完全な整数点ソルバーやランク計算は行っていない。

## 2. 主添字・複数二次式の素数冪

証明ノート： [v17_quadratic_prime_powers.md](v17_quadratic_prime_powers.md)。

主添字n,n-1の大きな素因数を排除する一般部分は、階乗の付値と
基数pの繰り上がりを数える記述証明である。有限サンプルからの外挿ではない。

負側の12オフセットで、反復素数の付値公式が例外を持つ条件を
118個の定数に帰着した。全根表は**69組**。
初稿の68という数は訂正し、証明・生成器・独立監査・進捗文面で69に統一した。
生成器のHensel持ち上げと、独立監査器の法p²の全剰余検査が一致した。
残る4添字149,157,275,5382は、必要な立方整除の最小倍数だけで排除した。

一般付値の支持検算、実際の二項係数、共通合同補題の数値検査は、
定理の全称命題を置き換えない。支持検算の件数と全例外領域の件数を区別した。

正側のLCM二乗条件にはn=3 mod6が必要である。
負側の同時積の強い数値上界は小さい分岐のみ。
「12式のうち8式が平方自由」とは主張せず、p²>mの大きな反復素数に限定する。

## 3. n²+2 の補因子と不足約数

証明ノート： [v17_neighbor_defect.md](v17_neighbor_defect.md)。

素因数pに対するw=(n²+2)/p<=64の領域を、小さい係数c0,c1の立方の約数へ還元した。
生成器は素因数の指数から約数を作り、独立監査器はdとN/dの対を完全に列挙する。
両者はすべての係数族・第二整除通過点・整数p・最後の平方境界に一致した。

| 項目 | 件数 |
|---|---:|
| 係数族 | 8,712 |
| 約数生成点 | 590,028 |
| 正規化後n | 350,188 |
| 第二整除通過 | 1,260 |
| 整数p | 20 |
| p>6n-9 | 11 |
| 平方復元 | 0 |

pの素数性を課さない、より広い必要候補集合を排除した結果である。
生成された最大n=1,816,487,208は走査の端点ではない。
p<=m側は証明から104<=n<=383に限定される。独立監査では全22,540個のrを直接確認し、
残る4組のdelta=1,1,5,1を既存のdelta>=13で除外した。

全証明書は269,767 bytesのJSONを49,290 bytesのgzipに損失なく保存した。
圧縮前後のSHA-256を生成器・監査器・manifestに記録する。

不足約数deltaの移送は2,3を含む全素数で有効であり、wの可逆性を仮定しない。
固定J=z-9wの多項式高さはp>mかつk=rの結果である。
deltaまたはJの全域に上限が付いたとは主張しない。

## 4. 実行と成果物の同一性

最終保存ディレクトリで、3生成器と3独立監査器をすべて再実行し、
終了コード0と各記録のPASSを確認した。これらはPython標準ライブラリのみを使う。

補助的にSymPy 1.14.0で、平方根境界の復元二次式、判別式、
楕円曲線の座標恒等式・判別式、追加下限の計5恒等式を独立展開した。
すべての係数が一致した。この追加監査も終了コード0・PASS。
SymPyはこの補助スクリプトだけの依存であり、完全CASソルバーではない。

[v17_manifest.json](v17_manifest.json) は、前段入力のGit blob SHA、
各ファイルのbytes・SHA-256・Git blob SHA、再現コマンド、検証範囲を記録する。
manifest自身の自己ハッシュは含めない。
