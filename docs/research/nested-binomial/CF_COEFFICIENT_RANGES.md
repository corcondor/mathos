# 連分数の係数範囲と65候補の形式化

`v10_formal/CFCoefficientRanges.lean` は、v9の連分数ノート3.3–3.4節に対応する6補題を固定し、DeepSeekに証明生成・修正を委任したもの。
正確な型と証明本文はLeanソース、実行結果は `v10_formal/additional_kernel_check.json` を参照する。

| 補題 | 検証する内容 |
| --- | --- |
| `b_strict_bound` | 小分母側 `2q<N` では `|b|<3Q/(2q)+1/2` |
| `smaller_half_a_bounds` | `b≠0`、`|b|≤2`、前記評価と分母の表示から `−1≤a≤4` |
| `smaller_half_b_zero` | `b=0` に対応する整数倍の表示と既約性・正分母から `a=1` |
| `larger_half_c_bounds` | 大分母側 `Q_next≤2q`、次の列の誤差評価と行列式から `−3≤c≤3` |
| `coefficientCandidates_spec` | 明示した有限集合と2種類の係数範囲が同値 |
| `coefficientCandidates_card_le` | 任意の整数 `aNext` について候補集合の要素数が65以下 |

近似定数は元の `3/(2q²)` を保つ。`1/(2q²)` の標準Legendre条件へ置き換えていない。
小分母側は `0≤Q_previous≤Q`、`Q≤q`、`q=aQ+bQ_previous` を使う。
大分母側は `p=bP_next+cP`、`q=bQ_next+cQ` と、その2列の行列式の絶対値1を仮定する。
正の分母、既約性、誤差評価など、各型に明記した仮定を満たす場合に適用する補題である。

候補集合は、`−1≤a≤4, −2≤b≤2` の30組と、
`−2≤b≤2, −3≤c≤3, a=b*aNext+c` で生成する35組の和集合。
重複があり得るため、要素数は「ちょうど65」ではなく「65以下」。

## 残る接続

このモジュールだけで元の方程式の候補の網羅性や全曲線の排除を証明したとは扱わない。
以下は別途必要である。

- 対象の分数について `Q_m≤q<Q_(m+1)` となる区間を選び、その存在と網羅性を証明する。
- 実際の収束分数データから、行列式・誤差評価・既約性・分母の単調性を供給する。
- `c=a−b*aNext` と次の列への書き換えを、上記補題と1つの候補被覆定理へ接続する。
- 連分数の円筒区間を認証し、全5,214曲線の証明書をLeanで検査し、最終定理へ接続する。

従って30余因子最終定理の連分数仮定は、現時点ではまだ外れていない。

## 委任と定理文の固定

実際のv9ノートとPython検証コード、検証済みCFApproximationCore、研究スキル、状態、参考リポジトリ要約をDeepSeekに送った。
モデル提案のimportとJSON形式、定義の余分な括弧、未使用のパラメータをホストが定理固定前に正規化した。
候補数65以下の定理も固定し、全6証明の本文と修正はDeepSeekが作成した。
成功した証明本文の手作業での変更は行わない。
