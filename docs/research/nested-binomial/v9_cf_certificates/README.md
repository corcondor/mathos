# v9：連分数の完全な有限証明書

`S01.json`〜`S12.json` は、それぞれ固定した整数 S に対する
全 T=162S+1,...,229S−1 の連分数係数を保存している。
合計5,214曲線、4,877,566個の連分数係数を含む。

各JSONは、完全な係数列を zlib で圧縮し、base64のテキストとして
`data` フィールドに入れている。省略した係数はない。
復元後の形式は `[T, [a0,a1,...]]` の配列で、立方根が有理数の
一件は係数列が `null` となる。圧縮前後のSHA-256も記録する。

親ディレクトリで次を実行すると、全内容を復元して厳密検証する。

```sh
python3 v9_gcd_defect_cf_checks.py verify
```

再生成する場合：

```sh
python3 v9_gcd_defect_cf_checks.py generate
```

検証器は生成に使った立方根計算法を使わず、連分数区間の両端の
三乗を整数演算で比較する。これで根を挟むこと、全係数列が正しいこと、
証明された分母上限に到達したことを確認してから、完全な65組の
近似補題で候補を再構成する。詳しい証明は
[v9_gcd_defect_continued_fractions.md](../v9_gcd_defect_continued_fractions.md) を参照。

この連分数の完全性の証明と全検査は、まだLean形式化していない。
v9_formal のLean記録は、余因子2の別証明に現れる2,592件を対象とする。
