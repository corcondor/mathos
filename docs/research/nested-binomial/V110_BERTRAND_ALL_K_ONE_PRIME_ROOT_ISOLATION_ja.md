# v110：任意の k に適用できる単一大素数・有限体の完全解判定（Legendre予想・R_kの因数分解不要）

2026-11-13。ユーザーの「任意のkでやる方法ないの？」に対する、**数学的に無条件かつ全てのkで実行可能な代数的判定法**。v109の平方間素数の条件やv108の「良い素因数の個数」という未証明仮定を外す。注意：**全kに適用できる完全な判定アルゴリズム**と、**全kの無解を一度に証明する全称定理**は異なる。後者は今回も未達。

## 0. 正確な対象
元の4変数方程式
\[
\binom{\binom ij}{\binom{k}{\ell}}=\binom{i²}{j²}+\binom{k²}{\ell²}
\]
の枝 \(j=1,\ell=k-1\) は
\[
\boxed{\binom{i}{k}=i²+R_k,\quad R_k=\binom{k²}{2k-1}}.\tag{110.1}
\]
k=2は \(\binom i2<i²+R_2\) で無解。以後k≥3。
旧v100の単調性・v101の初等高さ評価から、**整数解が存在するなら** \(2k<i<k³\)。

## 1. ベルトランの定理が、全kで「使える素数」を無条件に作る

**任意の整数k≥3に対して**、Bertrandの定理により少なくとも1個の素数
\[
\boxed{k³<q<2k³}\tag{110.2}
\]
がある。この素数qは \(q>k²>2k-1\) を満たすから、\(k!\) と \((2k-1)!\) のいずれも \(\bmod q\) で逆元を持つ。

大きな \(R_k\) を計算せず、次の小さな約2k項だけで
\[
\boxed{
c_k\equiv R_k\equiv
\left(\prod_{h=0}^{2k-2}(k²-h)\right)\cdot((2k-1)!)^{-1}
\pmod q
}\tag{110.3}
\]
を求められる。**R_kの素因数分解もq|R_kも必要ない**。実際q>k²なのでqはそもそもR_kの素因数ではない。

次のモニックな次数k多項式を定義する：
\[
\boxed{
F_{k,q}(X)=\prod_{h=0}^{k-1}(X-h)-k!X²-k!c_k
\in\mathbb F_q[X].
}\tag{110.4}
\]
元の自然数等式(110.1)を満たす整数iは \(F_{k,q}(i)=0\) in Fq。ところが
\(2k<i<k³<q\)、つまり**整数iのq剰余はi自身**。

従って、\(F_{k,q}\) のFq上の全根集合
\[
\mathcal R_{k,q}:=\{r\in[0,q):F_{k,q}(r)=0\bmod q\}
\]
のうち \(2k<r<k³\) を満たすものだけが、元等式の**完全な整数候補**。次数がkで先頭係数1なので
\[
\boxed{|\mathcal R_{k,q}|\le k.}\tag{110.5}
\]
**任意のkに対し、最大k³個だった整数iを、高々k個の完全な候補へ、unconditionally縮約**。
各候補rについて巨大でもk項の二項係数 \(\binom rk\) と \(R_k\) を整数演算で比較し、完全に解の有無を決められる。全整数iの逐次走査は不要。

## 2. 有限体の根の完備性を何で証明するか

有限体上では \(X^q-X\) がFqの全元をちょうど単純根として持つため、
\[
\boxed{
H_{k,q}(X)=\gcd_{\mathbb F_q[X]}(F_{k,q}(X),X^q-X)
=\prod_{r\in\mathcal R_{k,q}}(X-r)
}\tag{110.6}
\]
が厳密な恒等式となる。右辺の積に重複はない。\(X^q-X\) を次数qまで展開してはならない。\(X^q\bmod F\) を繰り返し平方して次数k未満に保ち、Euclidのアルゴリズムでgcdを求める。
有限体でHを一次因子へ分けるにはBerlekamp/Cantor–Zassenhaus等の標準アルゴリズムが利用できる。**出力された根の完全性は、右の線形因子積が左のgcdに一致することを別途検証できる**。
したがって一つのqでroot-free \(\gcd=1\) なら、全自然数iを**高さ評価さえ不要で即時排除**。根があるときは、まだ等式の解を意味しないので候補を整数再検算する。

理論上は素数qの選択も確定的な素数判定＋Bertrandの保証で有限停止。性能上は確率的なfinite-field factoring（出力証明書は整数mod演算で独立チェック）を使えるが、確率的因数分解の提出結果を直接証明と呼ばない。

## 3. 平方間素数を使わず、2桁Henselに減らす変種

Bertrandを \(k²\) に適用して \(k²<q<2k²\) と取っても
\[
\boxed{q²>k^4>k³.}
\]
従って、F_{k,q}の根をmodq²へ持ち上げれば同じ高さ区間を覆える。qが\(R_k\)を割る必要なし。**単純根**なら一意にHensel持ち上げ。重根の場合、q個の次桁分岐を特別に検査する必要があり、全kで重根が存在しないとは主張しない。1桁q>k³の手順ならこの重根問題を回避する。

## 4. 独立した「全k無解」という本当の目標

一般kの単項式
\[
P_k(X)=\prod_{h=0}^{k-1}(X-h)-k!X²-k!R_k\in\mathbb Z[X]
\]
には、元式の整数解iがあれば必ず一次因子 \(X-i\) がある。よって
\[
\boxed{\forall k\ge3,\quad P_k(X)\text{に整数根はない}}\tag{110.7}
\]
を数学的に証明すれば枝全体は解決する（逆も同じ）。もっと強い \(P_k\) の \(\mathbb Q\) 上の既約性を示してもよいが、単なる有限個のkの既約性や有限体でのroot-free例では全称証明にならない。
今回のBertrandの選び方は、全てのkの**個別の厳密判定法**にはなるが、式110.7をすべてのkについて一度に証明するものではない。

この多項式は「連続一次因子の積 + 多項式の摂動」というSchur/Pólya型の既存分野と関係する。ただし既知の小摂動の既約性定理を、巨大なk! R_k定数へ無条件で適用できるわけではない。
文献：A. Schinzel型の古典研究; *Irreducibility criteria of Schur-type and Pólya-type*, https://link.springer.com/article/10.1007/s00605-010-0241-9。
有限体実装：BerlekampおよびCantor-Zassenhausのアルゴリズム、https://flintlib.org/doc/algorithms/polynomials/factoring-finite-fields.html 。

## 5. 完全に再現できる実装
[v110_arbitrary_k_single_prime_roots.py](v110_arbitrary_k_single_prime_roots.py) は各kについて q=nextprime(k³) を見つける（必ず2k³未満、素数判定で確認）、R modqをO(k)短積で計算、F modqの根を有限体因数分解で取得。次にFとX^q-Xの多項式gcdを**別方式**で計算し、線形根の積との一致を確認する。最後に**全k上限iのスキャンはせず**、高々k個の候補のみを元整数等式でチェック。kの任意上限Nを増やして「全k無解」を主張するものではなく、任意入力kの決定アルゴリズムを実証する。

数学的到達点：
- 無条件・全k・小素数因数分解不要・Hensel不要の厳密決定法が成立。
- しかし P_k の全k整数根不存在の**全称証明は未達**。
- その本命は Schur/Pólya型の連続因子多項式の一次因子不存在、または全kで適切な有限体root-free素数の存在を示す定理。どちらも現時点で立証していない。
- 元の4変数式の完全解にも至っていない。
