# v59：判別式の第二因子 \(8b^2+9\rho\) から9・12位数捩れを同時排除

2026-11-08。第一楕円商
\[
E_{1,T}: y^2+6xy+(8+9T)y=x^3,\quad
T=\rho/b^2>0,\quad b\mid486
\]
の有理捩れ群について、v58の \(p\mid\rho\) に加え、**判別式のもう一方の悪い還元因子**を使う。目的は任意の正の \(\rho\) に通用する必要条件を得ることであり、正階数の全有理点や元の整数方程式の全解を決定したと主張するものではない。

## 定理：第二判別式因子の素因数の指数に強い制約

\[
M=8b^2+9\rho,\qquad
\Delta(E_{1,T})=-243T(8+9T)^3,\qquad
c_4=144(1-9T).
\]
\(p\ge5\) が \(M\) を割り、\(h=v_p(M)\ge1\) とする。\(b\mid486\) より \(p\nmid b\) であり、
\(8+9T=M/b^2\equiv0\pmod p\)。
同時に \(T\not\equiv0\pmod p\)：もし \(p\mid M,\rho\) なら \(p\mid8b^2\) となって矛盾する。

従って
\[
\boxed{
v_p(\Delta)=3h,\quad c_4\equiv1296\not\equiv0\pmod p.
}\tag{59.1}
\]
最小モデルは乗法的還元 \(I_{3h}\) を持つ。\(8+9T\equiv0\) での特殊繊維
\[
y^2+6xy=x^3
\]
は \((0,0)\) に分裂結節点を持ち、二次接線が \(y(y+6x)\) に分解される。従って分裂乗法的で
\[
\boxed{\#\widetilde E_{\rm ns}(\mathbb F_p)=p-1.}\tag{59.2}
\]

Néronモデルの成分群の位数は幾何学的には \(3h\)、滑らかな還元の点数は \(p-1\)。\(N\in\{9,12\}\) は \(p\ge5\) に対して素なので、\(N\)-位数の有理点があれば、pro-\(p\) 核を通る還元の群論から
\[
\boxed{N\mid3h(p-1).}\tag{59.3}
\]
これにより

\[
\boxed{
\begin{aligned}
E_{1,T}(\mathbb Q)\text{ が9位数捩れを含む},\
p\mid M,\ p\equiv2\pmod3
&\Longrightarrow 3\mid v_p(M),\\
E_{1,T}(\mathbb Q)\text{ が12位数捩れを含む},\
p\mid M,\ p\equiv3\pmod4
&\Longrightarrow 2\mid v_p(M).
\end{aligned}}\tag{59.4}
\]
この結論は \(\rho\) の大小に依存しない。

## 新しい無限族系：p≡11 (mod12) の一次因子があれば階数0は元解を与えない

特に
\[
\boxed{
p\mid(8b^2+9\rho),\quad p\equiv11\pmod{12},
\quad v_p(8b^2+9\rho)=1
}\tag{59.5}
\]
を満たす素数 \(p\ge5\) が存在すれば、(59.4)の二条件に同時に反し、9・12位数の有理捩れを双方とも排除する。
v58のMazur分類から
\[
\boxed{E_{1,\rho/b^2}(\mathbb Q)_{\rm tors}
\cong\mathbb Z/3\text{ または }\mathbb Z/6.}\tag{59.6}
\]

v50/v56により、元の主枝の整数解の第一楕円商への像が位数1,2,3,6の捩れ点であることは不可能。このため
\[
\boxed{
\text{条件 (59.5) を満たす \((\rho,b)\) で元の整数解が存在するなら }
\operatorname{rank}E_{1,\rho/b^2}(\mathbb Q)\ge1.
}\tag{59.7}
\]
これは \(p\mid\rho\) に関するv58の系とは独立に適用できる。なお正階数の点を排除したという主張ではない。

### 二つの悪い還元因子の同時ふるい

v58では \(p\mid\rho\)、\(e=v_p(\rho)\) の場合、分裂指標 \(\chi_p=(-3/p)\) を用いて、9または12捩れなら
\[
9\text{ または }12\ \mid e(p-\chi_p)
\]
が必要だった。今回はもう一方の \(p\mid M\) で
\[
9\text{ または }12\ \mid 3v_p(M)(p-1)
\]
が必要と分かった。\(p\ge5\) では \(\gcd(\rho,M)\mid8b^2\) なので、**両集合の素因数は重ならない**。従って独立の素因数の付値で、9・12捩れの可能性を同時に絞り込める。

例：\(\rho=100003,\ b=2\) なら \(M=900059=23\cdot39133\)。素数23は \(23\equiv11\pmod{12}\)、\(v_{23}(M)=1\)。従ってこの繊維では第一楕円商の9/12捩れは不可能。v51での実際の捩れ群 \(\mathbb Z/3\) の直接証明とも一致する。
