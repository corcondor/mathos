# v20：固定した (δ,J) の完全再構成と、正符号の四次式の根の一意性

2026-11-07 JST。対象は元の添字二乗型の二項係数方程式の
\(\ell=1,j=i-3\) の枝。v19追補の消去式を、実際に再実行できる
有限ソルバーへ接続する。新しい Lean・DeepSeek 実行ではない。

## 1. 新しい一変数補題

正の実数 \(a,b,d\) に対して

\[
L(x)=ax^2-bx-d,\qquad
H(x)=\frac{L(x)}{\sqrt{x(x-1)}}\quad(x\ge2)
\]

とおく。このとき **H は厳密に増加する**。
微分の分子を正の分母 \(2\{x(x-1)\}^{3/2}\) で払うと

\[
2x(x-1)L'(x)-(2x-1)L(x)
=ax^2(2x-3)+bx+d(2x-1)>0.
\tag{1}
\]

従って正の \(D\) に対し、

\[
L(x)=\sqrt{D x(x-1)},\qquad x\ge2
\tag{2}
\]

を満たす実数は高々一つである。平方した四次方程式だけを解くと、
\(L(x)<0\) の余分な根を含む可能性がある。(1) は必要な正符号の枝に
対する完全な一意性を与える。

この補題自体は二項係数に依存しない。四次式を整数問題へ使う際に、
符号を保って一つの根だけを分離するための補題として再利用できる。

## 2. 元のパラメータとの接続

`v19_canonical_defect_elimination.md` の記号を使う。
\(C=M\delta\)、\(K=\delta r^2/Q\)、
\(c=C/\gcd(C,K)\)、\(h=K/\gcd(C,K)\) とすると

\[
cr^2=hn(n-1),\qquad9<h/c<10400/927<45/4.
\]

共通約数 \(G\) は、分岐ごとに次の正整数を割る。

\[
E_0=2(3h^2-4ch+68c^2),
\]
\[
E_1=3(12h^4-16ch^3+404c^2h^2-1752c^3h+7803c^4).
\tag{3}
\]

これらは有理数上の結果式だけでなく、v19の整数係数恒等式で証明された
**G全体の整除**である。2や3、素数冪の指数を捨てていない。

固定した \((\delta,J)\) について、
\(M\in\{1,2,3,6\}\)、\(9M\delta<K<(10400/927)M\delta\)、
\(\gcd(K,\delta)=1\) の係数族を全て取り、各 \(G\mid E_\varepsilon\) を取る。
ここまでで有限であり、\(n\) の走査上限を使っていない。

小分岐では \(a=h-9c>0,b=h+6c\) に対し

\[
an^2-bn-c(JG+10)=0.
\tag{4}
\]

その定数項は負なので正の実根は一つだけであり、
判別式の整数平方根と分子の \(2a\) による整除で、全整数根を判定する。

補分岐では \(d=c(JG+9)>0\) として

\[
L(n)=an^2-bn-d=2cr>0,
\qquad L(n)^2=4ch\,n(n-1).
\tag{5}
\]

(1) を適用すれば、**各 G に対し、n≥104 の対象根は高々一つ**。
v19の「四次式なので高々四つ」という一般的な個数より強い。

## 3. 浮動小数点を使わない根の分離

整数 \(n\ge104\) に対し、次の符号を計算する。

1. \(L(n)\le0\) なら負とする。
2. \(L(n)>0\) なら \(L(n)^2-4ch\,n(n-1)\) の整数符号を取る。

この符号は \(H(n)-2\sqrt{ch}\) の符号に一致する。(1) により、負から
非負へ変わる場所は高々一つである。

整数の上端も明示できる。\(4ch<45c^2<49c^2\) なので、

\[
U=\max\left(105,
\left\lfloor\frac{b+7c+\operatorname{isqrt}((b+7c)^2+4ad)}{2a}\right\rfloor+2
\right)
\]

は

\[
aU^2-(b+7c)U-d>0
\]

を満たす。従って \(L(U)>7cU>2\sqrt{ch\,U(U-1)}\) で、符号は正になる。
コードでもこの端点の整数比較を実際に確認する。

104で既に正なら対象整数根はない。104で0ならそれが唯一の根である。
それ以外は [104,U] を整数の二分探索で分け、隣接する二整数 \(v,v+1\) で
負から非負に変わる証明書を返す。後者の値が0かどうかを整数計算すれば、
根の有無が確定する。一般の数値的な四次方程式ソルバーは使わない。

平方根の下端・上端と同様、この隣接整数の符号証明書は、二分探索を信頼せずに
別実装から検査できる。

## 4. 因数分解の正しさも別に証明する

生成器は SymPy の factorint で (3) の因数候補を得る。しかし、因数の
積が E に一致することだけでは、素因数分解が完全とは限らない。
そこで現れた全素数 p に対し、p−1 の完全な因数分解と整数 a を保存し、

\[
a^{p-1}\equiv1\pmod p,\qquad
\gcd\left(a^{(p-1)/q}-1,p\right)=1
\quad(\text{全ての素数 }q\mid p-1)
\tag{6}
\]

を検査する。p−1 の素因数についても同じ証明書を再帰的に付け、p=2で止める。

(6) が素数証明になる理由も短い。pの任意の素因数 \(\ell\) に対して、
aの法 \(\ell\) での位数は p−1 を割り、各素数 q の指数を一つも落とせない。
従って位数は p−1 で、\(\ell-1\ge p-1\) となる。\(\ell\mid p\) から
\(\ell=p\)、すなわちpは素数である。検査器は素数判定の確率的な返り値を使わない。

素因数分解の積・全素数証明・全指数の約数生成を確認した後、(4)・(5) の
全 G を調べる。根があれば整数 r、実際の M,δ、canonical な G、残る必要条件を
戻し、必要に応じて元の二項係数の合同式を検査する。
有限個の法を通るだけの候補は、元式の解や不存在証明として扱わず未判定で返す。

## 6. 再現と範囲

```sh
python v20_fixed_parameter_solver.py
python v20_fixed_parameter_verify.py
python v20_root_isolation_checks.py
```

最初の二つは上記の既定2クエリを生成・検査する。
任意の一組を調べるには、例えば生成器に
`--delta 25 --J 33 --branch complement --output query.json.gz` を渡す。
別配置なら `--elimination-note` で v19 の消去証明を指定する。

生成器だけが因数候補の探索に SymPy を使う。独立検査器は SymPy も生成器も
import しない。結果・全素数証明・全根分離証明書は
`v20_fixed_parameter_certificate.json.gz`、監査結果は
`v20_fixed_parameter_verification.json` に保存した。

元式からの消去式 (3) は v19 の記述証明を入力として使う。
このノートの新しい一般部分は (1) の単調性と、符号を保つ完全な整数根分離である。
未形式化の一般証明・完全な有限検査・実装の回帰例を区別する。
