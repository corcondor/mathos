# 二項係数方程式の三次曲線を楕円曲線へ移す

対象は元の方程式の `ell=1, j=i-3` の枝であり、既存の還元で得られる

\[
6Sr^3=T(y^3-y),\qquad y=n-1\ge103,\quad S,T>0
\]

を扱う。ここで \(c=6S/T\in\mathbb Q\) と置く。
本稿は座標変換を形式検証するもので、原方程式の全解の決定ではない。

## 検証対象の写像

\(c\ne0, y\ne0\) のとき

\[
x=-\frac{cr}{y},\qquad z=\frac c y
\]

とすれば

\[
\boxed{z^2=x^3+c^2}
\]

となる。逆に \(c\ne0,z\ne0\) のとき

\[
y=\frac c z,\qquad r=-\frac x z
\]

で \(y^3-y=cr^3\) を復元する。両方向の合成が恒等になることも検証対象とする。
元の曲線で除く点は \(y=0\) の点 \((r,y)=(0,0)\) であり、
研究対象の \(y\ge103\) はこの点を含まない。
楕円曲線側では \(z=0\) の点と射影的な無限遠点をこの座標チャートに含めない。

これは有理点の開チャート上の対応である。
Schemeの圏での双有理写像全体や、群構造との互換性をLeanで構成したとは主張しない。

## 実際のmathlibの楕円曲線構造

`v10_formal/GeometricReduction.lean` は、単なる式の変形だけでなく
mathlibの `WeierstrassCurve ℚ` を使い、係数

\[
(a_1,a_2,a_3,a_4,a_6)=(0,0,0,0,c^2)
\]

について

\[
\Delta=-432c^4\ne0,\qquad \mathrm{IsElliptic},\qquad j=0
\]

を検証する。前後の曲線方程式、合成の恒等式、判別式、非零性、
楕円曲線であること、j不変量、元のS,T曲線からの直接適用を9定理へ分割した。

DeepSeekが研究案と証明本文を生成した。初期案には反例がある写像、特異なモデル、
逆写像の誤りがあったため採用せず、ホスト側で定義と定理文を点検・訂正して固定した。
固定後の9個の証明本文と、そのLeanエラーへの修正はすべて
`deepseek-v4-1-flash-1017` が作成し、証明本文は手作業で修正していない。

## 現代的な計算手法への接続と未実施部分

この古典的な座標変換自体を新規の最先端定理とは呼ばない。
`j=0` の明示モデルを固定することで、次に検討する対象を具体化できる。

- 3降下・Selmer群：有理点候補の大域的制約を調べる。降下写像、局所条件、
  被覆曲線、得られた上界の証明書が必要で、今回これらの計算は行っていない。
- 楕円対数と格子基底縮約：高さのある点の探索領域を縮約する候補。
  群の生成元・飽和性、認証済みの数値評価と高さ上界なしに完全性を主張しない。
- Mordell–Weil sieveと局所条件：既存の合同式フィルタと組み合わせる候補。
  法ごとの像と、大域の候補集合を覆う根拠が必要である。

Mordell–Weil群の有限生成性は、有理点が有限個であるという意味ではない。
階数0、生成元の完全性、全整点の決定、原方程式の非存在は今回証明していない。
30余因子の最終定理の連分数仮定も、この座標変換だけでは外れない。
