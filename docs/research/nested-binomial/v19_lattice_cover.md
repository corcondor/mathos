# v19 追記：二次式の全整数点を、二次元格子の縮小で再構成する

2026-11-07 JST。対象は引き続き

\[
\binom{\binom ij}{\binom{k}{\ell}}
=\binom{i^2}{j^2}+\binom{k^2}{\ell^2}
\]

の \(\ell=1,j=i-3\) の枝。右辺は添字の二乗である。

## 1. 今回実際に追加したもの

v19 の暗号手法ノートでは、小根法の適用条件を点検し、未変換の式が
その十分条件を満たさないことを確かめた。この追記では、**実際に格子を
構成し、基底を縮小し、元の整数点を漏れなく復元する計算**を実施した。

固定した不足約数 \(13\le\delta\le24\) に対する全 3,571 係数族を、
Pell の基本単数や連分数を使わずに再計算した。証明済みの高さ全域を
2,818,386 個の区間に分け、16,810,125 本の格子ベクトルから、
正整数 \(n\ge104,r\) の二次式の解 112,249 個を復元した。
その全点集合は、保存済みの Pell 証明書と各係数族で一致した。
残る 93 組・元式の 186 分岐も、23 以下の素数の合同式ですべて排除した。

これは既存の **\(\delta\ge25\)** を異なる完全性の論拠で再検証する成果である。
\(\delta\) の数値下限をさらに上げた結果ではない。\(\delta\) 全域や
四変数方程式全体を排除したものでもない。

## 2. 整数条件から格子を作る

[v16](v16_square_defect_pell.md) の記号を使う。

\[
M=\gcd(n,3)\gcd(n-1,6),\quad Q=n(n-1)/M,
\quad\delta=Q/\gcd(Q,r^2),
\]
\[
C=M\delta,\quad K=\delta r^2/Q.
\]

元式の解なら

\[
Cr^2=Kn(n-1),\qquad
9C<K<\frac{10400}{927}C<16C,
\qquad 104\le n<2^{42\delta}.
\tag{1}
\]

ここで

\[
x=2n-1,\qquad y=2r,\qquad \alpha=\sqrt{K/C}
\]

と置けば、正整数点が満たす式は

\[
Cy^2-Kx^2=-K,
\qquad y^2=\alpha^2(x^2-1).
\tag{2}
\]

従って \(0<y<\alpha x\)、\(0<\alpha<4\) であり、

\[
0<\alpha x-y
=\frac{\alpha^2}{\alpha x+y}
<\frac\alpha x<\frac4x.
\tag{3}
\]

この評価には浮動小数点も近似等号も使わない。

### 格子長方形補題

\(B\le x<2B\) という一つの区間を固定し、

\[
L=B^2,\qquad a=\lfloor L\alpha\rfloor,
\qquad e=Ly-ax
\]

とする。\(\beta=L\alpha-a\in[0,1)\) なので、(3) から

\[
e=-L(\alpha x-y)+\beta x>-4B,
\qquad e<\beta x<x<2B.
\]

よって全ての対象点は、整数格子

\[
\Lambda_{B,C,K}
=\{(x,Ly-ax):x,y\in\mathbb Z\}
=\mathbb Z(1,-a)+\mathbb Z(0,L)
\tag{4}
\]

の中の有限長方形

\[
\boxed{B\le x<2B,\qquad -4B<e<2B}
\tag{5}
\]

へ入る。格子の共体積は \(L=B^2\)。長方形の面積との比は 6 であり、
\(n\) の桁数が増えても同じである。ただし、面積比が 6 であることから
格子点数が 6 以下だと結論するわけではない。点数と全候補は以下の
厳密な係数区間から実際に計算する。

\(a\) は

\[
a=\operatorname{isqrt}\!\left(\left\lfloor\frac{KL^2}{C}\right\rfloor\right)
\]

で整数計算だけから求まり、毎回
\(Ca^2\le KL^2<C(a+1)^2\) を確認した。

## 3. 基底縮小の証明書と、全点を尽くす係数区間

入力基底行列を

\[
A_B=\begin{pmatrix}1&-a\\0&L\end{pmatrix}
\]

とし、整数上の Gauss 縮小を行った。これは二次元の基底縮小であり、
返された \(R=UA_B\) に対して次を全て整数演算で検査する。

- \(U\) の全成分が整数で、\(\det U=\pm1\)。従って格子全体が保存される。
- \(|\det R|=L\)。
- 基底行を \(b_1,b_2\) として
  \(2|\langle b_1,b_2\rangle|\le\lVert b_1\rVert^2\)。
- \(4\lVert b_2\rVert^2\ge3\lVert b_1\rVert^2\)。これは二次元の
  Lovász 条件 \(\delta_{\rm LLL}=3/4\) と等価である。
- Gram–Schmidt の分母も含む恒等式
  \(\lVert b_1\rVert^2\lVert b_2\rVert^2-
  \langle b_1,b_2\rangle^2=L^2\)。

不足約数 \(\delta\) と縮小パラメータ \(\delta_{\rm LLL}\) は別の量である。

**短い基底が見つかっただけでは全解回収にならない。** 完全性を与えるのは
次の係数区間である。\(b_1=(u_1,v_1),b_2=(u_2,v_2)\)、
\(D=u_1v_2-v_1u_2=\pm L\) とすれば、

\[
(x,e)=z_1b_1+z_2b_2
\quad\Longrightarrow\quad
z_1=\frac{xv_2-eu_2}{D},\qquad
z_2=\frac{eu_1-xv_1}{D}.
\tag{6}
\]

長方形上で右辺の一次式の最大・最小は四隅で得られる。
その値の切上げ・切下げから、一方の整数係数の全区間を求める。
各係数を固定すると、二つの座標不等式がもう一方の整数係数の区間を
与える。これらの区間の全整数を調べれば (5) 内の格子点を漏れなく得る。
縮小条件そのものが最短ベクトルや全根を保証すると仮定していない。

各点から \(y=(e+ax)/L\) を戻し、\(x\) が奇数、\(y>0\) が偶数、
そして (2) が厳密に成立する点だけを採用する。従って余分な長方形の点が
二次式の解に混入することもない。

### 実際の基底の小さい例

\(C=78,K=703,B=128\) の区間では \(L=16384,a=49186\) で、

\[
\begin{pmatrix}1&3\\481&1444\end{pmatrix}
\begin{pmatrix}1&-49186\\0&16384\end{pmatrix}
=\begin{pmatrix}1&-34\\481&30\end{pmatrix}.
\]

左の変換行列の行列式は 1。行の長さが数万の入力を、小さい座標を
持つ基底に変えたことが直接確認できる。同じ係数族では、
\(B=2^7,\ldots,2^{546}\) の 540 区間をすべて処理し、
4,078 本の長方形内の格子ベクトルから 47 個の正整数点を得た。

## 4. 全高さを被覆し、平方係数の例外を処理する

(1) の高さから

\[
207\le x\le 2^{42\delta+1}-3.
\]

従って \(B=2^b\)、\(7\le b\le42\delta\) の全区間を使い、
最初と最後の区間をこの厳密な端点で切ればよい。
数値的に選んだ \(n\) の探索上限はなく、区間数は既証の高さのビット数に
比例する。各区間の内部も (6) により完全に列挙する。

\(CK=s^2\) が平方になる係数族は別に扱う。(2) から

\[
x^2-\left(\frac{Cy}{s}\right)^2=1.
\]

括弧内は有理数で、その平方が整数なので整数である。
整数の二平方の差が 1 となる非負の解は \(x=1,y=0\) しかなく、
\(x\ge207,y>0\) に反する。実際の係数範囲ではこの場合が 4 族あり、
格子の列挙から無断で省いたものではない。

区間を一段進めるたびに \(L\) は 4 倍になる。
前の座標 \((x,e)\) を

\[
(x,4e+(4a-a')x)
\]

へ移せば、同じ変換行列から次の入力格子の基底を得る。
これを再縮小することで、毎回巨大な最初の行列から計算し直す必要を減らした。
この更新についても \(UA'_B=R'\) を各回に確認する。

## 5. 全 3,571 族での結果

全係数は、既存の必要条件

\[
13\le\delta\le24,\quad M\in\{1,2,3,6\},\quad
9M\delta<K<\frac{10400}{927}M\delta,\quad \gcd(K,\delta)=1
\]

から生成した。保存済みの候補があった族だけを最終対象に選ぶことはしていない。

| 段階 | 件数 |
|---|---:|
| 全係数族 | 3,571 |
| 平方 \(CK\) による記述排除 | 4 |
| 全 dyadic 区間・縮小基底の厳密検査 | 2,818,386 |
| 長方形内の格子ベクトル | 16,810,125 |
| \(x\) 奇数・\(y>0\) 偶数の候補 | 4,137,798 |
| 二次式を満たす \(n\ge104,r>0\) | 112,249 |
| 元の \(M,\delta,Q\mid r^3\)、粗い区間、対数区間を通る点 | 93 |
| 元の二項係数式の両分岐 | 186 |
| 23 以下の素数で排除した分岐 | 186 |
| 残存 | 0 |

主生成器の全処理時間は 281.658 秒。これは一度の実行の記録で、
一般的な計算量や他の手法に対する優位を実証する測定ではない。
この二次式は Pell 法に適しており、ここでの格子法の役割は**別経路での
完全な回収と検証**である。暗号向けの方法が既存の Pell 法より速いという
主張をしない。

同じ \(13\le\delta\le24\)・全 3,571 族・同じ高さ・同じ元式の排除という
契約で、次を実際に測定した。

| 実行 | 秒 | 完了内容 |
|---|---:|---|
| 格子による生成・旧全点集合との照合 | 281.658 | 全基底の検査・全点・93候補・186合同反証 |
| 別実装の格子監査 | 230.157 | 全基底・全点を再構成し、全合同反証を再検査 |
| 既存の独立 Pell 監査の再実行 | 0.912 | 全基本単数・全Pell点・上限外点・全合同反証 |

一回の測定であり、CPU の隔離や無作為化をした比較実験ではない。生成器と
検査器の処理分担も異なる。この入力では格子方式が速いという結果は得ていない。
記録された仮説の評価は「独立な全被覆法として採用、Pell 法の高速な代替という
主張は採用しない」である。入力・コードのハッシュと測定値は
`v19_lattice_method_trial.json` に保存する。

最大の最終候補 \(n\) は 297 桁である。候補を実際に 1 からその値まで
走査したのではなく、証明された高さを (5) と (6) の格子区間へ変換した。

## 6. 独立実装と、実際の SymPy LLL 呼び出し

主生成器 `v19_lattice_cover.py` は Pell の基本単数も連分数も使って
格子点を生成しない。格子の計算を完了した後にだけ、旧証明書の Pell 列から
得る同じ二次式の全点集合と比較する。この比較で、全 3,571 族の集合が一致した。

独立検査器 `v19_lattice_verify.py` は、主生成器・Pell コードを import せず、
旧 Pell 証明書も読まない。初期基底の行順序、丸めの同点処理、行列式の向き、
列挙する係数を変え、さらに誤差長方形を閉区間 \([-4B,2B]\) に広げて
再計算する。各族の全整数点のハッシュ、完全な係数範囲、候補 93 組を照合し、
Lucas の各桁を階乗逆元から作り直して元式の 186 合同反証を検査する。
全 3,571 族・2,818,386 区間の再実行は PASS。拡大した長方形内の
ベクトル 16,810,508 本から同じ 112,249 整数点を回収し、93 組・186 分岐の
排除まで一致した。実行結果を `v19_lattice_independent_audit.json` に保存した。

加えて、今回使用した実際の \(C=78,K=703\) の三つの区間
\(B=2^7,2^{273},2^{546}\) で、SymPy 1.14.0 の
`Matrix.lll_transform(delta=Rational(3,4))` を実行した。
返された変換行列を整数上で再検査し、行列式・GSO・縮小条件がすべて一致した。
これは外部実装での補助点検であり、全 2,818,386 区間を SymPy で処理した
という意味ではない。全被覆は、前述の厳密 Gauss 縮小器と区間列挙による。

公式の [SymPy DomainMatrix 文書](https://docs.sympy.org/latest/modules/polys/domainmatrix.html#sympy.polys.matrices.domainmatrix.DomainMatrix.lll_transform)
も、縮小基底と \(T A=B\) を満たす変換行列を返す仕様を記載する。
ここでは返り値の表示だけで成功扱いにせず、実際の整数等式を検査した。

## 7. 証明書の内容と再実行

`v19_lattice_certificate.json.gz` は全係数族、点集合のハッシュ、全件数、
基底変換列のハッシュ、代表基底、93 個の最終候補と全合同証人を保存する。
全区間の巨大な行列を保存する形式ではなく、検査器が各区間を独立に再構成する。
ハッシュ比較だけが排除の根拠ではなく、再構成された**全点**に必要条件と
元式の合同式を適用することが排除の根拠である。

同じ研究ディレクトリで以下を実行する。

```sh
python v19_lattice_cover.py
python v19_lattice_verify.py
python v19_lattice_sympy_check.py
```

最初の二つは標準 Python ライブラリのみで動く。最後の補助点検には SymPy が
必要である。元の既存証明書を別配置に置く場合、生成器に
`--baseline-certificate /path/to/v19_defect_13_24_certificate.json.gz` を渡せる。
独立検査器はこの旧証明書を必要としない。

### 証明の依存関係と残る問題

- 元式から (1)、\(Q\mid r^3\) と対数区間を得る部分は v16 以前の記述証明に依存する。
- (2)〜(6) と有限区間の被覆は、このノートの直接の整数・線形代数の議論である。
- 有限区間の計算には、上記の実行済みコードと独立検査器を使う。
- 新しい Lean 形式化、DeepSeek API 呼び出し、楕円曲線の離散対数計算、
  Coppersmith の全小根回収は実行していない。
- この結果は \(\delta\ge25\) の既知の必要条件を別方法で確認する。
  \(\delta\) の無制限の範囲を有限化する定理は依然として必要である。
