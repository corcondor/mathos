# v19 の検証範囲と独立監査

2026-11-07 JST。

## 結論の種類

v19 の新結果は、元式の ell=1,j=i−3 の枝の必要条件を強めるものである。
以下の三つを混同しない。

1. **無限のパラメータ域の記述証明**：残差曲線の明示点の無限位数、
   Jの2進条件、ρの法5条件、J,wの不等式、3位数点と平方根境界の対応。
2. **証明で定まる有限領域の完全な整数検査**：δ=13〜24、J≤16、ρ≤10。
   それぞれ、範囲を尽くす根拠と実際の全データを保持している。
3. **支持検査・追加CAS出力**：多項式恒等式の独立検算、Coppersmith仮定の
   具体例、45楕円曲線のPARIランク出力。これらだけで原式全体の排除とはしない。

新しいLean検証やDeepSeek API呼び出しは行っていない。
以前の形式証明の数や成功を、今回の定理の形式化実績として加算しない。
相互監査は別のAI担当による内部点検で、外部研究者の査読ではない。

## 1. δ≥25の完全性

依存する一般理論は `v16_square_defect_pell.md` の高さとPell帰着である。
各δで n<2^(42δ)、4通りのM、厳密なKの有限区間を得る。
CK=s²dと分解し、x²−dy²=1の全正解を基本単数の冪で生成する。
最初に高さを超える点も記録し、点列の途中で任意に打ち切らない。

`v19_defect_batch_sieve.py` が生成し、`v19_defect_batch_verify.py` が
生成器とv16モジュールをimportせずに再構成する。
独立側は連分数の完全周期の偶奇を使用し、Lucasの各桁も階乗逆元で計算する。
係数族3,571、基本単数2,030、Pell点145,195、最終93組、元式の両分岐186件を
すべて照合した。全合同証人で左右が異なり、未排除は0。

`v19_defect_13_24_certificate.json.gz` は全記録の可逆圧縮であり、標本ではない。
旧δ≤12排除との結合によりδ≥25を得る。δ≥25の全域を除いたという意味ではない。

## 2. J≥17の完全性

小分岐に限る。Jに関する無限の2進除外と、全Jで有効なwの四次不等式を先に証明した。
固定したJ≤16に対してwの上端を厳密に決定し、e²|c³を
e|∏p^floor(3v_p(c)/2)に置き換えてnを全て生成した。
nの外部的な探索上限はない。

`v19_canonical_J_checks.py` の生成器はSymPyを利用する。
`v19_canonical_J_verify.py` は標準ライブラリだけで、約数生成・上端の決定・
有限体多項式演算を別実装している。6,620既約(J,w)、136,852の正規化n記録、
159高さ適合記録、110本のBézout恒等式を全て再構成した。
最大法素数107、残存0。

担当外のレビューは `v19_canonical_J_independent_review.md/.json`。
グレブナー基底が[1]という文字列だけを信用せず、係数恒等式を検査した。
固定Jの一般系は次元2であり、正の次元の系をRURで完全に解いたとはしていない。
補分岐J=1の問題は未完了である。

## 3. ρ≥11の完全性

v18の a<ρ(ρ+32b²) を使用する。bは486の全12正約数、ρは1〜10、
下端は27a≥31b。gcd(a,b)=1、ρ≡a² mod b、残差の厳密上限を保つ。

`v19_elliptic_residual_checks.py` が全45繊維、886,683係数候補を被覆。
法5の全繊維排除後775,235平方検査、平方5件、両符号で10復元を記録する。
いずれも元式に必要な正整数n,tとn≥104を満たさない。

`v19_elliptic_independent_audit.py` は生成器をimportせず、別の式

F=q₀²+3ρ(ρ+32b²)a²−ρ²(3b²+4ρ), q₀=2a³+(6b²−3ρ)a

で全域を再計算し、平方5件と全復元値が一致することを確認した。
範囲生成と剰余式も異なる。補助の14恒等式はSymPyでも独立に確認した。
その監査器にはSymPyが必要だが、主生成器の完全な整数検査は標準ライブラリで動く。
PARIの出力や未証明の階数仮定は、このρ≥11の根拠に含まれない。

## 4. 一様な無限位数の証明

`v19_residual_positive_rank.md` の証明は、Nagell–Lutzの積分性と
倍加公式からd|24aを導き、付値でd|12へ縮約する。
これは有限サンプルからの外挿ではない。

主検査器は整数係数の疎多項式として、曲線・点・接線・判別式を展開した。
`v19_uniform_rank_independent_review.py` は別の方法を用い、各変数次数12以下の
恒等式を13×13の全格子で評価する。次数の上限を明記した多項式恒等式検査であり、
一般の整数解探索に169点の上限を置いたものではない。
独立した記述証明レビューと、例外(3,1)の倍加・残差非平方検査も保存した。

PARIによる例外のランク上界0・ねじれ位数12の出力は別保存。
定理には位数4の点を直接確認するだけで十分で、完全なランク計算を前提としない。

## 5. 文献からの主張と今回の実行を区別

- 最新RUR論文と実装文書：零次元仮定を確認した。著者のJulia実装は実行していない。
- SymPy：結果式、飽和のためのRabinowitsch消去、グレブナー基底、拡張Euclidを実行した。
- 暗号論文：小根の大きさ、固定法、格子の第二極小と独立な短い根ベクトルの条件を確認した。
  CoppersmithやDual Coppersmithを実装・実行して全根を得たという主張はしない。
- 種数2・Affine Chabauty：幾何学的な入力と数値的ランク条件を明確にした。
  Coleman積分、完全なMordell–Weil基底、アルゴリズム全体は未実行。
- Modular Chabauty：固定Sの不足を判別式とc₄で確認した。b|486からS={2,3}とはしない。
- PARI/GP 2.17.4：45繊維の `ellrank` / `elltors` と例外曲線の実験を実行した。
  全有理点・全整数点の決定にはしていない。

取得できなかった文献は、読めた概要・著者READMEの範囲に限定した。
*Dual Coppersmith* はIACR原URLの取得に失敗し、同論文のミラーPDFを読んだことを
文献台帳に記す。具体的な適用条件は読めた定理3.4・系4.2・6.2節に対応する。

## 6. 既存資料・並行更新との関係

研究開始時点はv18コミット `4d2b7c60122c2fdcefc414b179a05d2b945545a0`。
途中で追加されたv18 Actionsのコミットを確認し、その履歴を保存先の親に含める。
別枝 `research/v18-next-descent` の `73cdb502392b61db093c7a50d44f5efb21f9e2e2`
には、27a<31bを残存領域として扱う案があったが、この領域はv17で既に排除済み。
v19の証明書は正しい27a≥31bの領域を使用する。
並行追加されたActionsの係数選択・報告表示・文書もこの条件へ修正した。
また正側の条件付きδ⁴高さの入力を、誤っていたn²+2からn²+1へ修正。
変更はこれら二つの数学的な誤接続と回帰テストに限定した。
全11件の軽量テストは成功し、新しい回帰テストは旧コードで失敗することも
確認した。実行ログ、元の固定コミット、変更前後のハッシュと具体例は
`v19_actions_corrections.json` と同名の説明ノートに保存する。

既存Lean本文・固定目標・DeepSeek状態を変更しない。
GitHub Actionsの実行有無と、このワークスペースで実行した検査を混同しない。
全ファイルと参照入力のハッシュは `v19_manifest.json` を参照。
