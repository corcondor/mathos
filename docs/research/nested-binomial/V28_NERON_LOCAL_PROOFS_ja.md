# v28：Néron成分群・中心例外成分・素因数障害を用いた無限倍数点ふるい

研究対象：
\[
\binom{\binom ij}{\binom k\ell}=\binom{i^2}{j^2}+\binom{k^2}{\ell^2},\qquad\ell=1,\ j=i-3.
\]
対象は**元の二項係数方程式の必要条件から得た補助曲線上の巡回部分群 \(\langle R\rangle\) のみ**であり、全有理点や元問題全体の排除ではない。

## 入力（v20〜v27の既存結果から継承）

整数 \(b\mid486\), \(b>0\), \(\rho>0\), \(a>0\) は
\[
\gcd(a,\rho)=\gcd(a,3),\quad \rho\bmod9\in\{1,4,6,7\}
\]
を満たす。第2楕円商は \(T=\rho/b^2\),
\[
A=-T^2(4T+3),\quad B=12(T^2+5T+3),\quad C=12(2-T),
\]
\[
E_T:\quad Y^2=X^3+BX^2+ACX+4A^2,\qquad
R=(8T(4T+3),6T(4T+3)(9T+8)).
\]
元曲線から \(P=mR\) に落ちる場合は
\[
 a^2=b^2 A(T)/X(mR)\in\mathbb Z_{>0}.
\tag{1}
\]
\(mR=O\), \(X(mR)=0\) では有限の \(a\) は復元できない。\(R\) は \(T>0\) の有理特殊化で無限位数という既存v27の結果を使う。重要：この復元は必要条件であり、(1)を満たす \(a\) が元の四変数方程式の解になるわけではない。

## 定理A：\(p\ge5\) が \(\rho\) を割るときの成分群

\(e=v_p(\rho)>0\) とする。\(b\mid486=2\cdot3^5\) なので \(p\nmid b\) で \(v_p(T)=e\)。
\[
\Delta(E_T)=-62208 T^5(4T+3)^2(9T+8)^3,\quad
c_4(E_T)=576(45T^3+130T^2+120T+36).
\]
従って \(v_p(\Delta)=5e\), \(v_p(c_4)=0\)、最小モデルの還元は \(I_{5e}\)。還元された結節三次曲線は \(Y^2=X^2(X+36)\) で、接線 \(Y=\pm6X\) が \(\mathbb F_p\) 上にあり、**分裂乗法的還元**である。

Néron成分群は \(\mathbb Z/(5e)\)。点 \(R\) に対して \(v_p(Y(R))=e\)。Silverman/Cremonaによる \(\kappa(R)=\pm\min\{v_p(2Y(R)),5e/2\}=\pm e\) の公式から、\([R]\) は成分群で正確に位数5。

さらに元の復元条件と \(p\nmid a\) から
\[
\boxed{v_p(X(mR))=v_p(b^2A/a^2)=2e.}\tag{2}
\]
曲線の右辺の付値を調べると、\(v_p(X)=2e\) の点では \(v_p(Y)\ge2e\)。\(v_p(Y)>2e\) なら成分番号の絶対最小代表は \(2e\) より大きく \(5e/2\) 以下となり、\([mR]=m[R]\) が取り得る \(0,e,2e,3e,4e\) のいずれにも一致しない。よって \(v_p(Y)=2e\)、成分番号は \(\pm2e\)。必要条件は
\[
\boxed{m\equiv2,3\pmod5.}\tag{3}
\]

## 定理B：\(5\mid\rho\) なら全 \(m\) を排除

加法公式の厳密な恒等式：
\[
5R=\left(-\frac{16(T+12)(4T+3)}{25},\frac{6(T+72)(4T+3)(9T+8)}{125}\right).
\tag{4}
\]
\(5\mid\rho\) のとき \(v_5(X(5R))=-2\)、\(v_5(Y(5R))=-3\) なので \(5R\in E_1(\mathbb Q_5)\)、すなわちNéronモデルの特殊ファイバーで単位元に還元される。従って \(mR\) と \(rR\) (\(m\equiv r\pmod5\)) は同じ滑らかな還元点を持つ。

\(m\equiv\pm1\) では近傍 \(X=T Z_1,Y=T W_1\) で \(R\) の \(Z_1\equiv24\equiv4\pmod5\) が単元なので \(v_5(X(mR))=e\)。\(5\mid m\) なら \(mR\in E_1(\mathbb Q_5)\)、ゆえに \(v_5(X(mR))<0\)（\(O\) は除く）。

\(m\equiv2,3\) では近傍 \(X=T^2Z,Y=T^2W\) の特別ファイバーは
\[
 W^2=36(Z-1)^2.
\]
\(2R\) と \(3R\) はそれぞれ \((Z,W)\equiv(0,4),(0,1)\pmod5\) という**滑らかな**還元点を持つ。従って \(m\equiv2,3\) なら \(Z\equiv0\pmod5\)、すなわち \(v_5(X(mR))\ge2e+1\)（\(X=0\) も可）。すべての \(m\) で(2)に矛盾。結論：
\[
\boxed{5\mid\rho\Longrightarrow \text{\(mR\)から元の整数点は一つも復元できない（全整数\(m\)）。}}\tag{5}
\]
この証明の全\(m\)への延長は、Néron特殊ファイバーで形式群 \(E_1\) が単位元に還元される事実を使う。有限個の数値実験だけに基づく結論ではない。

## 定理C：中心成分での\(5R\)の作用・\(p\ge7\)での合同式

\(X=T^2 Z,Y=T^2W\) で \(5R\) を加えると、\(T=0\) の中心成分で
\[
(Z,W)\mapsto\left(\frac{50-34Z-5W}{16},\frac{90-90Z-17W}{8}\right).
\tag{6}
\]
曲線 \(W^2=36(Z-1)^2\) の二つの直線では
\[
 W=+6(Z-1): Z\mapsto5-4Z,\qquad
 W=-6(Z-1): Z\mapsto(5-Z)/4.
\]
\(2R\) の \(Z=5\)、\(3R\) の \(Z=0\) から帰納的に、全整数 \(k\) で
\[
\boxed{ Z((5k+2)R)\equiv1+4(-4)^k,\quad
 Z((5k+3)R)\equiv1-(-4)^{-k}\pmod p.}\tag{7}
\]
\(p\ge7\), \(p\mid\rho\) において (2) が成立するには \(Z\ne0\) で \(v_p(Z)=0\)。そのとき \(A/T^2\equiv-3\pmod p\) から
\[
 a^2 Z\equiv-3b^2\pmod p,\quad
 \boxed{\left(\frac{-3/Z}{p}\right)=1}.\tag{8}
\]
これを満たさない \(k\) は、\(\rho\) や \(m\) に探索上限を付けず排除できる。

## 定理D：\(13\mid\rho\) および不適合素数組

\(-4\bmod13=9\) は位数3を持ち、\(\langle-4\rangle=\{1,3,9\}\)。式(7)の \(Z\) は \(0,5,11\) のみ。\(-3\equiv10\) は13で平方剰余だが、5,11は平方非剰余なので (8) は一度も成立しない。
\[
\boxed{13\mid\rho\Longrightarrow\text{全整数\(m\)を排除。}}\tag{9}
\]

同じ表を \(p=29,113\) で作ると \((-4)\) の位数はいずれも7で、\(m=5k+2\) に対する許容 \(k\) は \(\{1,4\}\) と \(\{0,2,3,5\}\)、\(m=5k+3\) では \(\{2,5\}\) と \(\{1,3,4,6\}\)。両枝とも不適合。従って \(29\cdot113\mid\rho\) なら全 \(m\) 排除。

同様に \(37\cdot109\mid\rho\) でも全 \(m\) を排除する。さらに \(7\cdot17\cdot19\mid\rho\) などは、3つの法をCRTで併合すると不適合。これらは全て(7)(8)の**有限の厳密合同表**で証明できる。

## 定理E：法5の良い還元を形式群まで精密化

\(5\nmid\rho\) で \(T\equiv1,2,4\pmod5\) の場合は良い還元。還元点 \(R\) は位数5で、以前の平方剰余の必要条件では
\[
T\equiv1,4:\ m\equiv0\pmod5,\quad
T\equiv2:\ m\equiv0,1,4\pmod5
\]
が残る。しかし \(5\mid m\) なら \(mR\in E_1(\mathbb Q_5)\)。形式パラメータ \(z=-X/Y\) に対し、\(Xz^2\equiv1\pmod5\) なので \(X(mR)\) の単元部分は平方。一方 \(T\equiv1\) では \(A(T)\equiv3\pmod5\) が平方非剰余で、\(A/X\) は5進数の平方にならない。従って
\[
\boxed{\rho\equiv b^2\pmod5 \Longrightarrow \text{全整数\(m\)を排除。}}\tag{10}
\]

## 系：\(\rho\) の残りの2タイプ

(v20からの) \(\rho\bmod9\in\{1,4,6,7\}\) も使う。\(5\mid\rho\) は(5)、\(T\equiv1\) は(10)で排除。

\(T\equiv2\pmod5\) の場合、\(\rho\bmod5\) は非平方剰余。もし \(\rho\) に素因数 \(p\ge7\) があれば(3)は \(m\equiv\pm2\pmod5\) を要求するが、法5の良い還元は \(m\equiv0,\pm1\) を要求し矛盾。もし \(\rho\) が2と3にしか素因数を持たなければ、\(\rho\bmod9\) の条件から必ず \(\rho=2^{2u}\) または \(\rho=3\cdot2^{2u+1}\) となり、いずれも \(\rho\bmod5\) は平方剰余なので \(T=2\) と矛盾。

\(T\equiv4\pmod5\) では \(5\mid m\) が必要だが、\(p\ge7\mid\rho\) があれば (3)と矛盾。従って \(\rho\) は2,3にしか素因数を持たず、上記2族に限る。

\(T\equiv3\pmod5\) では \(\rho\bmod5\) が非平方剰余（従って \(p\ge7\mid\rho\)）であり、E2の \((4T+3),(9T+8)\) が同時に5の倍数となる**悪い還元の衝突ファイバー**。この場合は本ノートの法5良い還元ふるいを使えない。

以上から元の整数点が \(mR\) に写る場合の必要条件は、次のいずれかに限られる：
\[
\boxed{
\begin{array}{ll}
\text{(I)}&\rho=2^{2u}\text{ または }3\cdot2^{2u+1},\quad \rho\equiv4b^2\pmod5,\\
\text{(II)}&\rho\equiv2,3\pmod5,\quad4\rho+3b^2\equiv0\pmod5.
\end{array}}
\tag{11}
\]
さらに (9) と不適合素数組の除外を併用できる。既知の \(\rho\ge32770\) を使うなら(I)の \(u\) はそれぞれ \(u\ge8,u\ge7\)。

## 監査の範囲・未解決部分

- **実行済み（SymPy + 有理数の厳密演算）**：R,2R,3R,4R,5R の加法・式(4)(6)(7)の基礎、7セット×18倍の p 進付値・還元との一致。
- **実行済み（標準Python）**：\(p=5,13,29,113,37,109\) の合同類、互換しない素数組・3素数組、\(\rho\bmod9\) を満たす2,3冪の分類。
- **数学的外部入力**：Tateの還元分類、Silverman/Cremonaの成分番号公式、Néronモデルの形式群と還元の準同型性。新しいCAS/Lean形式化による完全証明ではない。
- **未実施**：SageMath/Magmaによる個別のMordell–Weil階数と飽和、形式的証明支援系での定理全体の検証、外部査読。
- **重大な限界**：特殊化の \(E_T(\mathbb Q)\) に \(\langle R\rangle\) 以外の点があり得る。これらの制約は巡回部分群だけのものであり、元の整数点の全域排除ではない。

参考：John Cremona, *Computing in Component Groups of Elliptic Curves*, ANTS VIII (2008); Silverman, *Advanced Topics in the Arithmetic of Elliptic Curves*; A. Snowden, Lecture 8/9: elliptic curves over DVRs and Néron models.
