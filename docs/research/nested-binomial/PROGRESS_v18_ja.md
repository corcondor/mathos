# v18：残差楕円曲線族の具体的降下計画

2026年11月7日 JST。

## 概要

v17で得られた残差楕円曲線

\[
Y^2 = X^3 - 3b^2(72a^2 + b^2)X + 2b^2(648a^4 + 180a^2b^2 - b^4)
\]

に対し、固定された小さい約分子\(a\)ごとに有限個の曲線を明示的に構成し、ランク計算・モジュラー制約・局所Chabauty型フィルタを適用する具体的手順を記録した。

## 追加したファイル

- `v18_concrete_descent.md` — 明示的な曲線例、計算ステップ、チェックリスト
- `v18_small_a_models.py` — 小さい\(a\)に対するWeierstrass係数と残差上限を生成するスクリプト

## 次の実行可能な作業

1. \(a \le 10\)の許可される\((a,b)\)ごとに最小モデルを構成し、conductor・ランク・残差範囲内の整数点数を記録する。
2. ランクが正の曲線に対し、モジュラー形式との非合同を検証する。
3. \(H = 21 \sim 30\)の連分数被覆を実行し、証明書を生成する。

本ノートは計画であり、新たな完全証明書はまだ含まれない。元の四変数問題とこの枝全体は引き続き未解決。
