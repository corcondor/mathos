# v26 — Gemini提案の監査と、第二楕円商の階数1・小倍数点の整数排除

日付：2026-11-07 (JST)

## 0. 位置付け

対象は入れ子の二項係数方程式の枝 `ell=1, j=i-3` で、v24–v25の補助系 `a,b,rho` に帰着したもの。以下の多項式恒等式は本稿で独立にSymPyで検算した。一方 `b | 486`, `gcd(a,b)=1`, `a²>b²+rho`, `rho mod 9 in {1,4,6,7}`, `rho>=32770` は以前の v20–v23 の結果を**前提として再利用**し、その大規模完全探索をこの作業で再実行したわけではない。

「すべての元問題の解が除外された」とは主張しない。

## 1. `Gamma_0(3)` と明示的3-isogeny

`lambda=(8b²+9rho)/(216b²)` とし、`E1: y²+xy+lambda*y=x³`。

- `c4=1-24lambda`
- `Delta1=lambda³(1-27lambda)`
- `j1=(1-24lambda)³/(lambda³(1-27lambda))`
- `t_H=(1-27lambda)/lambda=-243rho/(8b²+9rho)`。Geminiの `+27rho/(8b²+9rho)` は誤り。
- `j1=(t_H+27)(t_H+3)³/t_H`。

核 `{O,(0,0),(0,-lambda)}` による標準3-isogeny の相手を

`E1': y²+xy+lambda*y=x³-5lambda*x-lambda-7lambda²`

と取ると、`c4'=1+216lambda`, `Delta'=lambda(1-27lambda)³`,
`j'=(t_H+27)(t_H+243)³/t_H³`。Deuringモデルに対する有理写像

```
x' = (x³+lambda*x+lambda²)/x²,
y' = [y(x³-lambda*x-2lambda²)-lambda*(x+lambda)²]/x³
```

はソース式を代入して曲線方程式の剰余が0となることをSymPyで検証した。既知のVélu/deuring式（独創的な新しい3-isogenyではない）。参照: https://www.cambridge.org/core/journals/mathematical-proceedings-of-the-cambridge-philosophical-society/article/locally-imprimitive-points-on-elliptic-curves/FBEB9EA77B0CBC3EF462666C911C7E8E

**p>=5 での還元型の精密化。** `b|486` ゆえ `p ∤ b`。`D=8b²+9rho` とすると `p|rho` と `p|D` は同時に起こらない。`c4,c4'` はそれらの素数ではp進単元になる。よって両曲線のp>=5の悪い還元はすべて乗法的で、

| pの条件 | E1 | E1' |
|---|---|---|
| `p | rho` | `I_{v_p(rho)}` | `I_{3 v_p(rho)}` |
| `p | D` | `I_{3 v_p(D)}` | `I_{v_p(D)}` |

となる。したがって 2,3 を除く導手の部分は両者とも `rad(rho D)`。素数2,3をこの記述から消してよいわけではない。

## 2. 第二楕円商の有理楕円曲面と「点の3分の1」

`T=rho/b², w=b²/a², v=S/a³` とすると、v25第二楕円商は

```
v²=4+(24-12T)w+(36+60T+12T²)w² - T²(3+4T)w³.
```

`A=-T²(4T+3), B=12(T²+5T+3), C=12(2-T)`, `X=Aw`, `Y=Av` で

```
E2: Y²=X³+B X²+AC X+4A².
```

この有理楕円曲面で

- `Delta2=-62208 T⁵(4T+3)²(9T+8)³`
- `c4=576(45T³+130T²+120T+36)`
- 特異ファイバーは `T=0 : I5`, `T=-8/9 : I3`, `T=-3/4 : I2`, `T=∞ : II`。

Weierstrass係数の次数は2,4,6の範囲で、無限遠の判別式は位数2、`c4` は位数1。この楕円曲面は section を持つ有理楕円曲面（Picard数10）。Shioda–Tateにより幾何的 Mordell–Weil 階数は `10-2-(4+2+1)=1`。

**明示的非捩れsection**:

```
R=(8T(4T+3), 6T(4T+3)(9T+8))
2R=(5T², 3T²(9T+8))
3R=(0,2T²(4T+3))
4R=(-T(7T+24)/4, 3T(T+12)(9T+8)/8)
```

v25およびGeminiが挙げた無限遠由来の点 `P0=(w,v)=(0,2)` は、このモデルで `(X,Y)=(0,-2T²(4T+3))`。従って **`P0=-3R`**。

`T=1` では `E2:Y²=X³+108X²-84X+196` で `R(1)=(56,714)≠O`。p=5,11は良い還元で、有限体上の点数がそれぞれ5と9。有理数体上の捩れ部分は自明なので `R(1)` は非捩れ。関数体のsection `R` も非捩れである。

**結論:** `rank E2(Q(T))=rank E2(Qbar(T))=1`。この事実は個別の `rho` の特殊化で階数が1という主張ではない。Shioda–Tate参照: https://doi.org/10.1112/blms.13175

なお、`E2` の元の三次式（`u`について）の多項式判別式は `-3888 b⁴ rho (8b²+9rho)³`。一方、それを Weierstrass 形にしたモデルの楕円曲線判別式は

`-62208 b⁴ rho⁵ (3b²+4rho)² (8b²+9rho)³`。

「多項式判別式」と「Weierstrass楕円曲線判別式」を混同してはいけない。後者には追加の `3b²+4rho` がある。

## 3. 最初の9つの倍数点に対する正整数排除

元の曲線への逆像は、`w=b²/a²=A/X(mR)` より、`a²=b² A/X(mR)` を満たす必要がある。`m=1,2` は `a²<0`、`m=3` は `w=0` で有限 `a` が存在しない。`m=4,...,9` の式は次の通り：

| m | 正整数 `a` に必要な式 |
|---|---|
| 4 | `a²=4rho(4rho+3b²)/(7rho+24b²)` |
| 5 | `a²=25rho²/[16(rho+12b²)]` |
| 6 | `a²=rho(4rho+3b²)/[3(rho+32b²)]` |
| 7 | `a²=(7rho+24b²)²/[40(rho+72b²)]` |
| 8 | `a²=16(rho+12b²)²(4rho+3b²)/[5(11rho²+1584b²rho-576b⁴)]` |
| 9 | `a²=9rho(rho+32b²)²/[8(rho²+264b²rho-576b⁴)]` |

すべて加法公式を用いてSymPyで恒等的に検証した。ここでは曲線の有限分岐（`a` が整数）を扱う。

### 3.1 m=4〜7：一次分母の約数条件

`a²` が整数なら以下が必要：

| m | 必ず割り切る正整数 | 右辺 |
|---|---|---|
| 4 | `7rho+24b²` | `7200 b⁴` |
| 5 | `rho+12b²` | `3600 b⁴` |
| 6 | `rho+32b²` | `4000 b⁴` |
| 7 | `rho+72b²` | `230400 b⁴` |

証明は例えばm=4で `7rho+24b² | 4rho(4rho+3b²)` を49倍して `7rho ≡ -24b²` を代入するもの。他も一次分母で剰余を取るだけ。**rhoに恣意的な上限を置かず**、`b|486` の全ての約数を走査した。

### 3.2 m=8,9：結果式による有限化

`D8=11rho²+1584b²rho-576b⁴`, `N8=16(rho+12b²)²(4rho+3b²)`、
`D9=rho²+264b²rho-576b⁴`, `N9=9rho(rho+32b²)²` とおく。

SymPyの整数多項式結果式は

```
Res_rho(D8,N8)=-2332800000000000*b^12 = -2^16*3^6*5^11*b^12
Res_rho(D9,N9)=-2985984000000*b^12 = -2^18*3^6*5^6*b^12
```

`a²` が正整数なら対応する `D_m(rho)>0` かつ `D_m(rho)|N_m(rho)`。整数係数Bézout恒等式によって `D_m(rho)` はそれぞれ上記の結果式の絶対値を割る。すべての正約数を列挙し、二次方程式 `D_m(rho)=d` の判別式が平方となる場合だけ正整数 `rho` を復元した。`rho` を直接総当たりしていない。

### 3.3 完全な有限監査の件数

| m | 検査した約数 | `a²` 平方 | `gcd(a,b)=1` | `a²>b²+rho` かつ v20 rho mod9 | v23 rho下限も通過 |
|---:|---:|---:|---:|---:|---:|
| 4 | 3,744 | 24 | 2 | 0 | 0 |
| 5 | 3,276 | 96 | 13 | 2 | 0 |
| 6 | 4,224 | 22 | 2 | 0 | 0 |
| 7 | 6,084 | 203 | 34 | 2 | 0 |
| 8 | 122,544 | 0 | 0 | 0 | 0 |
| 9 | 77,700 | 12 | 1 | 0 | 0 |

m=5で中途まで通るのは `(b,rho,a)=(1,88,11),(1,888,37)`、m=7では `(1,568,25),(2,9952,109)`。いずれも v23の `rho>=32770` より小さいため排除。m=8は `b|486, rho>0` に対して一切整数平方 `a²` を生成しない。m=9の唯一原始候補は `(1,8,3)` で `a²=b²+rho` となり厳密不等式に反する。

**結論（v20/v23の既存必要条件に依存）:** もとの枝の補助整数候補が `E2(Q)` の `mR`（`1<=|m|<=9`）に対応することはない。これは未制限の `rho` への有限約数計算による条件付き必要条件であり、**全ての m、特殊化した楕円曲線の全点、元の四変数問題全体を排除したものではない**。

## 4. Geminiの残る提案の判断

- モジュラー不変量と3-isogeny：理論的に有用。上の還元型と双対判別式が正確な成果。ムーンシャインとの結びつきは新しい整数解排除を直接与えない。
- 双楕円ふるい：最優先。特殊化 `rho` ごとの `rank E1(Q), rank E2(Q)` と十分なMordell–Weil群の生成元・飽和が必要。`rank J(C) = rank E1+rank E2 <2` を認証できた曲線でのみ古典的Chabautyの階数条件を満たす。参照: https://docs.magma-maths.org/ArithmeticGeometry/HyperellipticCurves/chabauty-method.html
- ABC／Szpiro：判別式の支持だけで全域高さの衝突は導かれない。ABC予想は現時点で未証明で、無条件の除去定理とは混同しない。計算を進めるなら別の研究分岐。
