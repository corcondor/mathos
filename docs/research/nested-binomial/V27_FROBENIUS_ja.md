# v27追補 — Frobeniusトレースと二重楕円商の合同ふるい

日時: 2026-11-07 JST  
対象: 元の入れ子二項係数方程式の `ell=1, j=i-3` 枝から生じる **必要条件**（v25–v27）。

**結論の射程:** 以下の定理は第二楕円商上の **特定の有理点Rの整数倍** `mR` に関する。特殊化した E₂(Q) の全点ではない。`rho=32770` の検査は `1<=m<=10^6` という有限範囲の結果であり、元問題の全解決ではない。

## 1. 定義と双楕円商のFrobenius分解

`b|486`, `b>0`, `rho>0` を固定し、`T=rho/b²` とする。

\[
 A=-T^2(4T+3),\quad B=12(T^2+5T+3),\quad C=12(2-T).
\]

第二楕円商のモデルと指定した有理点は

\[
 E_2:\;Y^2=X^3+BX^2+ACX+4A^2,\qquad
 R=(8T(4T+3),\,6T(4T+3)(9T+8)).
\]

元の整数点に必要な条件の一つは

\[
  a^2=b^2\frac{A(T)}{X(mR)}\in\mathbb Z_{>0},\qquad m\in\mathbb Z\setminus\{0\}.
  \tag{1}
\]

`X(3R)=0` なので `m=±3` 自体は不適。固定特殊化において `mR=O` もあり得るが、研究対象の正の有理数 `T` ではRは無限位数（v27）。

第一楕円商 `E₁: S²=f(q)` は、`q=a²` とした六次式の三次多項式 `f` で与えられ、種数2曲線 `C_{b,rho}: S²=f(a²)` のヤコビ多様体は `E₁×E₂` に有理同種である。

良い還元を持つ `p>=5` では

\[
 \boxed{\#C(\mathbb F_p)=p+1-a_p(E_1)-a_p(E_2)
     =\#E_1(\mathbb F_p)+\#E_2(\mathbb F_p)-(p+1).}\tag{2}
\]

ここで `a_p(E)=p+1-#E(F_p)`。さらにv25の3-isogeny商 `E₁'` については `a_p(E₁)=a_p(E₁')` であり、両者の点数は独立のフィルターにならない。これらはFrobenius固有値の一致に関する既知の同種不変性による。

**安全な良い還元条件:** `p>=5`、`p∤b rho (4rho+3b²)(8b²+9rho)`。この条件下で3曲線とも滑らかであり、`A(T)` は `p`-進単元。

## 2. 一般の局所倍数ふるい（無限のmに有効）

良い素数 `p` で `h_p=ord_{E₂(F_p)}(R)` を求める。各 `r mod h_p` について `Q=rR mod p` とおく。もし (1) が整数平方なら

- `Q=O` の場合: `a²≡0 (mod p)` が許されるので排除しない。
- `Q` が有限点で `X(Q)=0`: `A` は単元なので (1) は `p`-進整数でなく、**排除**。
- `X(Q)≠0` の場合: `b² A/X(Q)` は法pの平方剰余でなければならず、`(A/X(Q) | p)=-1` なら **排除**。

したがって、整数点に必要な `m mod h_p` は正確に上の安全側の許容集合に含まれる。`h_p | #E₂(F_p)=p+1-a_p(E₂)` なので、Frobeniusトレースが周期長の評価を与える。

## 3. 定理A: p=5での一様制約

`b|486` なので `5∤b`。`rho≡1,4 (mod5)` と仮定すると、`T=rho/b²≡1,4 (mod5)` であり、5で良い還元を持つ。v26の明示座標

\[
 X(2R)=5T^2,\quad Y(2R)=3T^2(9T+8),\qquad
 X(3R)=0,\quad Y(3R)=2T^2(4T+3)
\]

を還元すると `2R=-3R (mod5)`、従って `5R=O`。`R≠O` なので位数は5。`m≡±2` なら `X(mR)=0` で排除、`m≡±1` なら

\[
 a^2\equiv-b^2T/8=-\rho/8\equiv 3\rho\pmod5.
\]

`rho=1,4 (mod5)` のとき `3rho` は平方非剰余だから排除。結局

\[
 \boxed{\rho\equiv1,4\pmod5\ \Longrightarrow\ 5\mid m.}\tag{3}
\]

これは `rho` に上限を置かない。`rho` が5で0、2、3になる場合をこの式から排除してはならない。

## 4. 定理B: 7倍点の分母から得られる一様制約

`p>=11` を素数とし、`p | (7rho+24b²)` とする。このとき `p∤b`、`T=-24/7 (mod p)` で、`T`, `4T+3`, `9T+8` はいずれも非零。従ってpは良い還元。

v26で導出した `X(4R)=-T(7T+24)/4` と `X(3R)=0` を用いると、還元した `4R` と `3R` は同じX座標0を持つ。もし `4R=3R` ならR=Oだが、Rは有限の非零点。ゆえに `4R=-3R`、即ち `7R=O`。位数は正確に7。

`m≡±3 (mod7)` ならX座標0で排除。`m≡±1,±2` ではそれぞれ

\[
 b^2\frac{A}{X(R)}\equiv\frac{3b^2}{7},\qquad
 b^2\frac{A}{X(2R)}\equiv\frac{15b^2}{7}\pmod p.
\]

従って

\[
 \boxed{m\pmod7\in\{0\}
    \cup\bigl(\{\pm1\}\;\text{if } (21/p)=1\bigr)
    \cup\bigl(\{\pm2\}\;\text{if } (105/p)=1\bigr).}\tag{4}
\]

ここで `(d/p)` はLegendre記号。例えば `p=11,19,29,31` はどちらの記号も-1なので、これらのpが `7rho+24b²` を割る場合は `7|m`。

**無限合同類の例:** `b=1`, `rho≡226 (mod495)` は `rho≡1 (mod5)`, `rho≡6 (mod11)`, `rho≡1 (mod9)` を満たすため、(3)(4)から `35|m`。`rho=32896` が `rho>=32770` を満たす例。残る35の倍数を排除したわけではない。

## 5. 実行した有限体計算と二実装の照合

再現コード: `v27_frobenius_sieve.py`（正規化モデル、Eulerの判定）と `v27_frobenius_independent.py`（非モニック三次モデル、平方集合）で独立に計算した。

- `p=5, T=1,2,4` の正確な許容集合: `{0}`, `{0,1,4}`, `{0}`。上記p=5の一様定理を再現。
- 各素数 `11<=p<=251` に対する `T=-24/7 (mod p)` の条件を再現。`ord(R)=7` と (4) のLegendre条件が一致。
- `b=1, rho=32770` の良い素数 `11,13,17,19,23,41,67` で、各Frobeniusトレースを計算し、`lcm(h_p)=5040`、許容 `m mod5040` が **ちょうど** `{0,630,810,1260,2070,2970,3780,4230,4410}` と確認（9/5040、約0.18%）。
- 固定 `rho=32770`、すべての12個の `b|486` について、`5<=p<=239` の良い素数から必要条件を作り、**すべての整数 `1<=m<=1,000,000` を排除**。独立の別座標プログラムで各段階の残存件数と許容類を再計算し一致。

この有限計算は `rho=32770` における特定の部分群 `<R>` の初めの100万倍を対象とする。`rho=32770` 自体の全点・全m・元の二項係数方程式の解を排除したものではなく、`rho>32770` を一般に排除するものでもない。

## 6. 理論上の限界と次の実験

任意の**有限個**の良い素数に対して、`m` が `lcm(h_p)` の倍数ならすべての還元がOになり、今回の局所必要条件はその `m` を通す。よって「素数を有限個増やすだけ」で全てのmを排除することはできない。

突破口は (i) 悪い還元の素数（特に `p|rho`）における局所高さと `gcd(a,rho)=gcd(a,3)` の結合、(ii) 楕円除数列の原始素因数が `X(mR)` の **零点**（`(m±3)R`）を強制する正確な発現指数の評価、(iii) 特殊化したE₁(Q),E₂(Q)の認証されたMordell–Weil部分群と双楕円ふるいによる全点処理、のいずれか。

Frobeniusのスペクトルは局所周期を正確に決めるが、リーマン予想やGUE統計を仮定・利用していない。古典的な同種不変性と有限群演算のみを用いる。
