# v50：第一楕円商の階数0から、種数2補助曲線の全有理点を厳密決定

2026-11-08。元の入れ子二項係数方程式の主枝に由来する種数2補助曲線
\[
C_T:\quad s^2=(6u^2+2+3T)^2+4(u^2-1-T)^3
\]
の**全有理点**を、第一楕円商の完全なMordell–Weil群から分類する。これは従来の \(mR+nH\) の部分群ふるいや、元の整数解の高さ上界とは独立の方法である。

## 定理（階数0の繊維についての全有理点）

\(T\in\mathbb Q_{>0}\) とし、
\[
E_{1,T}:\quad y^2+6xy+(8+9T)y=x^3.
\]
\(E_{1,T}(\mathbb Q)\) のMordell–Weil階数が0、捩れ群が位数3であると仮定する。このとき、滑らかな射影モデルの全有理点は
\[
\boxed{
C_T(\mathbb Q)
=\{\infty_+,\infty_-\}
\cup
\left\{(u,s):
u=\pm\sqrt{1+T}\in\mathbb Q,\quad s=\pm(8+9T)\right\}.
}
\tag{50.1}
\]
したがって \(1+T\notin\mathbb Q^{\times2}\) なら**有限有理点は存在せず、全有理点は無限遠の2点だけ**。

### 証明（完全な有理写像と3捩れ）

\[
x=u^2-1-T,\quad h=6x+8+9T,\quad
y=(s-h)/2
\]
と置く。すると
\[
s^2=h^2+4x^3
\iff y^2+hy=x^3
\iff (x,y)\in E_{1,T}(\mathbb Q).
\]
楕円曲線の \(P=(0,0)\) は接線 \(y=0\) が3重接触するので正確に位数3を持つ。階数0かつ捩れ群位数3なら
\[
E_{1,T}(\mathbb Q)=\{O,(0,0),(0,-(8+9T))\}.
\]
有限有理点 \((u,s)\) は有限の \(x\) に写るので \(O\) には写らない。従って \(x=0\)、すなわち \(u^2=1+T\)。さらに \(s^2=(8+9T)^2\) なので \(s=\pm(8+9T)\)。逆にこれらはすべて \(C_T\) の点となる。これで全**有限**有理点を分類した。

\(C_T\) の右辺の六次多項式の判別式は
\[
\boxed{
3869835264\,T^4(4T+3)(9T+8)^6.
}
\]
\(T>0\) では非零であり、六次係数は4という有理平方だから、滑らかな射影モデルには無限遠の有理点が2つある。よって(50.1)。\(\square\)

## 実際に階数0・捩れ3を証明できた2繊維

SageMath 10.10のrank(proof=True,algorithm='pari')、gens(proof=True)、torsion_subgroup()により、次の**固定繊維**について階数0・捩れ群 \(\mathbb Z/3\) が証明済み：
\[
\boxed{T=1,\qquad T=100003.}
\]
[既存の成功したSage証明ログ](https://github.com/corcondor/mathos/actions/runs/42457291859) と [v49実行コード](v49_first_quotient_rank.sage) を参照。

- \(T=1\) では \(1+T=2\) が非平方。
- \(T=100003\) では \(1+T=100004\) が非平方。

したがって
\[
\boxed{C_1(\mathbb Q)=\{\infty_+,\infty_-\},\quad
C_{100003}(\mathbb Q)=\{\infty_+,\infty_-\}.}
\tag{50.2}
\]
これは両繊維の種数2補助曲線の**全有理点を決定した**という厳密な結論であり、元の整数解候補だけの排除ではない。

## b|486の全12繊維への拡張

\(\rho=100003\)、\(T=\rho/b^2\) で \(b\mid486\) のとき
\[
1+T=(b^2+100003)/b^2
\]
は12種類の \(b\) すべてで非平方である（整数平方根で検算可能）。従って、**もし個々の第一楕円商の階数0・捩れ群3が証明できれば**、(50.1)により、その繊維の全有理点が無限遠2点だけと確定する。

この条件の確認のため、[v50 Sage実行コード](v50_first_quotient_all_b.sage) と [12繊維を走らせるGitHub Actions](https://github.com/corcondor/mathos/actions/workflows/v50-genus2-all-rational-fibres.yml) を追加した。各繊維のランクが正、またはrankの証明が不成功なら、**全有理点を決定したとは宣言せず**、未分類・未証明として記録する。

## 注意

- v49/v50の全有理点決定は、**第一楕円商からの写像を持つ種数2曲線 \(C_T\)** のもの。第二楕円商 \(E_{2,T}(\mathbb Q)\) 自体の全有理点が決定したことを意味しない。
- \(T=100003\) の全12個の \(b\) について rank0 が成立すると仮定してはならない。Sageの個別の証明ログに従う。
- 一般の \(\rho\) すべてについて \(E_{1,\rho/b^2}\) の階数が0という主張は誤りになり得る。元の四変数問題の全解も未決定。
- 新しい全有理点の推論は既知の3捩れ・Sageのrank証明と上記の代数恒等式を使う。Lean形式化・外部査読は未実施。
