## Notes

- Delta bit length indicates the size of the discriminant; larger values correspond to potentially larger conductors.
- For a=1, b=3 the discriminant is 0 (singular case), already excluded in v17.
- j_max is the residual upper bound on the auxiliary residual j.
- Rank and modular form checks require Sage/Magma or equivalent; the coefficients above are ready for direct import into EllipticCurve([0,0,0,A4,A6]).
- Example Sage snippet:
  ```sage
  E = EllipticCurve([0,0,0,-219,1654])
  print(E.conductor(), E.rank())
  ```
