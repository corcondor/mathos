# v21：対数評価を残差へ移す・原始係数との二次橋・完全有限監査

\[
\binom{\binom ij}{\binom k\ell}=\binom{i^2}{j^2}+\binom{k^2}{\ell^2}
\]

の **\(\ell=1,\ j=i-3\)**、両方の \(k=r\) と \(k=A-r\) の分岐。\(n=i\ge104\)、\(A=\binom n3\)、\(r=\min(k,A-k)=3n+t\)、\(0<t<n/3\)。以下はこの枝の元の等式を満たすと仮定した**必要条件**であり、枝全体の解決ではない。

## 1. 新しい定理

従来の互いに素な \(a,b>0\)、\(b\mid486\)、\(\rho>0\) を使う。v20 の \(t>2n/(5\log n)\)（\(n\ge1024\)）と v17 の \(t>3\sqrt n\) を残差の明示多項式に代入し、

\[
\boxed{a^2<152\rho\log\rho}\tag{V21.1}
\]

を得た。固定 \(\rho\) の全候補 \(a\) は \(O(\sqrt{\rho\log\rho})\)。本結果は原式の二項係数の大小を用いるため、補助的な残差曲線の全ての点に一般化してはならない。

さらに v18 の \(n<36a^5/(b\rho^2)\) と \(b\ge1\) から

\[
\boxed{n<2^{24}\sqrt\rho(\log\rho)^{5/2}},\tag{V21.2}
\]

を得る。これは固定 \(\rho\) の高さを以前の次数8（または11/2）の多項式型から、平方根×対数冪型に改善する。

## 2. 残差と \(\delta\) 側の原始係数の二次式

\[
\frac ab=\frac{9n(t^2+3t+3)+t^3}{81n(n-1)},\qquad
\rho=a^2+ab(9n-t-6)-b^2(t^2+3t+3).
\]

v19 の \(C=M\delta\)、\(K=\delta r^2/Q\)、\(g=\gcd(C,K)\)、\(c=C/g\)、\(h=K/g\) は \(\gcd(c,h)=1\)、\(c\ge\delta\)、\(h/c=r^2/(n(n-1))>9\) を満たす。

\[
\begin{aligned}
\mathcal L&=(a^2-6ab-\rho-3b^2)(a^2+6ab-\rho-3b^2),\\
\mathcal T&=13a^4-17a^2\rho-6a^2b^2+4\rho^2+15\rho b^2+9b^4,\\
\mathcal W&=5a^2+4\rho+3b^2.
\end{aligned}
\]

整数係数の**恒等式**として

\[
\boxed{\mathcal L h^2-18\mathcal T hc+81\mathcal W^2c^2=0}.\tag{V21.3}
\]

よって \(\gcd(c,h)=1\) から

\[
\boxed{c\mid\mathcal L,\qquad h\mid81\mathcal W^2}.\tag{V21.4}
\]

特に \(p\ge5\) が \(h\) を割れば \(p\mid\mathcal W\) で、\(v_p(h)\le2v_p(\mathcal W)\)。既存の六次平方条件 \(y^2=F(a,b,\rho)\) との判別式の関係は

\[
\boxed{(18\mathcal T)^2-4\mathcal L(81\mathcal W^2)=11664a^2 F=(108ay)^2}.\tag{V21.5}
\]

\(\mathcal L\ne0\) なら \(h/c=9(\mathcal T\pm6ay)/\mathcal L\)。\(\mathcal L=0\) の場合も一次式 \(h/c=9\mathcal W^2/(2\mathcal T)\) として扱い、除算による消失はない。

\(h>9c\ge9\delta\)、\(h\mid81\mathcal W^2\)、\(b\le486\) と (V21.1) を合わせると

\[
\boxed{\delta<9(760\rho\log\rho+4\rho+708588)^2}.\tag{V21.6}
\]

一方 \(\delta\le Q<n^2\) と (V21.2) からも \(\delta<2^{48}\rho(\log\rho)^5\)。両上界の小さい方を利用できる。\(\rho\) 自体の一様上界は未証明。

## 3. \(13\le\rho\le4096\) を打切りなしで排除
